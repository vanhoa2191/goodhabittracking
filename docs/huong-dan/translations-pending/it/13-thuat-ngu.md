# 13. Glossario

[← 12. Mappa dei collegamenti e scenari](12-ban-do-lien-ket.md) · [Indice](README.md)

Termini usati in tutta la documentazione, in ordine alfabetico, con link agli approfondimenti.

| Termine | Significato in KidHabit | Vedi |
|---|---|---|
| **Atti di generosità (7 atti di generosità)** | Sette semplici modi per donare ogni giorno: un sorriso, contatto visivo, parole gentili, gratitudine, tolleranza, un gesto d'aiuto e lasciare il passo agli altri | [6](06-khoa-hoc-thoi-quen.md#chan-dung) |
| **Bambino** | Un profilo bambino nella famiglia; si usa un dispositivo associato per aprire la schermata del bambino | [2](02-man-hinh-be.md) |
| **Soprannome** | Il nome mostrato nella classifica al posto del nome reale del bambino | [5](05-gia-dinh-va-cai-dat.md#ho-so) |
| **Classifica** | Graduatoria basata sulle stelle ottenute nel periodo: familiare, di gruppo o pubblica | [2](02-man-hinh-be.md#bang-xep-hang) |
| **Livello** | Aumenta ogni 100 stelle ottenute | [2](02-man-hinh-be.md#sao-cap-chuoi) |
| **Profilo (16 profili)** | Un orientamento per la crescita, non un tipo di personalità; ogni profilo è un distintivo | [6](06-khoa-hoc-thoi-quen.md#chan-dung) |
| **Proprietario della famiglia** | La persona che ha creato la famiglia; può eliminare i dati della famiglia | [1](01-bat-dau.md#vai-tro) |
| **Programma di abitudini** | Un gruppo di abitudini da sviluppare passo dopo passo, con promemoria e monitoraggio delle fasi | [4](04-thiet-ke-thoi-quen.md#chuong-trinh) |
| **Serie (fiamma)** | Numero di giorni consecutivi con attività confermate; lasciare un giorno vuoto per una pausa non interrompe la serie | [2](02-man-hinh-be.md#sao-cap-chuoi) |
| **Coupon / codice regalo** | Un codice che aggiunge giorni alla durata del piano | [7](07-goi-va-thanh-toan.md#coupon) |
| **Prova gratuita** | 7 giorni gratuiti, una volta per famiglia, senza addebito automatico | [7](07-goi-va-thanh-toan.md#dung-thu) |
| **Approvazione** | Un genitore conferma un'attività o un premio del bambino | [3](03-hom-nay-va-duyet-viec.md#duyet) |
| **Diritti del piano** | Ciò che il piano attuale consente, per esempio il numero di bambini; sono associati alla famiglia | [7](07-goi-va-thanh-toan.md#cac-goi) |
| **Famiglia** | Unità di dati e pagamento; ogni famiglia è uno spazio separato | [9](09-bao-mat-va-rieng-tu.md#ai-thay) |
| **Fascia (GD1–GD5)** | Le cinque fasce d'età del framework: 0–3, 3–6, 6–12, 12–15 e 15–18 | [6](06-khoa-hoc-thoi-quen.md#khung) |
| **Fase dell'abitudine** | Le quattro fasi di un'abitudine: ancorare il promemoria, sviluppare la routine, ridurre il supporto e consolidare l'abitudine | [6](06-khoa-hoc-thoi-quen.md#bon-pha) |
| **Associazione del dispositivo** | Collega un dispositivo a un bambino specifico usando un codice o un codice QR | [5](05-gia-dinh-va-cai-dat.md#ghep-thiet-bi) |
| **Pacchetto per età** | Un insieme di sei attività iniziali caricate con un tocco per la fascia d'età del bambino | [5](05-gia-dinh-va-cai-dat.md#ho-so) |
| **Fascia di lega** | Bronzo, Argento, Oro o Diamante in base alle stelle totali ottenute | [2](02-man-hinh-be.md#sao-cap-chuoi) |
| **Commissione** | Il 30% dell'importo effettivamente pagato da una famiglia segnalata | [8](08-gioi-thieu-ban-be.md#hoa-hong) |
| **Oggi** | La prima area per genitori: Approvazioni e statistiche | [3](03-hom-nay-va-duyet-viec.md) |
| **Distintivo** | Un premio sbloccato al raggiungimento di un traguardo: 5 distintivi di base e 16 distintivi dei profili | [2](02-man-hinh-be.md#huy-hieu) |
| **Framework delle 47 abitudini** | Un insieme di abitudini per le età da 0 a 18 anni, in 5 fasce e 5 aree | [6](06-khoa-hoc-thoi-quen.md#khung) |
| **Catalogo premi** | Un elenco di premi creati dai genitori per il bambino | [4](04-thiet-ke-thoi-quen.md#kho-qua) |
| **Percorso per età** | Cinque fasce, tre passaggi per fascia, con l'aggiunta di un'abitudine a ogni passaggio | [4](04-thiet-ke-thoi-quen.md#lo-trinh) |
| **Mascotte** | Sei personaggi che accompagnano il bambino: Leo, Bunny, Panda, Fox, Turtle e Bee | [2](02-man-hinh-be.md#linh-vat) |
| **Codice di associazione / codice di connessione** | Un codice fisso per ogni bambino; apre solo il profilo di quel bambino | [9](09-bao-mat-va-rieng-tu.md#ma-ghep) |
| **Codice di segnalazione** | Un codice di 8 caratteri allegato al link `?ref=` | [8](08-gioi-thieu-ban-be.md) |
| **Assistente** | Un familiare invitato a consultare i progressi in modalità di sola lettura | [5](05-gia-dinh-va-cai-dat.md#nguoi-cham-soc) |
| **PayOS / VietQR** | Un gateway di pagamento per bonifici tramite codice QR bancario | [7](07-goi-va-thanh-toan.md#thanh-toan) |
| **PIN genitore** | Un codice di 4 cifre che protegge la Modalità genitore e le operazioni sensibili; sblocca l'accesso per 2 ore | [5](05-gia-dinh-va-cai-dat.md#pin) |
| **PWA** | Installa il sito come app sulla schermata Home | [5](05-gia-dinh-va-cai-dat.md#pwa) |
| **Stelle** | Punti premio usati per richiedere premi e costruire la città | [2](02-man-hinh-be.md#sao-cap-chuoi) |
| **Pausa** | Sospende promemoria dei progressi e serie per tutta la famiglia senza perdere dati | [5](05-gia-dinh-va-cai-dat.md#tam-nghi) |
| **Dare l'esempio** | I genitori mostrano un modello con le proprie azioni | [6](06-khoa-hoc-thoi-quen.md#chan-dung) |
| **Promemoria “Se… allora…”** | Un piano che collega un'abitudine a un'attività familiare o a un orario fisso | [4](04-thiet-ke-thoi-quen.md#chuong-trinh) |
| **Più tardi (rinvio)** | Il bambino sposta un'attività alla fine della giornata; non viene conteggiata come mancata | [2](02-man-hinh-be.md#hoan-thanh) |
| **Webhook / riconciliazione** | PayOS comunica il pagamento; il sistema lo verifica di nuovo con PayOS | [7](07-goi-va-thanh-toan.md#kich-hoat) |
| **Verifica in due passaggi (amministratore)** | Un codice TOTP richiesto per gli account amministratore | [10](10-quan-tri-va-van-hanh.md#admin) |
