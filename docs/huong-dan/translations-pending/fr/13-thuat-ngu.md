# 13. Glossaire

[← 12. Carte des liens et scénarios](12-ban-do-lien-ket.md) · [Sommaire](README.md)

Termes utilisés dans l’ensemble de la documentation, par ordre alphabétique, avec des liens vers des explications détaillées.

| Terme | Signification dans KidHabit | Voir |
|---|---|---|
| **Actes de générosité (7 façons de donner)** | Sept façons simples de donner chaque jour : sourire, regard bienveillant, paroles aimables, gratitude, tolérance, geste serviable et laisser la place aux autres | [6](06-khoa-hoc-thoi-quen.md#chan-dung) |
| **Enfant** | Profil d’enfant dans la famille ; un appareil associé ouvre son écran | [2](02-man-hinh-be.md) |
| **Pseudonyme** | Nom affiché dans le classement à la place du vrai nom de l’enfant | [5](05-gia-dinh-va-cai-dat.md#ho-so) |
| **Classement** | Classement basé sur les étoiles gagnées pendant la période : familial, de groupe ou public | [2](02-man-hinh-be.md#bang-xep-hang) |
| **Niveau** | Augmente toutes les 100 étoiles gagnées | [2](02-man-hinh-be.md#sao-cap-chuoi) |
| **Portrait (16 portraits)** | Axe de progression, et non type de personnalité ; chaque portrait correspond à un badge | [6](06-khoa-hoc-thoi-quen.md#chan-dung) |
| **Propriétaire de la famille** | Personne ayant créé la famille ; peut supprimer ses données | [1](01-bat-dau.md#vai-tro) |
| **Programme d’habitudes** | Groupe d’habitudes à développer progressivement, avec déclencheurs et suivi des phases | [4](04-thiet-ke-thoi-quen.md#chuong-trinh) |
| **Série (flamme)** | Nombre de jours consécutifs comportant des tâches confirmées ; une journée laissée vide pour faire une pause ne met pas fin à la série | [2](02-man-hinh-be.md#sao-cap-chuoi) |
| **Coupon / code cadeau** | Code qui ajoute des jours à la durée du forfait | [7](07-goi-va-thanh-toan.md#coupon) |
| **Essai gratuit** | 7 jours gratuits, une fois par famille, sans débit automatique | [7](07-goi-va-thanh-toan.md#dung-thu) |
| **Approbation** | Un parent confirme une tâche ou une récompense demandée par un enfant | [3](03-hom-nay-va-duyet-viec.md#duyet) |
| **Droits du forfait** | Ce que le forfait en cours autorise, par exemple le nombre d’enfants ; ces droits sont associés à la famille | [7](07-goi-va-thanh-toan.md#cac-goi) |
| **Famille** | Unité de données et de paiement ; chaque famille constitue un espace distinct | [9](09-bao-mat-va-rieng-tu.md#ai-thay) |
| **Étape (GD1–GD5)** | Les cinq étapes d’âge du cadre : 0–3, 3–6, 6–12, 12–15 et 15–18 ans | [6](06-khoa-hoc-thoi-quen.md#khung) |
| **Phase d’une habitude** | Les quatre phases : ancrer le déclencheur, construire la routine, réduire le soutien et installer l’habitude | [6](06-khoa-hoc-thoi-quen.md#bon-pha) |
| **Association d’un appareil** | Associe un appareil à un enfant précis avec un code ou un QR code | [5](05-gia-dinh-va-cai-dat.md#ghep-thiet-bi) |
| **Pack par âge** | Ensemble de six tâches de départ chargé en un geste selon la tranche d’âge de l’enfant | [5](05-gia-dinh-va-cai-dat.md#ho-so) |
| **Catégorie de ligue** | Bronze, Argent, Or ou Diamant, selon le total d’étoiles gagnées | [2](02-man-hinh-be.md#sao-cap-chuoi) |
| **Commission** | 30 % du montant effectivement payé par une famille parrainée | [8](08-gioi-thieu-ban-be.md#hoa-hong) |
| **Aujourd’hui** | Premier espace parental : Approbations et Statistiques | [3](03-hom-nay-va-duyet-viec.md) |
| **Badge** | Récompense débloquée à une étape clé : 5 badges de base et 16 badges de portrait | [2](02-man-hinh-be.md#huy-hieu) |
| **Cadre des 47 habitudes** | Ensemble d’habitudes pour les 0 à 18 ans, réparties en 5 étapes et 5 domaines | [6](06-khoa-hoc-thoi-quen.md#khung) |
| **Boutique de récompenses** | Liste de récompenses que les parents créent pour leur enfant | [4](04-thiet-ke-thoi-quen.md#kho-qua) |
| **Parcours par âge** | Cinq étapes, chacune comprenant trois paliers qui ajoutent une habitude | [4](04-thiet-ke-thoi-quen.md#lo-trinh) |
| **Mascotte** | Un des six personnages qui accompagnent l’enfant : Leo, Bunny, Panda, Fox, Turtle et Bee | [2](02-man-hinh-be.md#linh-vat) |
| **Code d’association / de connexion** | Code permanent propre à chaque enfant ; il ouvre uniquement son profil | [9](09-bao-mat-va-rieng-tu.md#ma-ghep) |
| **Code de parrainage** | Code de 8 caractères associé au lien `?ref=` | [8](08-gioi-thieu-ban-be.md) |
| **Aidant** | Membre de la famille invité à consulter la progression en lecture seule | [5](05-gia-dinh-va-cai-dat.md#nguoi-cham-soc) |
| **PayOS / VietQR** | Passerelle de paiement par virement bancaire à l’aide d’un QR code bancaire | [7](07-goi-va-thanh-toan.md#thanh-toan) |
| **Code PIN parental** | Code à 4 chiffres qui protège l’espace parental et les actions sensibles ; déverrouille l’accès pendant 2 heures | [5](05-gia-dinh-va-cai-dat.md#pin) |
| **PWA** | Installation du site web comme application sur l’écran d’accueil | [5](05-gia-dinh-va-cai-dat.md#pwa) |
| **Étoiles** | Points de récompense servant à échanger des récompenses et à construire la ville | [2](02-man-hinh-be.md#sao-cap-chuoi) |
| **Pause** | Suspend les rappels de progression et les séries de toute la famille sans supprimer les données | [5](05-gia-dinh-va-cai-dat.md#tam-nghi) |
| **Donner l’exemple** | Les parents montrent la voie par leurs propres gestes | [6](06-khoa-hoc-thoi-quen.md#chan-dung) |
| **Déclencheur « Si… alors… »** | Plan qui associe une habitude à une activité familière ou à une heure fixe | [4](04-thiet-ke-thoi-quen.md#chuong-trinh) |
| **Plus tard (report)** | L’enfant déplace une tâche à la fin de la journée ; elle n’est pas comptée comme manquée | [2](02-man-hinh-be.md#hoan-thanh) |
| **Webhook / rapprochement** | PayOS signale le paiement ; le système vérifie aussi de nouveau auprès de PayOS pour le confirmer | [7](07-goi-va-thanh-toan.md#kich-hoat) |
| **Vérification en deux étapes (administration)** | Code TOTP requis pour les comptes administrateurs | [10](10-quan-tri-va-van-hanh.md#admin) |
