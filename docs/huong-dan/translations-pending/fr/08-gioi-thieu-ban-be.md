## Présentation

Le programme s’adresse à deux parties, reliées par un **code de parrainage de 8 caractères** ajouté au lien `https://kidhabithero.com/?ref=<MÃ>` :

| Partie | Avantage |
|---|---|
| **Parrain** (parent utilisant KidHabit) | **Commission de 30 %** sur le montant effectivement payé par la famille parrainée |
| **Famille parrainée** | **10 % de réduction** sur le premier achat du forfait annuel (399,000 VND passe à 359,100 VND) |

Conditions publiques : page `/gioi-thieu/` du [site web](11-website-va-trang-cong-khai.md#trang-chinh). <!--op-->Règles techniques et opérationnelles : [Programme de parrainage](../affiliate-program.md).<!--/op-->

<a id="tham-gia"></a>
## Pour les parrains : adhérer et partager

1. Accédez à `Family → Settings → Offers & referrals`, puis ouvrez la carte **Parrainer un proche**. Lisez les règles, cochez la case d’acceptation et cliquez sur **Adhérer au programme**.
2. Copiez ou **partagez** « Votre lien de parrainage ». Vous pouvez envoyer le lien à votre proche ou lui communiquer le code à saisir manuellement.
3. Suivez le nombre de familles inscrites et ayant payé, et les commissions agrégées en attente, disponibles, demandées et versées.

Pas d’auto-parrainage ni de spam. Seuls les nombres et les commissions agrégées sont visibles, sans historique individuel ni informations sur les familles.

<a id="giam-10"></a>
## Pour les familles parrainées

- Ouvrez le lien `?ref=` de votre proche, puis connectez-vous et configurez votre famille comme d’habitude ; vous pouvez aussi **saisir le code manuellement** dans le champ « Avez-vous un code de parrainage ? » (dans `Settings` ou directement dans la fenêtre de paiement).
- Le parrainage est enregistré et le message « Vous bénéficiez de 10 % de réduction sur votre premier forfait annuel » s’affiche.
- Lors de votre premier achat du **forfait annuel**, le paiement affiche le prix réduit et la mention « 10 % de réduction grâce à votre code de parrainage ». Les forfaits Famille · Mensuel et À vie ne sont pas concernés.
- Chaque compte utilisateur ne peut être parrainé qu’une fois, dans les 60 jours suivant sa création et avant toute commande payée. Supprimer ou recréer une famille ne réinitialise ni les conditions ni la période de 12 mois. N’utilisez pas votre propre code.

<a id="ghi-nhan"></a>
## Enregistrement des parrainages

Vous pouvez saisir un code de deux façons. Les deux suivent la même règle et ne permettent pas d’enregistrer deux fois le même parrainage :

1. **Lien** : le site lit `?ref=` et enregistre le cookie `kidhabit_ref` (60 jours). Après la connexion du parent, l’application transmet le code pour l’enregistrer, puis supprime le cookie.
2. **Saisie manuelle** : champ de code dans Paramètres ou dans la fenêtre de paiement.

Le résultat s’affiche immédiatement : code enregistré ; code invalide ; vous ne pouvez pas utiliser votre propre code ; un code de parrainage est déjà associé à ce compte ; le code est réservé aux nouveaux comptes utilisateur n’ayant jamais payé ; programme suspendu. Seuls les parents autorisés à gérer la famille peuvent saisir un code.

<a id="hoa-hong"></a>
## Commissions

- 30 % du montant réellement payé pour chaque paiement pendant les 12 premiers mois à partir de la création du compte utilisateur parrainé, et non de la famille. Par exemple, le paiement réduit de 359,100 VND pour le forfait annuel génère une commission de 107,730 VND.
- Les nouvelles commissions sont retenues 40 jours à partir du paiement réussi pour couvrir le délai de remboursement de 30 jours et le traitement ; les dates de libération existantes restent inchangées. Elles restent gelées tant que la commande fait l’objet d’un dossier de remboursement ou d’assistance à la facturation ouvert. Une commande remboursée annule sa commission ; si elle a déjà été versée, nous contactons le parrain pour convenir du remboursement.
- Le système crée automatiquement la commission lorsque la commande aboutit ([activation du forfait](07-goi-va-thanh-toan.md#kich-hoat)) ; une erreur à cette étape n’empêche jamais l’activation du forfait du client.

<a id="rut-tien"></a>
## Retraits

1. Définissez un [code PIN parental](05-gia-dinh-va-cai-dat.md#pin) (obligatoire), puis saisissez-le dans ce navigateur.
2. Dans la carte **Recevoir votre commission**, indiquez la banque, le numéro de compte et le nom du titulaire, puis cliquez sur **Enregistrer les coordonnées**. Seuls les quatre derniers chiffres du compte sont affichés. Après une modification des coordonnées de versement, vous devez attendre **24 heures** avant de demander un retrait.
3. Lorsque le montant « Disponible » atteint le **minimum de 200,000 VND**, cliquez sur **Demander un retrait**.
4. L’équipe des opérations effectue le virement bancaire **manuellement** et vous en informe ; la demande passe à l’état « Versé ». <!--op-->Traitement côté administration : [10. Administration et opérations](10-quan-tri-va-van-hanh.md#gioi-thieu-admin).<!--/op-->

Les commissions peuvent être assujetties à l’impôt sur le revenu des personnes physiques ; il appartient aux bénéficiaires de les déclarer.

<a id="hoan-tien-hoa-hong"></a>
## Remboursements et commissions

Si elle figure dans une demande de retrait, KidHabit refuse la demande avant l’annulation ; si elle est déjà versée, nous contactons le parrain pour convenir du remboursement, sans déduction automatique des commissions futures. [Remboursements](07-goi-va-thanh-toan.md#hoan-tien).

<a id="quy-tac"></a>
## Règles et limites

- Ne vous parrainez pas vous-même et n’envoyez pas de messages indésirables. Les auto-parrainages avec le même compte ou la même famille sont bloqués.
- Chaque compte utilisateur ne peut être parrainé qu’une fois, dans les 60 jours suivant sa création et avant toute commande payée. Supprimer ou recréer une famille ne réinitialise ni les conditions ni la période de 12 mois. N’utilisez pas votre propre code.
- Une personne pourrait créer deux comptes pour se parrainer elle-même ; le système ne bloque pas complètement ce cas, mais les virements sont manuels et vérifiés avant paiement.
- Un compte de parrainage peut être suspendu en cas d’infraction (actuellement, la suspension est effectuée manuellement par un administrateur).
- Les taux de commission et de réduction, délais de retenue et montants minimums de retrait sont enregistrés dans la configuration du programme et peuvent changer ; les commissions déjà créées conservent le taux applicable à leur création.
- Certains éléments restent en attente : examen juridique et fiscal, notifications par courriel aux parrains et virements bancaires automatiques.
