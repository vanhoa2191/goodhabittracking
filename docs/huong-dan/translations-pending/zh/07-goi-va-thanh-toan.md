## 7 天免费试用

- **免费：0 VND**，无需信用卡，结束时**不会自动扣费**。
- 解锁家庭计划的所有功能，儿童人数**不设上限**。
- **每个家庭仅限一次**。如果家庭已使用过试用，开始按钮会显示：“此家庭已使用过试用，请选择计划以继续。”
- 开始方式：(a) 如果没有计划，在[家庭设置](01-bat-dau.md#thiet-lap)最后一步自动开始；(b) 打开 `/start`（“开始 7 天试用”）：使用 Google 登录、设置家庭并点击开始；(c) 在价格窗口的试用面板中开始。只有家庭中的家长可以开启试用。
- 家庭付款后，试用面板**不会再次显示**。
- 试用即将结束时，系统会发送提醒邮件（[电子邮件](#email)）。

<a id="cac-goi"></a>
## 计划

| 计划 | 价格 | 儿童人数 | 适用情况 |
|---|---|---|---|
| **7 天免费试用** | 0 VND | 不限 | 决定前体验所有功能 |
| **单儿童计划** | 29,000 VND / 月 | 1 名儿童 | 从一名儿童开始的家庭 |
| **家庭计划 · 月付** | 49,000 VND / 月 | 不限 | 多名儿童或使用全部功能 |
| **家庭计划 · 年付** | 399,000 VND / 年（原价 588,000 VND，节省 189,000 VND，即 32%） | 不限 | 持续使用，让小步骤逐渐成为习惯 |
| **终身计划** | 不出售 | 不限 | 仅由管理员手动授予<!--op-->（[10](10-quan-tri-va-van-hanh.md#khach-hang)）<!--/op--> |

所有付款均为**一次性付款**，不会自动续订。价格页面还列出家庭计划的额外权益（每周追踪报告、家庭竞赛和更快的技术支持），以及年付计划的权益（优先支持和育儿指南电子书）；该电子书**尚未提供**。

**名称因地区而异：**营销网站将*单儿童计划*称为“基础计划”，将两种家庭计划称为“高级计划”（月付和年付）。产品和价格相同。

**各计划可添加的儿童人数**由数据库检查：单儿童计划最多 1 名儿童；试用、家庭和终身计划不设上限；没有有效计划时，不能添加儿童档案。

## 购买入口

| 入口 | 说明 |
|---|---|
| 顶部栏中的**升级 Pro**按钮 | 打开“KidHabit Hero Pro 价格”窗口，供您选择计划 |
| 需要计划时显示的价格窗口 | 例如计划到期后 |
| `/pricing` 页面和[网站](11-website-va-trang-cong-khai.md#trang-chinh)上的计划选择按钮 | 带您前往应用中的 `/checkout?plan=…` |
| `/checkout` 页面 | 加载所选计划：登录；如有需要，设置家庭；然后付款 |

计划链接无效（已过时或信息缺失）时，会显示“付款计划无效”以及查看价格的按钮。权益属于**家庭**，不属于某个电子邮件地址。

<a id="thanh-toan"></a>
## 付款步骤

付款通过 **PayOS（VietQR）**处理：

1. 选择计划 → 如有需要，使用 Google 登录 → 点击“继续付款”。如果档案资料不完整，请填写全名和电话号码；这些信息会留作以后付款使用。优惠属于自愿选择，默认关闭。接着按要求确认条款，然后仅在家庭符合条件时输入推荐码。提交推荐码期间不能创建订单。只有在生成 QR 码之前才能输入代码，因为服务器会在创建订单时计算金额；应用代码后，此窗口不会替换现有订单。
2. 付款页面显示 **VietQR 码**和转账资料：收款人名称、银行、账号、**准确金额**和**必填转账备注**。页面提供复制每项内容的按钮、**下载 QR 码**按钮（可打开银行应用并选择扫描图库中的图片），以及打开 PayOS 安全付款页面的链接。若复制失败，请长按选中文字并手动复制。页面没有倒计时，因为服务器不设 15 分钟付款期限。
3. 使用银行应用或 MoMo 扫码。请**保留准确金额和转账备注**。
4. 如有需要，点击**“我已转账”**；应用会自动检查状态。状态错误会以您选定的语言显示，自动检查会继续。付款完成后，页面会显示“🎉 升级成功！”，计划立即解锁。

如果付款仍在处理中，**请勿立即再次付款**。价格由服务器设定，不能在浏览器中更改。只有家庭中的家长可以付款；若已设置 [PIN](05-gia-dinh-va-cai-dat.md#pin)，创建付款时需要输入 PIN。从 PayOS 页面返回应用后即可查看付款结果。

<a id="kich-hoat"></a>
## 启用和对账

系统通过以下三条独立路径之一**确认**付款后启用计划；先收到的确认生效，付款绝不会重复计入：

1. PayOS 的 **webhook** 调用 `/api/payment/webhook`（核验签名、金额、转账备注和订单所有者）。
2. **查询 PayOS：**家长停留在付款页面时，应用直接向 PayOS 查询订单，不依赖 webhook。
3. **后台对账：**后台任务每 10 分钟检查待处理订单并向 PayOS 查询。

如果已转账但没有看到计划，请等待几分钟，重新打开 `/checkout`，然后向客服提供订单代码。<!--op-->运营团队可在[管理 → 付款](10-quan-tri-va-van-hanh.md#thanh-toan-admin)中查看订单。<!--/op-->

<a id="cong-don"></a>
## 延长时长

如果当前计划仍有效时购买新计划，时间会**追加到当前期限末尾**，包括剩余试用时长：月付计划增加 1 个月，年付计划增加 1 年。如果购买的计划低于现有计划，**保留较高级别的计划**。终身计划不会被其他计划替代。

<a id="coupon"></a>
## 礼品码（优惠码）

礼品码由运营团队创建。在 `Settings → Account → Coupon code → Apply code` 中输入。

- 礼品码会增加**额外使用天数**；仅提供折扣的代码不能在此使用。如果家庭还没有付费计划，会切换为相应天数的“家庭计划 · 月付”；如果已有计划，天数会追加到当前期限末尾，计划类型不变。礼品码不能用于终身计划。
- 每个家庭只能使用**一次代码**。代码过期、已用完或停用时，会显示：“未找到代码、已使用或已过期。”
- **15 分钟内失败超过 10 次**后，访问会暂时锁定几分钟。

<a id="giam-gia"></a>
## 推荐家庭折扣

输入推荐码（通过 `?ref=` 链接或手动输入）的家庭，首次购买年付计划可享受 **9 折**（399,000 VND 降至 359,100 VND），前提是家庭此前没有付费订单。付款页面会显示“使用推荐码优惠 10%”。详情见[8. 推荐](08-gioi-thieu-ban-be.md#giam-10)。

<a id="hoan-tien"></a>
## 退款和取消

- **30 天退款：**如果您不满意，请在付款后 30 天内将订单代码和付款时间发送至客服邮箱。退款由人工处理；退款确认后，如果该订单的推荐佣金仍在待结算状态，将予以追回（[8](08-gioi-thieu-ban-be.md#hoan-tien-hoa-hong)）。
- **待付款链接**可由客服团队取消；只有 PayOS 确认后，订单才会变为“已取消”。
- **取消计划**由客服团队处理，并通过电子邮件确认。不会自动扣费。

<a id="email"></a>
## 发送给您的电子邮件

电子邮件分为两组：

- **登录邮件**（由 Supabase 发送）：注册确认、登录链接、账户恢复、邀请、电子邮件更改和重新验证。邮件界面已预先设计（[模板](../../supabase/email-templates/README.md)）。
- **生命周期邮件**（可开启或关闭）：欢迎和设置说明（`welcome_setup`）、试用到期提醒（`trial_ending`）、付款收据（`payment_receipt`）、客服请求更新（`support_status`）、退款（`refund_status`）和计划取消确认（`subscription_cancelled`）。

生命周期邮件**不包含儿童数据**。只有在您同意接收优惠时才会发送推广邮件；关闭同意后会立即停止发送。退信、投诉或取消订阅的地址不会再收到邮件。

<a id="het-han"></a>
## 计划到期

试用或计划到期且未续订时，家庭会被视为没有计划：您不能添加新的儿童档案，应用会建议您选择计划。**数据不会删除**；购买计划或使用礼品码即可继续使用。
