**设计**区域（`Design`）包含三个部分：习惯、年龄路线和奖励。需要有效计划或正在进行的试用（[7](07-goi-va-thanh-toan.md)）。

<a id="quan-ly-viec"></a>
## 管理习惯

`Design → Habits` 包含三个视图：

| 视图 | 用途 |
|---|---|
| **使用中** | 查看已分配的习惯，按儿童或“所有儿童”筛选，查看过去 7 天的完成记录，编辑、删除并设置提示 |
| **资料库** | 从模板资料库中选择更多习惯（[资料库](#thu-vien)） |
| **计划** | 启动一组习惯，逐步建立（[计划](#chuong-trinh)）；仅越南语显示 |

每项习惯都是分配给**一名儿童**或**全家**（“分配给”）的卡片。暂停的习惯仍会保存，但不会显示在[儿童界面](02-man-hinh-be.md#nhiem-vu)中。

<a id="tao-viec"></a>
## 创建或编辑习惯

点击“创建新习惯”按钮会打开表单：

| 字段 | 含义 |
|---|---|
| 习惯标题 | 例如“吃饭前洗手” |
| 描述和目的 | 显示给儿童阅读，位于[任务详情](02-man-hinh-be.md#chi-tiet)的“为什么重要”部分 |
| 图标 | 代表该习惯的小图像 |
| 成长类别 | 健康饮食、善行、自我照护、学习、健康、品格、思维等 |
| 奖励星星 | 习惯完成后儿童获得的星星数 |
| 重复频率 | 每天、周一至周五、周六和周日，或自定义日期 |
| 一天中的时段 | 早晨、下午、晚上或任何时间 |
| 倒计时 | [计时器](02-man-hinh-be.md#dem-gio)的分钟数；0 表示不倒计时 |
| 需要家长审批 | 开启后，儿童标记完成时**不会**立即获得星星，须由家长[批准](03-hom-nay-va-duyet-viec.md#duyet) |
| 分配给 | 所有儿童或一名儿童 |

从资料库或路线应用模板后，家长仍可调整时间和星星数、添加或删除习惯，以适应家庭日常安排。每项习惯**每名儿童每天只记录一次**完成（重复点击不重复计数）。

<a id="thu-vien"></a>
## 资料库

资料库内容取决于当前语言：

- **越南语**：[0–18 岁 47 项习惯框架](#khung-47)。
- **其他语言**：“儿童推荐习惯资料库”，包含八类建议（健康饮食和用餐、善行与给予、品格、思维、和谐个性、智慧与学习、能力与独立、身体活力），名称和说明均翻译为对应语言。选择“添加到任务列表”即可加入日程。

除这两个资料库外，家长还可以在[儿童](05-gia-dinh-va-cai-dat.md#ho-so)中加载**适龄习惯包**（六项入门习惯），或应用[年龄路线](#lo-trinh)。

<a id="khung-47"></a>
## 0–18 岁 47 项习惯框架

越南语资料库包含**习惯框架**（[框架说明见第 6 章](06-khoa-hoc-thoi-quen.md#khung)）。使用方法：

1. 选择一个**成长阶段**（共 5 个）和一个**习惯领域**：内在生活、健康、人际关系、学习、金钱或“全部”。
2. 每张卡片显示建议年龄范围、**进步表现**、成人的角色、儿童自我追踪的方法，以及**“查看做法和支持方法”**按钮。年龄仅供参考，请根据儿童的实际能力调整。
3. 点击**“添加到任务列表”**；卡片会变为“已添加到家庭”。从框架添加的习惯会**分享给全家**。若要分配给某名儿童，请编辑“分配给”（[创建或编辑习惯](#tao-viec)），或使用[计划](#chuong-trinh)或[年龄路线](#lo-trinh)，应用时可选择儿童。卡片还会显示过去 7 天的完成次数。

从框架添加的习惯会保留其原始习惯链接（框架代码），因此儿童完成时，应用会记录[16 枚人物徽章](02-man-hinh-be.md#huy-hieu)和[计划](#chuong-trinh)的进度。健康内容仅供参考，不能代替专业建议。框架已提供英语、韩语、法语、德语、意大利语、西班牙语、中文和日语版本；没有译文的语言使用英语版。

<a id="chuong-trinh"></a>
## 计划和提示

**自适应习惯计划**（目前已启用）帮助逐步养成习惯，而不是一次分配很多习惯。

**“如果……就……”提示**：每项习惯都可设置一个使用儿童自己的话表达的计划，例如“刷牙后，我读一页书”。

- 使用中习惯卡片上的**提示**按钮会打开表单：提示类型（**接在熟悉的事情之后**或**固定时间**）、儿童自己的计划说法、一天中的时段、执行地点（选填）、周末或忙碌日的计划（选填）以及适用儿童。设置了提示的卡片会显示“已设置提示”。
- 可用五个提示模板：起床后、早餐后、放学回家后、晚饭后、晚上刷牙后。

**启动计划**（“计划”视图，仅越南语）：应用会为每名儿童建议一组习惯，并通过三个步骤引导您操作。

1. **选择要开始的习惯**：先从少量习惯开始，通常为一两项，且不超过[年龄建议上限](03-hom-nay-va-duyet-viec.md#hom-nay)。超出上限会显示提醒，但仍可继续。
2. 为每项习惯使用模板或自己的文字**设置提示**。
3. **确认**：为儿童添加习惯并保存提示。完成后会返回“使用中”视图。

设置提示后，应用会追踪每项习惯的**阶段**（设置提示、建立惯例、逐步减少支持、成为惯例），记录[儿童的完成方式](03-hom-nay-va-duyet-viec.md#muc-ho-tro)，并在“今天”提供[调整建议](03-hom-nay-va-duyet-viec.md#tien-trien)。详细逻辑见[第 6 章](06-khoa-hoc-thoi-quen.md#logic)。

<a id="lo-trinh"></a>
## 年龄路线

`Design → Age Roadmaps` 取代了过去固定的每周或每月路线，因为习惯研究没有给出适用于所有人的统一天数。

- **5 个年龄阶段**：0–3 岁“安全与感官”，3–6 岁“探索与意志力”，6–12 岁“勤勉与技能”，12–15 岁“身份与情绪”，15–18 岁“方向与责任”。每阶段都会建议成人扮演的角色：示范、共同完成、观察、支持或提供建议。
- 每个阶段约持续 **12 周**，分为 **3 步**；**每一步只增加一项新习惯**，同时保留以前的习惯。周数标记用于回顾，**不是截止期限**：每个家庭都可以根据儿童情况自行决定每一步持续多久。
- 应用根据所选儿童的年龄选择阶段；您也可以切换到其他阶段。每一步显示进度（已分配并练习的习惯数量）和当前步骤。
- 点击步骤可**查看详情**，选择“应用给哪名儿童？”，然后点击**确认并应用**。习惯会加入儿童的每日安排；已分配的习惯不会重复添加。

越南语标签页还会提醒家长：路线仅建议**添加习惯的顺序**，而[计划](#chuong-trinh)会遵循每名儿童自己的节奏。

<a id="kho-qua"></a>
## 奖励商店

家长在 `Design → Rewards` 创建儿童可用星星兑换的奖励（[儿童如何兑换奖励](02-man-hinh-be.md#qua)）。

- **创建奖励**：填写奖励名称、所需星星数量（至少 5 颗）、说明或条件。在此创建的奖励没有兑换次数上限，可以编辑或删除。
- **有意义的奖励点子**：模板资料库有两类，**体验**（共度时光、体验和选择权）以及**有目的的物品**（支持兴趣、运动、学习和给予精神），并提供建议星星数量。选择“添加到奖励”。
- 儿童的申请会出现在[今天 → 审批](03-hom-nay-va-duyet-viec.md#duyet)下。

应用建议优先选择共度时光和体验，而非物品（[肯定原则](06-khoa-hoc-thoi-quen.md#nguyen-tac)）。

## 各部分如何配合

```
47 项习惯框架 ──添加──▶ 使用中的习惯 ◀──应用── 年龄路线
        │                         │  ▲                      （适龄习惯包）
        │ 框架代码                │  └─ 创建自定义习惯
        ▼                         ▼
  16 枚人物徽章          提示 + 计划 ──▶ 阶段、建议（今天）
                                  │
                                  ▼
                       儿童标记完成 ─▶ 审批 ─▶ 星星 ─▶ 奖励（奖励商店）
```

完整应用地图见[12](12-ban-do-lien-ket.md#ban-do)。
