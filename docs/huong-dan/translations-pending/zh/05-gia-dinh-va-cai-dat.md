**家庭**区域包含两个部分：`Family → Child profiles` 和 `Family → Settings`。

<a id="ho-so"></a>
## 儿童档案

每名儿童都有独立档案，包含：

| 信息 | 说明 |
|---|---|
| 真实姓名 | 供家长使用；除非您选择分享，否则不会公开显示 |
| 昵称 | 排行榜上显示的名称；留空时，公开排行榜使用“超级宝贝” |
| 年龄（0 至 18 岁） | 滑块会自动确定**阶段**（0–3、3–6、6–12、12–18）并附有说明。这会决定建议、[路线](04-thiet-ke-thoi-quen.md#lo-trinh)和[适龄界面](02-man-hinh-be.md#giao-dien-tuoi) |
| 吉祥物和颜色 | 六种[吉祥物](02-man-hinh-be.md#linh-vat) |
| 排行榜 | 选择是否加入公开排行榜，以及显示真实姓名还是仅显示昵称（建议使用昵称）。新儿童档案默认设为**私密** |
| 适龄界面 | 编辑档案时，可选**按年龄自动调整**、固定为 3–8 岁或 9–12 岁范围、固定为 13 岁起的界面，或**保留当前界面**。家长的选择优先于儿童设备上的选择 |

在档案卡片中，家长可以：

- **添加、编辑或删除**儿童档案。儿童人数取决于[计划](07-goi-va-thanh-toan.md#cac-goi)：单儿童计划最多允许 1 名儿童；试用和家庭计划没有人数上限。计划到期后，您必须订阅计划才能添加新档案。
- **加载适龄习惯包**（“自动添加 6 项适龄习惯……”），立即获取六项入门任务。
- [**手动奖励或扣除星星**](03-hom-nay-va-duyet-viec.md#chinh-sao)。
- 查看星星、等级、连续记录，以及儿童是否隐藏在排行榜中。
- 打开儿童的**连接码和 QR 码**（[下文](#ghep-thiet-bi)）。

<a id="ghep-thiet-bi"></a>
## 配对儿童设备

每名儿童都有**一个长期有效的连接码**（以及对应的 QR 码）。代码只允许访问该儿童，不包含 PIN 或家庭数据；除非家长刷新，否则会保持不变。

1. **获取儿童代码**：在 `Family → Child profiles` 中复制代码或点击“显示 QR 码”。如果已设置 [PIN](#pin)，您需要输入 PIN。
2. **打开儿童设备**：打开应用，进入“这是儿童的设备吗？”，然后选择“输入代码或扫描 QR”（或点击顶部栏的“儿童代码”）。
3. **扫描 QR 码或输入代码**：设备会自动登录到正确的儿童档案。屏幕显示“连接成功！”，儿童点击“开始儿童任务”。

配对后，设备每次都会直接进入[儿童界面](02-man-hinh-be.md)，不会显示家长控制面板或销售页面。

- 您可以**刷新**一名儿童的代码（“为此儿童创建新代码”），或刷新**所有儿童**的代码（“创建新的儿童代码”）：旧代码将失效。仅在怀疑代码泄露时操作。此操作需要 PIN。
- 如果相机无法打开：请授予相机权限、使用安全连接（https），或手动输入代码。
- 错误尝试次数过多会触发速率限制（[9](09-bao-mat-va-rieng-tu.md#ma-ghep)）。

<a id="thiet-bi"></a>
## 管理设备

`Settings → Devices & family rhythm → Children's devices` 会列出已配对设备：所属儿童、上次使用时间，以及访问权限是否过期。如果设备遗失或不再使用，请立即**撤销访问权限**（需要 PIN）。每台设备只能访问**一名儿童**的档案。

<a id="nguoi-cham-soc"></a>
## 邀请照护者

适用于想了解儿童进度但**不能更改任何内容**的祖父母或亲属。

1. 在 `Settings` 中点击**创建照护者邀请**。一次性邀请链接只会在创建时显示，并会在**72 小时后过期**。复制链接并发送给对方。
2. 受邀者打开链接，使用 Google 登录并点击接受。如果邀请已过期、被撤销，或其账户已属于另一个家庭，会看到“邀请无效……”提示。
3. 受邀者打开**照护者专区**，以只读权限查看每名儿童的进度：“今天：x / y 项任务”（y 为按重复规则安排在今天的任务数量；没有任务时显示“今天没有安排任务”）、“最近 7 天：x / y”、每名儿童的习惯，以及作为辅助数字显示的“累计”完成总数。照护者每天只能看到数量，不会看到完成了哪项任务、完成时间或任何备注。
4. 家长可以随时从“有效邀请”列表中**撤销邀请**。

<a id="cai-dat"></a>
## 设置分组

`Family → Settings` 分为多个分组；“设置分组”栏可跳转到各个部分：

| 分组 | 内容 |
|---|---|
| **设备和家庭节奏** | 儿童设备、安装应用、照护者、[家庭休息](#tam-nghi) |
| **账户和同步** | 客户信息、礼品码、家庭数据 |
| **隐私和通知** | 公开排行榜、匿名衡量、提醒 |
| **外观** | 浅色、深色、设备设置 |
| **保护家长区域** | PIN |
| **优惠和推荐** | 推荐码输入框、“推荐朋友”卡片（页面底部，仅登录后显示） |

地址栏会记住打开的部分（例如 `?section=settings#settings-security`）：重新加载后仍停留在该部分，浏览器的“返回”按钮会回到前一处。链接只会选择家长区域中的某个部分，不会解锁任何内容；儿童模式会忽略 `section` 部分。
页面底部有“打开用户指南”（应用中的 `/docs` 页面；见[在应用中获取帮助](01-bat-dau.md#tro-giup)），以及隐私、条款和联系客服链接（[11](11-website-va-trang-cong-khai.md)）。

<a id="tai-khoan"></a>
## 账户和同步

- **状态**：“家庭账户”、已验证、“云端就绪”。家庭数据会自动在手机、平板和电脑间同步，无需技术设置。
- **客户信息**：全名、电话号码（9 至 15 位数字）、电子邮件（只读），以及是否接收指南和优惠的选项。用于支持账户和付款。
- **优惠码**：输入礼品码可为访问权限增加额外天数（[7](07-goi-va-thanh-toan.md#coupon)）。

<a id="rieng-tu"></a>
## 隐私和通知

- **分享到公开排行榜**：适用于全家的开关，默认**关闭**，只能由家长更改。开启后，只会显示[档案](#ho-so)中选定的儿童，并只显示其昵称、头像、周期得分、连续记录和名次。可随时关闭（[9](09-bao-mat-va-rieng-tu.md#bxh-cong-khai)）。
- **匿名衡量**：家长同意开关，默认关闭。目前未配置数据接收目标，因此事件不会离开设备（[产品分析](../product-analytics.md)）。
- **提醒**：请见[下文](#nhac-viec)。

<a id="nhac-viec"></a>
### 家长提醒

开启“允许接收待处理事项提醒”，即可在有任务或奖励等待审批时收到提醒。提醒仅用于等待审批的事项，不用于广告，可随时关闭。若要在应用外接收通知，请点击“允许此设备发送通知”；如果设备阻止通知，提醒仍会显示在应用中（见[今天页面横幅](03-hom-nay-va-duyet-viec.md#nhac-viec-ngan)）。

<a id="giao-dien"></a>
## 外观

- 在“外观”分组中选择**浅色、深色或设备设置**。
- **字体和字号**：从顶部栏打开“字体和字号设置”窗口，让儿童更容易阅读文字。
- **语言**：使用顶部栏的语言选择器（[1](01-bat-dau.md#ngon-ngu)）。
- **按年龄调整儿童界面**：在[编辑儿童档案](#ho-so)时固定界面。

<a id="pin"></a>
## 家长 PIN

PIN **必须恰好为 4 位数字**，用于保护家庭管理区域。请勿向儿童透露。

- **创建**：输入 PIN，然后再次输入以确认。**更改**：输入当前 PIN，然后将新 PIN 输入两次。
- 设置 PIN 后，从儿童界面切换到家长模式时必须输入 PIN。正确输入后，此浏览器会保持解锁 **2 小时**；再次锁定时会清除解锁状态。
- 以下敏感操作需要解锁：查看或更改儿童连接码、撤销设备、审批任务和奖励、手动奖励或扣除星星、创建付款、删除家庭、保存银行资料或提取推荐收入。如果该区域未解锁，应用会返回锁定屏幕。
- 提取推荐收入要求家庭**已设置 PIN**（[8](08-gioi-thieu-ban-be.md#rut-tien)）。
- 错误尝试次数过多后，必须等待几分钟（“尝试次数过多”）。
- 儿童在家长设备上点击“完成”**不需要** PIN。

<a id="tam-nghi"></a>
## 全家休息

在 `Settings → Family break` 中点击**休息一下**，然后在全家需要暂时休息时确认（例如生病、旅行或假期）。休息期间：

- 儿童界面会隐藏进度提醒、连续记录和排行榜，并显示温和提示（[2](02-man-hinh-be.md#tam-nghi-be)）；
- 儿童仍可以完成任务；星星、奖励和任务不会删除；
- 休息日不会中断[连续记录](02-man-hinh-be.md#sao-cap-chuoi)，也不会在[计算习惯阶段](06-khoa-hoc-thoi-quen.md#logic)时计作漏做；
- [提醒](#nhac-viec)会暂停。

准备好后点击**恢复**。

<a id="pwa"></a>
## 安装应用

“安装 KidHabit Hero”卡片可让您像使用应用一样快速打开，同时继续从网页获取新版本。在 Android/Chrome 上点击“立即安装”；在 iPhone 上用 Safari 打开 → 分享 → 添加到主屏幕。需要时也可点击“刷新应用数据”。

<a id="du-lieu"></a>
## 家庭数据

“家庭数据”卡片可让您**下载 JSON 副本**，其中包含儿童档案、习惯、完成历史、奖励、小组、日记、提示以及儿童完成方式记录。文件**不包含 PIN 或付款信息**，但包含儿童数据，请妥善保管。“从 JSON 文件恢复”仅适用于存储在此设备上的数据（会替换所有本地数据）；Google 账户的数据保存在家庭服务器上。请从[统计](03-hom-nay-va-duyet-viec.md#thong-ke)单独导出儿童日记。永久删除：[9](09-bao-mat-va-rieng-tu.md#xoa-du-lieu)。

<a id="uu-dai"></a>
## 优惠和推荐

`Settings` 中的最后一个分组仅在登录后显示：

- **推荐码**：“有朋友给您的推荐码吗？”输入框（仅在家庭符合条件时显示）。
- **推荐朋友**：用于获取链接、追踪佣金和提取收入的卡片（[8](08-gioi-thieu-ban-be.md)）。
