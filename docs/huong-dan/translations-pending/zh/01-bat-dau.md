## 进入应用的三种方式

首次打开 `app.kidhabithero.com` 时，“您想如何进入 KidHabit？”页面会提供三个选项：两个直接显示的按钮，以及一个折叠的儿童入口。家长区域和儿童区域彼此分开：儿童不会看到付款或家庭设置。

| 入口选项 | 适用对象 | 操作结果 |
|---|---|---|
| **以家长身份继续**（使用 Google 登录） | 父母和监护人 | 打开家庭控制面板（[3](03-hom-nay-va-duyet-viec.md)）。首次使用时，您需要完成[家庭设置](#thiet-lap)。 |
| **这是儿童的设备吗？**（打开后选择“输入代码或扫描 QR”） | 儿童 | 设备只会与一名儿童配对，并直接打开[儿童界面](02-man-hinh-be.md)。儿童无需账户。 |
| **体验演示**（显示在家长按钮下方） | 所有人 | 使用示例数据，无需账户（[演示](#demo)）。 |

已登录的家长会直接进入控制面板。若要再次查看落地页，请选择“首页”或“查看落地页”。儿童设备完成配对后，每次都会直接打开儿童界面，不会显示家长控制面板或价格页面。

<a id="dang-nhap"></a>
## 登录

- **Google** 是家长的主要登录方式。
- **通过电子邮件接收一次性验证码**是第二种方式，目前处于**关闭**状态，直到启用<!--op-->（`emailCodeLogin` 标志，[启用方法](../deployment.md)）<!--/op-->。启用后，入口页面会显示折叠的“其他登录方式”区域；展开后会看到“通过电子邮件获取登录验证码”输入框。标志关闭时，该区域不会显示。家长输入电子邮件地址后会收到一组简短数字验证码，输入后即可登录。几秒后可以再次申请验证码；请求过于频繁时，需要等待几分钟。
- 登录失败时，应用会显示简短提示和重试按钮，不会保存任何信息。

通过推荐链接（`?ref=`）登录的家长会自动记为推荐来源（[8](08-gioi-thieu-ban-be.md#ghi-nhan)）。受邀成为照护者的人使用 Google 登录，然后接受邀请（[5](05-gia-dinh-va-cai-dat.md#nguoi-cham-soc)）。

<a id="thiet-lap"></a>
## 创建第一个儿童档案

首次进入时，“创建适龄家庭计划”窗口只用于创建儿童档案：

- 输入**儿童全名**（必填）、昵称（选填）和年龄（默认 5 岁）。
- 打开**更多自定义选项**，查看年龄阶段说明、更换吉祥物（默认 Leo）、预览六个入门习惯，或关闭添加入门习惯（默认开启）。家长之后可以修改这些设置。

您必须**确认自己是该儿童的父母或法定监护人**，并同意 KidHabit 存储儿童档案、习惯和进度。系统会按照政策版本记录同意信息（[9](09-bao-mat-va-rieng-tu.md#dong-thuan)）。公开排行榜默认关闭。

如果家庭尚未订阅计划，完成设置后会**自动开始 7 天免费试用**（按钮文字为“开始 7 天试用”）。每个家庭只能使用一次试用（[7](07-goi-va-thanh-toan.md#dung-thu)）。

您也可以直接从网站打开 `/start`（“开始 7 天试用”）：使用 Google 登录，设置家庭，然后点击开始。

<a id="thong-tin"></a>
## 客户信息

家长只需在结账时、填写条款和推荐步骤之前输入**全名和电话号码**。电话号码必须为 9 至 15 位数字。信息会保存在服务器上供以后付款使用；已填写完整资料的档案无需重复此步骤。此要求不会阻止登录或创建儿童档案。接收指导信息和优惠属于自愿选择，默认关闭。家长之后可以在 `Family → Settings → Account` 中修改资料（[5](05-gia-dinh-va-cai-dat.md#tai-khoan)）；取消订阅后，推广邮件会立即停止（[7](07-goi-va-thanh-toan.md#email)）。如果加载或保存失败，请点击**重试**。

<a id="vai-tro"></a>
## 家庭角色

| 角色 | 可以执行 | 不可以执行 |
|---|---|---|
| **家庭所有者**（创建者） | 执行家长可执行的所有操作、付款和删除家庭数据 | 无 |
| **父母或监护人** | 管理儿童、任务、奖励、审批和设备 | 所有者专属操作（删除家庭） |
| **照护者** | 在“照护者视图”中查看进度 | 编辑档案、任务、星星或计划 |
| **儿童**（已配对设备） | 完成自己的任务、申请奖励和记录日记 | 查看付款、设置或其他儿童的档案 |

只有家庭中的家长可以开始试用或付款。敏感操作还需要输入 [PIN](05-gia-dinh-va-cai-dat.md#pin)。

<a id="demo"></a>
## 演示

“体验演示”会打开包含三名示例儿童（年龄分别为 8 岁、4 岁和 1 岁）的应用，并提供示例任务、奖励和小组。演示数据存储在当前浏览器标签页中，因此重新加载页面后仍会保留。设置真实家庭或登录时，演示数据会被删除，**不会**与真实数据混合。演示不会向服务器发送任何内容，也无需付款。

<a id="ngon-ngu"></a>
## 语言

应用支持九种语言：越南语、英语、法语、德语、意大利语、西班牙语、中文、日语和韩语。初始语言按以下顺序确定：您保存的选择、所在国家或地区（来自 Cloudflare）、浏览器语言，最后是英语。您可以通过顶部栏的语言选择器更改语言。选择会被保存，因此页面、标题和界面都会保持为同一种语言。

窄屏上，顶部栏控件会移至**菜单**（⋮ 按钮）。菜单包含**账户**组、**快捷设置**组（语言、浅色或深色外观、文字大小、声音）以及**用户指南**链接。不常用的项目（价格、输入儿童配对码、16 种优势指南、家庭设置、首页和存储状态）位于**更多**下，默认收起，打开后才会显示。

部分详细内容（包括年龄阶段路线和“今天”页面）尚未翻译成全部九种语言；如果没有对应译文，内容会以英语显示。

<a id="tro-giup"></a>
## 在应用中获取帮助

本指南以两种形式内置在应用中：

- **每个项目旁边的 ?。** 在家长区域，每项功能标题旁都会显示一个小小的 **?**，例如审批、提示、PIN、配对码和付款。将鼠标悬停在问号上、点击它，或按 Tab 键移到它上面，即可阅读一到两句简短说明。点击**查看详情**，就能在当前页面打开指南中的相关部分，无需离开正在进行的操作。在窗口中点击其他章节链接可继续阅读，点击**返回**可回到上一处。按 **Esc** 或点击窗口外部即可关闭说明。
- **专门的指南页面。** 顶部栏中的**用户指南**按钮（或 `Family → Settings → Open user guide`）会打开 `/docs`：其中包含章节列表、**搜索**框（可输入带或不带声调的文字）、适用于常见任务的**“我想……”**快捷入口组，以及每章的目录。详情窗口中的**打开完整指南**按钮也会带您前往本页面的对应位置。

完整指南提供越南语和其他译文，目前包括英语。没有译文的语言会以英语显示问号说明，详细章节则以越南语显示，`/docs` 上另有简短摘要。
