本页以通俗语言说明 KidHabit 如何保护儿童数据。技术详情请见[安全与隐私](../security-privacy.md)。

<a id="du-lieu"></a>
## 储存哪些数据

应用会储存儿童档案（姓名、昵称、年龄）、习惯、进度、积分、奖励、已配对设备、订阅计划以及家长联系资料（全名、电话号码、电子邮件）。选用的功能还可能包含一句话日记、提示计划、儿童每次尝试的完成方式和愿望清单。**我们绝不会**将儿童数据、会话代码、PIN、PayOS 密钥或 webhook 内容发送到任何分析系统。

<a id="ai-thay"></a>
## 谁能看到什么

| 人员 | 可以查看 | 无法查看 |
|---|---|---|
| 家长 | 自己家庭的所有数据 | 其他家庭的数据 |
| 照护者 | 儿童姓名、启用中的习惯（及其重复安排）、每名儿童已完成或获批准尝试的总数，以及最近 7 天每天的数量；仅有只读权限 | 不能修改任何内容；无法查看单次尝试、一天中的具体时间、备注、年龄、昵称、奖励、小组、订阅、付款、设置或其他成员 |
| 儿童（已配对设备） | 自己的数据 | 其他儿童档案、付款、设置或 PIN |
| 运营人员 | 家长档案（姓名、电子邮件、电话）、订阅计划和订单；所有操作都会记录 | 儿童档案、任务或儿童日记 |

每个家庭在数据库层面都被隔离在独立的“区域”中：即使应用界面出现错误，一个账户也不能读取或写入另一个家庭的数据。每条数据都属于一个 `family_id`；计划和权益属于家庭，不属于电子邮件地址。

<a id="ma-ghep"></a>
## 儿童配对码

- 每个代码只会打开**一名儿童的档案**，且不包含 PIN 或家庭数据。数据库只储存代码的哈希值。
- 儿童设备的会话储存在 HTTP-only cookie 中，页面脚本无法读取；每次请求只会返回一名儿童的数据。
- 错误代码连续输入过多次会触发**速率限制**。
- 家长可随时**刷新代码**（旧代码将失效）并**撤销单台设备**（[5](05-gia-dinh-va-cai-dat.md#ghep-thiet-bi)）。查看、更改或撤销代码需要输入 PIN。

<a id="pin"></a>
## PIN

4 位 PIN 由**服务器**验证。正确输入后，浏览器会收到与家长和家庭绑定的签名解锁 cookie。有效期为 **2 小时**，再次锁定时会删除。设置 PIN 的家庭必须先解锁，才能执行以下敏感操作：删除家庭、撤销设备、查看或更改配对码、创建付款、审批任务和奖励、手动增加或扣除星星，以及查看推荐收入提现资料。儿童可以在家长设备上点击完成任务，无需输入 PIN。设置 PIN 的说明见[5](05-gia-dinh-va-cai-dat.md#pin)。

<a id="dong-thuan"></a>
## 同意

- 在[家庭设置](01-bat-dau.md#thiet-lap)期间，成人必须确认自己是父母或法定监护人，并同意储存儿童数据。同意信息会与**政策版本**一起储存。
- 公开排行榜、匿名分析、提醒和推广优惠都是**可选项目**，默认**关闭**，之后也可再次关闭。撤回同意会保留时间戳，不会删除同意历史。
- 照护者只能通过家长创建的一次性邀请进入家庭（72 小时后过期）；邀请可以撤销（[5](05-gia-dinh-va-cai-dat.md#nguoi-cham-soc)）。

<a id="bxh-cong-khai"></a>
## 公开排行榜

只有同时满足以下**两个条件**，儿童才会出现在公开排行榜中：家庭已开启分享（默认关闭，且只能由家长更改），**并且**儿童档案已设为参与（新档案默认私密）。排行榜只显示昵称（或“超级宝贝”）、头像、周期内获得的积分、连续记录和名次；**不含**儿童代码、家庭代码、真实姓名或年龄。积分根据周期内已确认的记录计算，而非当前余额，因此用星星兑换奖励不会改变排名。家庭和小组排行榜只使用各自范围内的数据。设置见[5](05-gia-dinh-va-cai-dat.md#rieng-tu)；儿童界面见[2](02-man-hinh-be.md#bang-xep-hang)。

<a id="chia-se"></a>
## 分享里程碑

“分享积极的里程碑”（[3](03-hom-nay-va-duyet-viec.md#thong-ke)）在打开设备分享面板前，始终会让家长**预览并确认**。默认情况下，内容不包含儿童姓名、年龄、照片或任务，也没有跟踪代码。

<a id="gioi-thieu-rieng-tu"></a>
## 推荐计划

推荐码会在 `kidhabit_ref` cookie 中保存 60 天（记录后删除）。只有获授权的管理员才能查看推荐人的银行资料；推荐人只能看到末四位。推荐人**绝不会**看到被推荐家庭的信息（[8](08-gioi-thieu-ban-be.md)）。

<a id="goi-y-ai"></a>
## AI 建议

此功能正在逐步开放，且默认**关闭**；只有您在“设置 → 隐私”的**AI 建议**卡片中同意后才会显示。点击建议按钮时，应用会请求 AI 模型（Cloudflare Workers AI）起草内容：

- **使用 AI 建议小步骤**（在习惯表单中）：只会发送**您刚输入的习惯名称**（已移除链接、电子邮件和电话号码）以及年龄段。
- **使用 AI 总结本周**：只会发送**本周计数**（独立完成、有人提醒、一起完成、未完成），不包含习惯名称或儿童姓名。

**绝不会发送**：儿童姓名或昵称、日记、儿童写的任何内容、照片或您的电子邮件。发送和返回的内容**不会写入系统日志**。结果仅作为标注“AI 起草”的建议；您阅读后选择**使用**或**忽略**，应用不会自行执行任何操作。每个家庭每天可使用的建议数量有限，用尽共享配额后功能会暂停。与其他敏感操作一样，此功能需要 PIN。关闭开关会立即停止。

<a id="do-luong"></a>
## 分析和提醒

- **匿名分析**有严格边界：事件中不包含姓名、习惯内容、儿童/家庭/用户代码、配对码、付款资料或精确时间戳。**目前未配置数据接收目标**，因此即使家长同意，数据也不会离开设备。未经真实测量，不会公布 DAU、留存率、NPS 等指标。请见[产品分析](../product-analytics.md)。
- **提醒**仅用于通知您有任务等待审批，不用于广告。
- 儿童各次尝试的完成方式和提示计划**仅用于向家长提供建议**，不用于给儿童排名或互相比较（[6](06-khoa-hoc-thoi-quen.md#logic)）。

<a id="xoa-du-lieu"></a>
## 下载和删除数据

- **下载**：获取家庭数据的 JSON 副本（[5](05-gia-dinh-va-cai-dat.md#du-lieu)）以及一句话日记的 CSV 文件（[3](03-hom-nay-va-duyet-viec.md#thong-ke)）。这些文件包含儿童数据，请妥善保管。
- **永久删除**：只有**家庭所有者**可以在 `Today → Analytics` 中准确输入 `DELETE FAMILY` 执行（如已设置 PIN，则需要 PIN）。这会删除儿童档案、习惯、进度、奖励、已配对设备和配对会话，且无法撤销。恢复登录账户**不会**恢复已删除的数据（[数据恢复](../data-recovery.md)）。

<a id="ky-thuat"></a>
## 技术保护措施

| 保护措施 | 对您的意义 |
|---|---|
| 家庭隔离和事务中的行级锁 | 不同家庭的数据不会混在一起 |
| 所有基于 cookie 的写入命令都会拒绝跨来源请求 | 陌生网站无法代表您操作 |
| PayOS“失败时关闭”：检查签名、金额、内容、订单所有者和重复处理 | 虚假通知无法启用计划 |
| 一次性试用和数据库级别的计划检查 | 无法通过更改界面绕过限制 |
| 内容安全策略（CSP）、框架保护和最小化浏览器权限 | 降低恶意代码造成的风险 |
| 敏感功能仅在服务器运行；新功能默认关闭 | 减少可被滥用的范围 |
| 管理员必须使用两步验证，所有操作均附原因记录 | 便于追踪和管理 |

<a id="phap-ly"></a>
## 法律限制

儿童数据的默认设置采取**审慎做法**，但这**不等于**获得 COPPA 或 GDPR-K 合规认证。在特定市场启用公开排行榜前，应进行法律审核，确认同意年龄、保留期限、访问权和删除权。[网站](11-website-va-trang-cong-khai.md#phap-ly-web)上的“隐私”“条款”和“联系”页面在法律批准标志启用前可能仍是草稿（未编入索引，也不显示在页脚或结账页）。报告事件时，请勿通过公开渠道发送机密信息或儿童数据。
