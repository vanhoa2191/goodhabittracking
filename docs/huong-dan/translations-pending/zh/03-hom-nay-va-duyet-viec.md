## 家长区域结构

家长区域有三个部分，每个部分都包含若干子部分。您可以使用键盘（方向键、Home、End）导航。

| 部分 | 项目 | 指南 |
|---|---|---|
| **今天** | 审批、统计 | 本指南 |
| **设计** | 习惯、适龄路线、奖励 | [4](04-thiet-ke-thoi-quen.md) |
| **家庭** | 儿童、设置 | [5](05-gia-dinh-va-cai-dat.md) |

待审批任务数量会显示为“审批”上的徽标。您可以在“家庭”中配对儿童设备（[5](05-gia-dinh-va-cai-dat.md#ghep-thiet-bi)）；顶部栏可在家长模式和儿童界面之间切换，并打开[16 种优势与 7 种给予方式指南](06-khoa-hoc-thoi-quen.md#chan-dung)。

<a id="hom-nay"></a>
## 每名儿童的今日情况

**审批**部分首先显示“（儿童姓名）的今天”卡片。如果您有多名儿童，可从上方的按钮行中选择一名。

- **今天完成的任务**：今天完成任务数与计划任务总数（“已完成 3 / 5 项任务”），以及**连续记录**（“漏做一天不会抹去进度”）。
- **需要您处理**：列出等待您处理的任务，或显示“目前没有需要您处理的事项”。如果有调整建议，卡片会显示“有 N 条针对儿童习惯的调整建议”，并提供**查看建议**按钮（[建议](#tien-trien)）。
- **正在培养的习惯（进行中 / 上限）**：儿童处于早期阶段的新习惯数，与建议的年龄上限对比（0–3 岁：1 项；3–6 岁：2 项；6–15 岁：3 项；15 岁及以上：4 项）。超过上限只会出现温和提醒，不会阻止任何操作。
- **最近七天**：每天标记为“已完成”“未完成”或“未安排”，并显示儿童的完成方式（独立完成、需要提醒、与您一起完成）。
- 如果还没有任何习惯设置提示，卡片会建议**“为第一个习惯设置提示”**，并直接链接到[习惯](04-thiet-ke-thoi-quen.md#chuong-trinh)。

此卡片始终显示。下方的“今天是怎么做到的？”、“习惯进度”和“回顾本周”部分属于[自适应习惯计划](06-khoa-hoc-thoi-quen.md#logic)（目前已启用）。

<a id="duyet"></a>
## 待审批的任务和奖励

“审批”部分包含两个列表：

1. **等待家长审批的任务**：儿童标记为已完成，并且您[设为“需要审批”](04-thiet-ke-thoi-quen.md#quan-ly-viec)的任务。每行显示任务名称、儿童、星星奖励和完成日期。点击**批准**即可添加星星（并可能解锁[徽章](02-man-hinh-be.md#huy-hieu)）；点击**拒绝**则不会添加星星。
2. **儿童的奖励申请**：显示儿童申请的奖励、已扣除的星星和申请时间。流程为：儿童申请 → 家长**批准** → 家长**发放奖励** → 完成。**拒绝**申请会将星星退还给儿童（[儿童奖励](02-man-hinh-be.md#qua)）。

如果家庭设置了 [PIN](05-gia-dinh-va-cai-dat.md#pin)，批准或拒绝任务、批准或发放奖励都需要输入 PIN。如果儿童直接在家长设备上标记任务完成，则无需 PIN。如果已开启[提醒](#nhac-viec-ngan)，页面还会显示“有 N 项等待审核”横幅。

<a id="can-xu-ly"></a>
## “需要您处理”栏和批量审批

此功能正在逐步开放；如果您暂时看不到，表示您的版本尚未启用。

“审批”部分顶部的**需要您处理**栏会汇总所有等待处理的事项：待审批任务、奖励申请和习惯调整建议，并显示各自数量。点击某一项即可跳转到相应操作位置。没有待处理事项时，会显示“目前没有需要您处理的事项”。

在待审批任务列表中，每行都有一个复选框。**系统不会预先勾选任何任务**：您可以逐项选择，也可以点击**全选**（每次最多 50 项）。底部栏会显示您选择的任务数量和儿童，然后提供**批准 N 项任务**或**拒绝 N 项任务**。整个批次只需输入一次 [PIN](05-gia-dinh-va-cai-dat.md#pin)。如果某项任务已经被批准或拒绝（例如另一位家长已处理），系统会跳过并告知您，因此重复点击不会重复发放星星。

当儿童已适应[习惯组](04-thiet-ke-thoi-quen.md#chuong-trinh)中的初始习惯（提醒逐渐减少或习惯已稳定），且未达到年龄上限时，此栏会建议**添加该组的下一个习惯**。选择**添加下一步**可重新打开该组的三个步骤，或选择**稍后**（14 天内隐藏）。应用绝不会自行添加习惯。

如果您将应用安装到主屏幕并开启了[提醒](#nhac-viec-ngan)，在支持图标徽标的设备上，应用图标会显示**等待审批的任务和奖励数量**（并非所有设备都支持；只显示数字，不显示儿童姓名或任务）。长按图标还会显示**审批**和**用户指南**快捷方式。网页应用本身不带主屏幕小组件。

<a id="muc-ho-tro"></a>
## 记录儿童的完成方式

“今天是怎么做到的？”部分会询问儿童今天或昨天如何完成每项习惯，提供三个按钮：**独立完成**、**需要提醒**、**和您一起完成**。此项为选填。答案帮助应用判断何时逐步减少提醒（[四个阶段](06-khoa-hoc-thoi-quen.md#bon-pha)）；它不是评分，也不用于比较儿童。从 15 岁起，儿童可以[自行选择](02-man-hinh-be.md#hoan-thanh)，您仍可随时修改答案。

应用只会询问最近完成的事项（今天和昨天），每次显示少量项目；记录答案后会显示“已记录”。如果有多项完成记录尚未填写，进度卡片会提醒您补充，以便应用提供反馈。

<a id="nhin-lai-tuan"></a>
## 回顾本周

“回顾本周（5 分钟）”卡片每周出现一次，帮助全家一起反思，而不是每天提醒儿童。卡片包含：

- **一件值得表扬的事**：儿童正在稳定做到的一项习惯。
- **一件可以调整的事**：尚未稳定的一项习惯，并建议缩小目标或调整时间。
- 建议**添加**新习惯（当前习惯较稳定且未超过上限时），或再**保持节奏**一周。
- 如果数据不足，会提醒您先记录几天“儿童是怎么做到的”，以便应用提供反馈。

<a id="tien-trien"></a>
## 习惯进度和建议

“习惯进度”部分会列出每项设有提示的习惯及其当前阶段：**选择提示、培养习惯、逐步减少支持、习惯已形成**。这些是支持儿童的建议，不是评分。每名儿童一次最多看到三条建议；每条都附有易读的原因，例如：

- 同时培养的习惯太多 → 暂时暂停一项。
- 连续多次漏做 → 尝试缩小目标、调整时间或增加周末安排。
- 最近完成时大多需要提醒 → 尝试视觉提示，或让儿童自己设置提醒。
- 儿童已能独立完成 → 改用口头鼓励，并逐步减少星星。

选择“稍后”会将建议隐藏 14 天（保存在此浏览器中）。选择习惯可打开[习惯](04-thiet-ke-thoi-quen.md#quan-ly-viec)并编辑其提示。完整的建议规则请见[6. 习惯科学](06-khoa-hoc-thoi-quen.md#goi-y)。

<a id="xu-huong-ho-tro"></a>
## 每周支持情况和习惯状态

此功能正在逐步开放；如果您暂时看不到，表示您的版本尚未启用。

每项习惯都有一个中性的**状态标签**，并始终同时显示图标和文字：**尚未开始**（还没有提示）、**逐渐成形**、**需要支持**（例如停滞或依赖提醒的建议）和**稳定**（正在减少支持或已稳定，最近的机会大多完成）。标签只作描述，不会评判儿童。

打开**最近 6 周的支持情况**可查看逐周柱状图：独立完成、有人提醒、一起完成、未记录、未完成。只有在数据**至少连续 3 周**、最近一周儿童独立完成的比例比第一周**至少高 20 个百分点**，且两周都充分记录了完成方式时，应用才会写“支持正在减少”。否则会显示“数据不足，暂时无法判断”。这是一个置信度较低的设计阈值，绝不会用于比较儿童。

<a id="tot-nghiep"></a>
## 习惯毕业

当一项习惯稳定至少 **3 周**，且儿童在最近 10 次机会中有**至少 8 次独立完成**，[需要您处理](#can-xu-ly)栏会提供三个选项：

- **毕业**：该习惯从儿童的每日列表中移除，并显示在您和儿童的**我能做到的事**下。星星、历史记录和已获得徽章保持不变。
- **降低星星数**：此后任务奖励先降至初始星星数的一半，再降至五分之一（最低为 1）。已获得的星星不变，您可以随时恢复初始数值。
- **保持不变**：将建议隐藏 14 天。

应用只会提出建议，不会自行操作。对于已毕业的习惯，应用每月会问一次：“儿童现在仍能独立完成吗？”您只需点一下选择：**仍可独立完成**或**恢复习惯**。您也可以在毕业后立即点击**撤销**，或在“我能做到的事”下选择**恢复习惯**。

<a id="mot-thay-doi"></a>
## 本周尝试一项改变

此功能正在逐步开放；如果您暂时看不到，表示您的版本尚未启用。

“回顾本周”下方的**本周尝试一项改变**卡片，只会建议尝试**一项**为期 **7 天**的改变，并从儿童已有的建议中选取：

- **缩小目标**：为习惯改名，并说明两分钟版本（适用于框架中的全部 47 项习惯）。
- **更换时间**：将习惯移到儿童实际完成它的时段（根据完成时间推算；最近至少有 6 条记录，且大多发生在另一个时段）。
- **一起完成**：您和儿童一起做几天；一起完成不算漏做。
- **新提示**：打开“管理任务”以编辑提示。
- **减少提醒**：先等儿童开始，再进行提醒。

点击**试行 7 天**既会应用改变（如需要），也会记录这次尝试。尝试进行中或等待反馈时，应用不会再为该儿童建议其他改变。7 天后，卡片会询问**“这有帮助吗？”**（有帮助 / 还没有 / 放弃）。如果您对缩小版回答“还没有”或“放弃”，习惯会恢复完整版本；应用在 30 天内不会为同一习惯建议相同做法。“习惯进度”下的建议（停滞、依赖提醒、稳定）也有对应的**试行 7 天**按钮。

<a id="muc-tieu-tuan"></a>
## 儿童的每周重点

您可以将 **2 到 4 项任务**标记为“儿童可以选择”（在**儿童的每周重点**卡片中勾选每项任务旁的复选框）。从 6 岁起，儿童每周开始时可在自己的界面中选其中**一两项**作为重点，并看到“x/7 天”的进度；无需账户。6 岁以下儿童由您在卡片中陪同选择。儿童只能从您开放的任务中选择，并且只能保存自己的选择。如果儿童没有选择，界面仍会显示[我正在练习](02-man-hinh-be.md#tu-lap)栏。

<a id="chinh-sao"></a>
## 手动增减星星

在 `Family → Children` 下，每名儿童都有一个**手动奖励 / 扣除星星**按钮：输入要调整的星星数（正数为奖励，负数为扣除），并填写简短原因（例如“愿意和手足友好分享，给予表扬”“提醒……”）。此操作需要 [PIN](05-gia-dinh-va-cai-dat.md#pin)，且会留下记录。可用于肯定指定任务以外的表现；请勿用来比较儿童。

<a id="thong-ke"></a>
## 统计、打印和分享

**统计**部分（`Today → Statistics`）包括：

- **7 天趋势**：显示全家每天完成任务数量的柱状图；当天没有完成记录时显示空柱。
- **打印每周习惯表**和**打印每周报告**：前者按星期列出任务，方便贴在冰箱上；后者为每周报告（“本周完成 X / Y 项 · N 积分”）。两者都通过浏览器的打印对话框打印。
- **儿童的一句话日记**：按日期查看儿童记录的句子并**导出 CSV**（文件包含儿童写的内容，请妥善保管）。仅在[日记](02-man-hinh-be.md#nhat-ky)功能启用时显示。
- **分享积极的里程碑**：先预览，再确认通过设备的分享面板分享一条家庭信息。默认情况下，内容**不包含儿童姓名、年龄、照片或任务**，也没有跟踪代码。
- 页面底部的危险区域是**永久删除家庭数据**（仅限家庭所有者；必须准确输入 `DELETE FAMILY`；请见[9](09-bao-mat-va-rieng-tu.md#xoa-du-lieu)）。

<a id="nhac-viec-ngan"></a>
## 提醒

家长[允许发送操作提醒](05-gia-dinh-va-cai-dat.md#nhac-viec)且存在待审批项目时，页面会显示横幅；如果设备允许通知，浏览器也会发送通知。家庭[休息期间](05-gia-dinh-va-cai-dat.md#tam-nghi)不会发送提醒。提醒仅用于需要审批的事项，绝不用于广告。
