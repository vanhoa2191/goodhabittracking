儿童通过[代码或 QR 码](05-gia-dinh-va-cai-dat.md#ghep-thiet-bi)打开此界面；您也可以在家长账户中选择“返回儿童界面”。儿童只能看到自己的数据。

<a id="bon-tab"></a>
## 四个标签页

| 标签页 | 内容 |
|---|---|
| **任务** | 今天的任务，按一天中的时段分组；早晨来信、日记和梦想之城也在这里 |
| **排行榜** | 家庭、小组和公开排行榜 |
| **兑换奖励** | 奖励商店、奖励目标和已申请的奖励 |
| **徽章** | 已解锁和仍未解锁的徽章 |

页面顶部会显示问候语、吉祥物、等级、星星数量、连续记录和今日进度。

<a id="nhiem-vu"></a>
## 每日任务

- 任务根据您[创建任务](04-thiet-ke-thoi-quen.md#quan-ly-viec)时设定的时间安排，分为**早晨、下午、晚上、任何时间**。
- 每项任务只会在设定的重复日期出现（每天、工作日、周末或指定日期）。
- “前一天”和“后一天”按钮可让儿童查看并标记今天前后的日期；服务器只接受从今天**前两天到后一天**的日期。
- 完成所有任务后，会显示“您完成了今天的所有任务！”。如果今天没有任务，则显示“祝您今天愉快！”。
- 如果家庭正在[休息](#tam-nghi-be)，进度提醒和连续记录会隐藏。

<a id="hoan-thanh"></a>
## 完成、撤销、稍后再做

- **完成**：点击圆圈或**向右滑动**。卡片会立即更新状态，星星“+N”会向上浮起，设备会轻轻振动，保存成功时会播放声音。如果保存失败，卡片会恢复之前的状态，并显示“无法保存，请重试。”以及括号中的简短代码，方便您提供给客服。
- **需要家长审批的任务**：儿童标记任务完成后，卡片会变为“等待审批”（“您做到了！现在请家长检查。”），在您[批准](03-hom-nay-va-duyet-viec.md#duyet)之前**不会增加星星**。
- **撤销**：再次点击已完成的任务即可取消标记。如果任务所得星星已用于兑换奖励，应用不允许撤销，以免余额变成负数。
- **稍后再做**：**向左滑动**或点击“稍后再做”，将任务移至“今天稍后”；延期的任务不算错过。点击“现在做”可将任务移回。完成延期任务后，其延期状态会自动取消。
- 从 15 岁起，儿童完成习惯后可以选择“这次您是怎么做到的？”（自己完成、有人提醒或与他人一起完成），也可以跳过；请参阅[记录儿童的完成方式](03-hom-nay-va-duyet-viec.md#muc-ho-tro)。对于已经成为日常习惯的事项，儿童会看到口头肯定，而不只是星星奖励。

<a id="chi-tiet"></a>
### 详情、计时器和朗读

<a id="dem-gio"></a>
- **任务详情**：标记完成前，点击任务即可阅读其“意义”和“如何完成”（以及适用时的持续时间）。
- **计时器**：有时长限制的任务（例如刷牙 2 分钟）会显示**开始**、**暂停**、**重置**和**完成计时**按钮。
<a id="doc-to"></a>
- **朗读**：如果设备支持，点击扬声器按钮即可使用设备语音朗读任务内容。
- **声音**：使用按钮打开或关闭声音；从 20:00 到次日 07:00 之前，音量会减半。
- **文字大小和字体**：在“文字与字号设置”窗口中调整（[界面设置](05-gia-dinh-va-cai-dat.md#giao-dien)）。

<a id="sao-cap-chuoi"></a>
## 星星、等级和连续记录

- **星星**是奖励积分。每项任务会增加您设定数量的星星。星星可以用于兑换奖励或建造城市，但**累计获得的星星总数**不会减少。
- **等级**每累计获得 100 颗星星提升一级：少于 100 颗为 1 级，100 颗及以上为 2 级，以此类推。
- **连续记录**（火焰图标）统计连续有任务获确认完成的天数。如果儿童今天尚未完成任何任务，昨天的连续记录会保留到当天结束（火焰会变为“休息”状态）；再空过一天则连续记录归零并重新开始。家庭的[休息日](#tam-nghi-be)不会中断，也不会增加连续记录。
- **联赛段位**根据累计获得的星星计算：青铜、白银（70+）、黄金（150+）、钻石（300+），并显示在[排行榜](#bang-xep-hang)上。

星星和连续记录只用于激励，不用于评判品格或比较儿童（[原则](06-khoa-hoc-thoi-quen.md#nguyen-tac)）。

<a id="huy-hieu"></a>
## 徽章

**徽章**标签页会显示已解锁和未解锁的徽章及其进度。徽章分为两组：

- **五个基础徽章**：绿色起步（完成第一个任务）、3 日火焰、7 日勇士、善行超级英雄（20 项任务）、100 星皇冠。
- **16 枚人物徽章**：儿童完成与相应人物关联的[习惯框架](06-khoa-hoc-thoi-quen.md#chan-dung)中足够多的任务后，即可解锁对应人物；第 16 枚人物徽章“巅峰”会在其他徽章全部收集后解锁。

解锁新徽章时会显示庆祝页面。您也可以分享家庭里程碑，无需公开儿童的姓名或照片（[分享里程碑](03-hom-nay-va-duyet-viec.md#thong-ke)）。

<a id="qua"></a>
## 奖励

儿童在**兑换奖励**标签页使用星星。您可以在[奖励商店](04-thiet-ke-thoi-quen.md#kho-qua)中创建奖励。

1. **奖励目标**：儿童点击某个项目上的“设为目标”，追踪还需要多少星星。目标会保存在儿童的“梦想奖励目标”下。这还不算申请奖励。
2. **申请奖励**：儿童点击“兑换此奖励”。星星会**立即扣除**，申请会发送给您（“奖励兑换申请已发送给您的家长！”）。如果星星不足，会显示“星星不足，无法兑换”；缺货奖励无法兑换。
3. **家长审批**：申请会出现在[今天](03-hom-nay-va-duyet-viec.md#duyet)页面。您先**批准**，然后**发放奖励**；如果您**拒绝**，星星会退还给儿童。
4. 儿童的**奖励商店**会显示每个项目的状态：等待审批、已批准、奖励已发放。

<a id="bang-xep-hang"></a>
## 排行榜

排行榜有三个范围和三个周期：

| 范围 | 可查看者 | 条件 |
|---|---|---|
| **家庭** | 家庭中的儿童 | 无 |
| **小组 / 部落** | 小组成员 | 儿童创建或加入了小组 |
| **全球** | 家长允许分享的儿童 | 家庭账户已连接；您[开启分享](05-gia-dinh-va-cai-dat.md#rieng-tu)并选择儿童；默认**关闭** |

周期：今天、本周、本月。排名分数为**该周期内获得的星星数**；用星星兑换奖励不会改变排名。

- **小组**：创建小组（设置名称、小组奖励和全组每周星星目标；系统会生成一个**6 位邀请码**），或输入邀请码加入。小组成员可以发送“击掌”鼓励。
- 公开排行榜只显示**昵称**（若未设置，则显示“超级宝贝”）、头像、该周期积分、连续记录和名次；不会显示真实姓名、年龄或代码（[隐私](09-bao-mat-va-rieng-tu.md#bxh-cong-khai)）。
- 家庭休息期间，儿童界面会隐藏排行榜标签页。

<a id="linh-vat"></a>
## 吉祥物和颜色

共有六种吉祥物：**Leo**（狮子，通过小任务练习勇气）、**Bunny**（兔子，关心他人）、**Panda**（熊猫，保持平静、看得更清楚）、**Fox**（狐狸，对新事物充满好奇）、**Turtle**（乌龟，耐心地陪伴儿童前行）和 **Bee**（蜜蜂，乐于看到全家互相帮助）。儿童**最多每 7 天更换一次**吉祥物；界面会显示下次可更换的时间。**主色**可以随时更改。创建[档案](05-gia-dinh-va-cai-dat.md#ho-so)时也可以选择吉祥物。

<a id="thu-buoi-sang"></a>
## 早晨来信

从设备所在时区的 **07:00** 起，儿童每天会收到一封吉祥物的新信（包括开场、温和的信息和结尾）。儿童点击“我读过了”；当天仍可再次阅读，阅读状态也会同步到儿童的其他设备。此功能已**开启**。

<a id="nhat-ky"></a>
## 一句话日记

在“我想记住的一件事”卡片中，儿童写下**一句话**（最多 280 个字符，不换行），记录学到的内容、做得好的事或明天想再试的事，然后点击“保存日记”。只有儿童和家长可以查看；内容**不会用于衡量表现**。您可以在[统计](03-hom-nay-va-duyet-viec.md#thong-ke)中重读并导出 CSV。此功能已**开启**。

<a id="thanh-pho"></a>
## 梦想之城

儿童使用星星建造四座设施：**绿意花园**（30 颗星）、**图书馆**（60 颗）、**连心桥**（90 颗）和**天文台**（120 颗）。建成的设施会永久保留。累计获得的星星不会扣除，因此进度和达到的等级不会丢失。如果星星不足，会显示“积分不足”。此功能已**开启**。

<a id="giao-dien-tuoi"></a>
## 适龄界面

儿童界面会根据三个年龄段自动调整：**3–8 岁**、**9–12 岁**和**13 岁及以上**。最小年龄段的按钮更大、吉祥物更醒目；年龄较大的儿童使用更简洁的界面。从 13 岁起，界面使用“积分”而非“星星”，也不会称儿童为“小朋友”。3 岁以下儿童由家长引导，因此界面保持不变。

- 界面首次切换时，儿童可以选择“保留旧版外观”或“使用新版外观”，然后选择“简洁”或“有人陪伴”风格。
- 您可以在[编辑儿童档案](05-gia-dinh-va-cai-dat.md#ho-so)时为儿童**固定**年龄段，或保留旧版外观；您的选择优先于儿童在设备上的选择。

<a id="tam-nghi-be"></a>
## 家庭暂停

点击[休息一下](05-gia-dinh-va-cai-dat.md#tam-nghi)后，儿童界面会显示“今天我们全家休息。您仍可以随时做一件好习惯。”儿童仍可完成任务；星星、奖励和连续记录不会被删除。进度提醒和排行榜会隐藏。

<a id="tu-lap"></a>
## 我正在练习、节奏和我能做到的事

此功能正在逐步开放；如果您暂时看不到，表示您的版本尚未启用。

- **节奏**：儿童界面顶部会显示“本周 N/7 天”（儿童最近 7 天中至少完成一项任务的天数；家庭暂停日不计入）。连续记录仍会以小字显示在旁边（仅在较宽的屏幕上显示）。如果连续记录降至 0，儿童会看到“新的一天，我们继续努力吧！”，不会看到责备内容。
- **我正在练习**：简短显示一两项儿童正在建立提示或练习的习惯，帮助儿童知道该关注什么。项目由应用选定，儿童无需选择。
- **本周重点**（从 6 岁起）：如果您已[开放一些任务供儿童选择](03-hom-nay-va-duyet-viec.md#muc-tieu-tuan)，儿童会在每周开始时选出一两项作为重点，并查看 7 天中的进度。
- **鼓励语**：当儿童首次独立完成一项习惯、累计独立完成 3 次、连续独立完成 7 次，或两周无需提醒（仅在记录了完成方式时计数），会看到一次具体鼓励语，并有一个“好的”按钮。不会增加星星。
- **我能做到的事**：以只读方式列出已[毕业](03-hom-nay-va-duyet-viec.md#tot-nghiep)的习惯。习惯刚毕业时，儿童也会看到一条鼓励语。
