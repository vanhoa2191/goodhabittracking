お子さまは[コードまたはQRコード](05-gia-dinh-va-cai-dat.md#ghep-thiet-bi)でこの画面を開きます。または保護者アカウントから「お子さまの画面に戻る」を選択できます。お子さまには自分のデータだけが表示されます。

<a id="bon-tab"></a>
## 4つのタブ

| タブ | 内容 |
|---|---|
| **タスク** | 今日のタスクを時間帯ごとに表示します。朝のお手紙、日記、夢の街もここにあります |
| **ランキング** | 家族、グループ、公開ランキング |
| **ごほうびと交換** | ごほうびストア、ごほうびの目標、リクエストしたごほうび |
| **バッジ** | 獲得済みと未獲得のバッジ |

ページ上部には、あいさつ、マスコット、レベル、スター数、連続記録、今日の進捗が表示されます。

<a id="nhiem-vu"></a>
## 毎日のタスク

- [タスクを作成](04-thiet-ke-thoi-quen.md#quan-ly-viec)するときに設定したスケジュールに従い、**朝、午後、夕方、いつでも**に分けて表示されます。
- 各タスクは、繰り返し設定した曜日（毎日、平日、週末、または選択した曜日）にのみ表示されます。
- 「前の日」「次の日」ボタンで今日の近くの日を表示して記録できます。サーバーが受け付けるのは、今日の**2日前から1日後まで**です。
- すべてのタスクを完了すると、「今日のタスクをすべて完了しました！」と表示されます。今日のタスクがない場合は、「楽しい一日を！」と表示されます。
- 家族が[休憩中](#tam-nghi-be)の場合、進捗リマインダーと連続記録は非表示になります。

<a id="hoan-thanh"></a>
## 完了、取り消し、後で行う

- **完了**: 円をタップするか、**右にスワイプ**します。カードの状態がすぐに変わり、「+N」個のスターが浮かび、端末が軽く振動します。保存に成功すると音が鳴ります。保存に失敗した場合、カードは元の状態に戻り、「保存できませんでした。もう一度お試しください。」と、サポートへの連絡に使える短いコードが括弧内に表示されます。
- **保護者の承認が必要なタスク**: お子さまがタスクを完了にすると、カードは「承認待ち」（「できましたね！保護者が確認します。」）に変わります。[承認](03-hom-nay-va-duyet-viec.md#duyet)されるまでスターは**追加されません**。
- **取り消し**: 完了済みタスクをもう一度タップすると、未完了に戻せます。スターをごほうびとの交換に使った後は、残高がマイナスにならないよう、完了の取り消しはできません。
- **後で行う**: **左にスワイプ**するか「後で行う」をタップすると、タスクが「今日の後で」に移ります。後回しにしたタスクは未実施として数えられません。「今すぐ行う」をタップすると元に戻ります。後回しにしたタスクを完了すると、後回しの状態は自動的に解除されます。
- 15歳以上のお子さまは、習慣を完了した後に「今回はどのようにできましたか？」（自分で、声かけがあって、一緒に）を選択するか、スキップできます。[お子さまの実施方法の記録](03-hom-nay-va-duyet-viec.md#muc-ho-tro)をご覧ください。習慣として定着した場合は、スターだけでなく言葉で認めるメッセージが表示されます。

<a id="chi-tiet"></a>
### 詳細、タイマー、読み上げ

<a id="dem-gio"></a>
- **タスクの詳細**: タスクをタップすると、完了にする前に「意味」と「やり方」（設定されている場合は所要時間）を確認できます。
- **タイマー**: 制限時間のあるタスク（たとえば2分間の歯みがき）には、**開始**、**一時停止**、**リセット**、**時間完了**ボタンがあります。
<a id="doc-to"></a>
- **読み上げ**: 端末が対応している場合、スピーカーボタンで端末の音声を使ってタスクの内容を読み上げます。
- **音声**: ボタンで音声をオンまたはオフにできます。20:00から翌朝07:00前までは音量が半分になります。
- **文字サイズとフォント**: 「テキストとフォントサイズの設定」ウィンドウで調整できます（[画面設定](05-gia-dinh-va-cai-dat.md#giao-dien)）。

<a id="sao-cap-chuoi"></a>
## スター、レベル、連続記録

- **スター**はごほうびポイントです。各タスクで設定した数のスターを獲得します。スターはごほうびや街づくりに使えますが、**獲得したスターの合計**は減りません。
- **レベル**はスターを100個獲得するごとに上がります。100個未満はレベル1、100個以上はレベル2となり、以降も同様です。
- **連続記録**（炎）は、確認済みのタスクを連日完了した日数です。今日まだ何もしていない場合、昨日までの連続記録はその日の終わりまで維持され（炎は「休憩中」に変わります）。さらに1日空くと連続記録は0に戻り、数え直しになります。家族の[休憩日](#tam-nghi-be)は連続記録を途切れさせず、日数にも加算されません。
- **リーグランク**は獲得スターの合計に基づきます。ブロンズ、シルバー（70以上）、ゴールド（150以上）、ダイヤモンド（300以上）が[ランキング](#bang-xep-hang)に表示されます。

スターと連続記録は意欲を高めるためのものです。性格を評価したり、お子さま同士を比較したりするためには使いません（[原則](06-khoa-hoc-thoi-quen.md#nguyen-tac)）。

<a id="huy-hieu"></a>
## バッジ

**バッジ**タブには、獲得済みと未獲得のバッジが進捗とともに表示されます。2種類あります。

- **基本バッジ5つ**: 緑のスタート（最初のタスク）、3日連続の炎、7日間の戦士、よい行いのスーパーヒーロー（20タスク）、スター100個の王冠。
- **肖像バッジ16個**: お子さまが肖像に関連する[習慣の枠組み](06-khoa-hoc-thoi-quen.md#chan-dung)のタスクを一定数完了すると、その肖像が解除されます。16番目の肖像「頂点」は、ほかの肖像をすべて獲得すると解除されます。

新しいバッジを獲得すると、お祝い画面が表示されます。お子さまの氏名や写真を含めずに、家族の節目を共有することもできます（[節目を共有](03-hom-nay-va-duyet-viec.md#thong-ke)）。

<a id="qua"></a>
## ごほうび

お子さまは**ごほうびと交換**タブでスターを使います。[ごほうびストア](04-thiet-ke-thoi-quen.md#kho-qua)で保護者がごほうびを作成します。

1. **ごほうびの目標**: アイテムの「目標に設定」をタップすると、必要なスター数を確認できます。目標は「夢のごほうびの目標」に保存されます。この時点ではまだごほうびのリクエストではありません。
2. **ごほうびをリクエスト**: 「このごほうびと交換」をタップします。スターは**すぐに差し引かれ**、保護者にリクエストが送信されます（「ごほうびの交換リクエストを保護者に送信しました！」）。スターが不足している場合は「交換に必要なスターが足りません」と表示され、在庫切れのごほうびとは交換できません。
3. **保護者の承認**: リクエストは[今日](03-hom-nay-va-duyet-viec.md#duyet)に表示されます。保護者が**承認**してから**ごほうびを渡します**。**却下**すると、スターはお子さまに返却されます。
4. お子さまの**ごほうびストア**には、各アイテムの状態（承認待ち、承認済み、ごほうびを受け取り済み）が表示されます。

<a id="bang-xep-hang"></a>
## ランキング

ランキングには3つの範囲と3つの期間があります。

| 範囲 | 閲覧できる人 | 条件 |
|---|---|---|
| **家族** | 同じ世帯のお子さま | なし |
| **グループ／クラン** | グループのメンバー | お子さまがグループを作成または参加している |
| **全体** | 保護者が共有を許可したお子さま | 家族アカウントが接続されていること。保護者が[共有を有効にし](05-gia-dinh-va-cai-dat.md#rieng-tu)、お子さまを選択すること。初期設定は**オフ**です |

期間は、今日、今週、今月です。順位のスコアは**期間中に獲得したスター**です。ごほうびにスターを使っても順位は変わりません。

- **グループ**: グループ名、ごほうび、グループ全体の週間スター目標を設定して作成します。システムが**6文字の招待コード**を発行します。招待コードを入力して参加することもできます。グループのメンバーは「ハイタッチ」で応援を送れます。
- 公開ランキングに表示されるのは、**ニックネーム**（設定されていない場合は「スーパーベビー」）、アバター、期間内のポイント、連続記録、順位のみです。本名、年齢、コードは表示されません（[プライバシー](09-bao-mat-va-rieng-tu.md#bxh-cong-khai)）。
- 家族が休憩中の場合、ランキングタブはお子さまの画面で非表示になります。

<a id="linh-vat"></a>
## マスコットと色

マスコットは6種類です。**Leo**（ライオン。小さなタスクを通じて勇気を練習）、**Bunny**（ウサギ。人への思いやり）、**Panda**（パンダ。落ち着いて物事をよく見る）、**Fox**（キツネ。新しいことへの好奇心）、**Turtle**（カメ。お子さまと一緒にゆっくり進む）、**Bee**（ミツバチ。家族みんなで助け合う喜び）。お子さまがマスコットを変更できるのは**7日に1回まで**です。次に変更できる日時は画面に表示されます。**メインカラー**はいつでも変更できます。[プロフィール](05-gia-dinh-va-cai-dat.md#ho-so)の作成時にマスコットを選ぶこともできます。

<a id="thu-buoi-sang"></a>
## 朝のお手紙

端末のタイムゾーンで**07:00以降**、マスコットから毎日新しいお手紙が届きます（導入、やさしいメッセージ、締めくくり）。お子さまが「読みました」をタップすると、その日のうちに何度でも読み返せます。既読状態は、お子さまが使うほかの端末にも同期されます。この機能は**オン**です。

<a id="nhat-ky"></a>
## 1文日記

「覚えておきたいこと」カードに、お子さまは学んだこと、うまくできたこと、明日もう一度試したいことについて**1文**（改行なし、最大280文字）を書き、「日記を保存」をタップします。閲覧できるのはお子さまと保護者のみです。内容が**測定に使われることはありません**。[統計](03-hom-nay-va-duyet-viec.md#thong-ke)で読み返したり、CSVをエクスポートしたりできます。この機能は**オン**です。

<a id="thanh-pho"></a>
## 夢の街

お子さまはスターを使って4つの建物を作ります。**緑の庭園**（30スター）、**図書館**（60）、**つながりの橋**（90）、**天文台**（120）。建てた建物はずっと残ります。獲得スターの合計は差し引かれないため、進捗や到達したレベルが失われることはありません。スターが足りない場合は「ポイントが足りません」と表示されます。この機能は**オン**です。

<a id="giao-dien-tuoi"></a>
## 年齢に合わせた画面

お子さまの画面は、**3～8歳**、**9～12歳**、**13歳以上**の3つの年齢層に合わせて自動調整されます。低年齢向けはボタンが大きく、マスコットが目立つ表示になり、年齢が上がるほど簡潔になります。13歳以上では「スター」の代わりに「ポイント」を使い、「小さなお子さま」とは呼びません。3歳未満のお子さまは保護者がサポートするため、画面は変わりません。

- 画面が初めて切り替わる際、お子さまは「以前の表示を続ける」または「新しい表示を使う」を選び、「すっきり」または「仲間と一緒」のスタイルを選択できます。
- [お子さまのプロフィールを編集](05-gia-dinh-va-cai-dat.md#ho-so)するときに、年齢層を**固定**したり以前の表示を維持したりできます。この選択はお子さまの端末での選択より優先されます。

<a id="tam-nghi-be"></a>
## 家族の休憩

[休憩を取る](05-gia-dinh-va-cai-dat.md#tam-nghi)をタップすると、お子さまの画面に「今日は家族で休憩します。やりたくなったら、よい習慣を続けても大丈夫です。」と表示されます。お子さまは引き続きタスクを行えます。スター、ごほうび、連続記録は削除されません。進捗リマインダーとランキングは非表示になります。

<a id="tu-lap"></a>
## 練習中のこと、リズム、できること

この機能は段階的に有効化されています。アプリに表示されていない場合は、まだお使いのバージョンには反映されていません。

- **リズム**: お子さまの画面上部に「今週はN/7日」と表示されます（過去7日間のうち、少なくとも1つのタスクを行った日数。家族が休憩した日は数えません）。連続記録は横に小さく表示されます（幅の広い画面のみ）。連続記録が0になると、「新しい一日、続けていきましょう！」と表示され、責める言葉は表示されません。
- **練習中のこと**: 定着または習慣づくりに取り組んでいる習慣を1～2個、短く表示します。何に意識を向けるかがわかるようにするためです。習慣はアプリが選ぶため、お子さまが選ぶ必要はありません。
- **今週の目標**（6歳以上）: お子さまが選べるタスクを[いくつか設定](03-hom-nay-va-duyet-viec.md#muc-tieu-tuan)している場合、週の初めに1～2個を目標として選び、7日間の進捗を確認できます。
- **応援メッセージ**: 初めて1人で習慣を行ったとき、3回または7回連続で行ったとき、またはリマインダーなしで2週間続けたとき（実施方法が記録された場合のみ）、状況に合わせたメッセージが1回表示されます。確認ボタンを押してください。スターは追加されません。
- **できること**: [卒業した](03-hom-nay-va-duyet-viec.md#tot-nghiep)習慣を閲覧専用の一覧で表示します。習慣を卒業した直後には、お子さまに応援メッセージも表示されます。
