## 原則

1. **「21日」という決まった日数はありません。** 行動がほぼ自動的になるまでの時間は人によって大きく異なり、数週間から数か月かかることがあります。主に成人を対象に測定されています。アプリは、決まった日数で習慣が身につくとは約束しません。
2. **意志の力より、きっかけが大切です。** 「歯をみがいたら、本を1ページ読む」のような具体的な「もし…なら…」の計画と安定した状況があると、お子さまは始めやすくなります（[きっかけ](04-thiet-ke-thoi-quen.md#chuong-trinh)）。
3. **1回できなくても習慣が台無しになるわけではありません。** 罰を与えたり最初からやり直したりせず、翌日に続けます。何度か続けてできなかった場合は方法を調整する目安であり、お子さまが「怠け者」という意味ではありません。
4. **適切なサポートを行い、徐々に減らします**: 一緒に行う → 声をかける → お子さま1人で行う。
5. **条件付きのごほうびより、具体的に認める方が効果的です。** お子さまが今したことを具体的に伝え、物のごほうびは控えめにして徐々に減らします。スター、連続記録、バッジは意欲を高めるためだけのもので、性格を評価したりお子さま同士を比較したり**しません**。
6. **一度に新しい習慣を増やしすぎないでください。** アプリが年齢に応じた注意を表示するのは設計上の目安で、科学的根拠から直接導かれた数値ではありません。
7. **睡眠はほかの習慣の土台です。**

根拠文書にある具体的なしきい値（7回中／10回中、8回中／10回中、60%など）は確度が**低く**、実際のデータで検証が必要な仮説であり、科学的事実ではありません。

## 47の習慣の枠組み

この枠組みは、**0～18歳向けの47の習慣**を、2つの軸に沿って整理したものです。

**5つの段階**（年齢は目安であり、テストではありません）:

| 段階 | 年齢 | 名称 | 大人の役割 |
|---|---|---|---|
| GD1 | 0～3歳 | 安心と感覚の土台 | 手本を示し、説明する |
| GD2 | 3～6歳 | 探索と意志 | 一緒に行い、声をかける |
| GD3 | 6～12歳 | 勤勉さとスキル | 見守り、一緒に行う |
| GD4 | 12～15歳 | 自分らしさと感情 | 支え、共通のルールを一緒に守る |
| GD5 | 15～18歳 | 方向性と責任 | 助言し、支える |

**5つの領域**: 内面、健康、人間関係、学習、金融。

各習慣には、**お子さまにとっての意味**、**大人が支援する方法**、進捗の目安、概念タグ（強み、与える行い）が含まれます。お子さまのプロフィールでは、最初の習慣パックと画面に**4つの年齢層**（0～3、3～6、6～12、12～18歳）を使います。[ロードマップ](04-thiet-ke-thoi-quen.md#lo-trinh)と[ライブラリ](04-thiet-ke-thoi-quen.md#khung-47)では上記の5段階を使います。データと編集手順は[習慣の枠組みデータ仕様](../habit-framework-data-contract.md)をご覧ください。

この枠組みは、アプリ内の[ライブラリ](04-thiet-ke-thoi-quen.md#khung-47)とウェブサイトの[習慣の枠組みページ](11-website-va-trang-cong-khai.md#trang-khung)で利用できます。

## 16の強みと与える7つの行い

**16の強み**は、子どもに貼る性格ラベルではなく、*成長の方向性*を示すものです。学びの知恵、穏やかな喜び、豊かな人格、卓越性、優れた能力、調和のとれた体、強い健康、卓越した提唱力、賢明なコミュニケーション、自制心、明確なビジョン、人生への理解、思いやりをもって導くこと、徳を行動に移すこと、豊かさと幸運、そして**人としての成功**（16番目の強みであり全体の目標）です。人格、徳、能力、ビジョンの4グループに分かれます。

- 各強みは、関連する行動を必要な回数完了すると獲得できる[バッジ](02-man-hinh-be.md#huy-hieu)です。16番目の強みは、ほかのすべてを獲得すると解除されます。

**与える7つの行い**は、誰もが毎日できる7つの簡単な行いです。**笑顔**（顔で与える）、**温かいまなざし**（目で与える）、**思いやりのある言葉**（言葉で与える）、**感謝**（心で与える）、**許すこと**（広い心で与える）、**親切な行動**（行動で与える）、**相手に場所を譲ること**（場所で与える）。アプリは日常的な言葉を使い、徳や精神的な成果を約束しません。

上部バーの**16の強みと与える行いのガイド**には、3つのタブがあります。

1. **16の強みと4段階**: お子さまの年齢を選び、各強みに対応する行動の詳細を確認してから、**「（名前）に適用」**を選ぶと、その行動セットをスケジュールに追加できます。
2. **与える7つの行い**: それぞれの意味と毎日の実践方法。
3. **手本を示すことと6つの原則**: *手本を示す*ことの大切さ（「価値を説明するだけでなく、お子さまに学んでほしいことを自ら実践する」）、**思慮深い子育ての6つの大切な言葉**（簡潔に、楽しく、信頼して、やさしく、一貫して、意図をもって）、**寝る前の5つの質問による振り返り**（2分ほどで行います）。

**0～3歳**の子どもは主に観察から学ぶため、画面に「保護者の手本日記」が表示されます。保護者がお子さまの手本となるために16の人格形成行動を毎日実践して記録します。この記録は保護者のものとして扱われ、お子さまへのごほうびにはなりません。

<a id="bon-pha"></a>
## 習慣の4段階

お子さまの習慣は4段階を進みます。段階は日数ではなく、**お子さまが実際に行ったこと**で決まります。

| 段階 | 主な課題 | 大人がすること |
|---|---|---|
| 1. **きっかけを設定する**（きっかけの設定） | 状況と「もし…なら…」の計画を選ぶ | 一緒に決めて記録する |
| 2. **ルーティンを作る** | 同じ状況で定期的に繰り返す | 一緒に行う、声をかける、具体的にほめる |
| 3. **サポートを減らす** | 一緒に行う段階から声かけ、さらに自分で行う段階へ進む | 一段階ずつ徐々にサポートを減らす |
| 4. **習慣として定着** | 確認する頻度を減らす | 言葉で認め、介入を減らす |

段階の移行条件: きっかけの計画があり、お子さまが3回以上試したら1→2。直近10回のうち7回以上完了したら2→3（週単位の習慣は6回中5回）。直近10回のうち**8回以上を自分で行った**ら3→4（週単位は6回中5回）。10回中6回を下回った場合は段階3に戻ります。1回できなかっただけでは段階は変わりません。

<a id="logic"></a>
## アプリ内の提案ロジック

段階と提案は、固定値として保存されるのではなく、観察したデータから**計算**されます。習慣を行う予定の時点は*機会*として扱われ、結果は、1人でできた、声かけが必要だった、一緒に行った、実施方法を記録していない、未実施、またはお子さまが後で行うことを選択（未実施には数えない）のいずれかです。家族の[休憩](05-gia-dinh-va-cai-dat.md#tam-nghi)は機会から除外されます。「実施方法を記録していない」場合は完了として数えますが、**1人でできたとは数えません**。[お子さまの実施方法の記録](03-hom-nay-va-duyet-viec.md#muc-ho-tro)により、提案の精度が高まります。

3つの難易度（簡単、中程度、複雑）は、「通常は数週間／数週間から数か月／数か月かかる」という表示と、「停滞している可能性」の提案しきい値にのみ使われます。6歳未満では1.5倍します。サポート段階の確認者は年齢によって異なります。0～3歳は保護者、3～12歳は保護者が確認、12～15歳は保護者が確認してお子さまが設計を支援、15歳以上はお子さま自身が自立して行えたかを確認します。

<a id="goi-y"></a>
### 提案ルール

| 提案 | 表示される条件 | 内容 |
|---|---|---|
| **習慣づくりの段階で停滞** | 段階2にいる週数が難易度別のしきい値を超えた | より小さくする、きっかけや時間を変える、週末や忙しい日の計画を加える |
| **声かけに頼っている** | 段階3で、直近10回中6回以上が「声かけが必要」 | 視覚的なきっかけにするか、お子さま自身にリマインダーを設定してもらう |
| **新しい習慣が多すぎる** | 段階1～2の習慣数が年齢別上限を超える | 習慣を1つ一時停止する |
| **習慣として定着しそう** | 段階4に進むしきい値に達した | 言葉でほめるようにし、スターを徐々に減らす |
| **1段階戻る** | 段階3で直近5回中3回未実施 | 前のサポート段階に戻す |
| **実施方法を確認する** | 段階2で3回連続して未実施 | きっかけ、大きさ、週末の計画を見直す |
| **お子さまの実施方法を記録する** | 最近の実施の半数超で方法が未記録で、段階移行のしきい値に近い | 「どうやってできたの？」とやさしく尋ねる |

一度に取り組む新しい習慣の上限（制限ではなく注意表示）は、0～3歳: 1、3～6歳: 2、6～15歳: 3、15歳以上: 4です。一度に表示される提案は各お子さまにつき最大3件で、「後で」にした提案は14日間非表示になります。この分析は**保護者への案内にのみ使われ**、お子さまの順位付けや比較には使いません。

<a id="khong-tuyen-bo"></a>
## アプリが主張しないこと

- 習慣が決まった日数で身につくとは述べず、特定のお子さまの学習や行動が改善すると約束しません。
- バッジ、連続記録、スターが意欲を高めると「証明されている」とは述べません。
- お子さまに「遅い」「弱い」「怠けている」などのレッテルを貼ったり、比較したりしません。
- 健康に関する内容は、医師や心理士の助言に代わるものではありません。
- 枠組みの哲学的な内容は日常的な言葉で表現し、科学的な結論として提示しません。
