**設計**エリア（`Design`）には、習慣、年齢別ロードマップ、ごほうびの3つのセクションがあります。利用にはプランまたは有効なトライアルが必要です（[7](07-goi-va-thanh-toan.md)）。

<a id="quan-ly-viec"></a>
## 習慣の管理

`Design → Habits`には3つの表示があります。

| 表示 | 用途 |
|---|---|
| **使用中** | 割り当て済みの習慣を確認し、お子さままたは「すべてのお子さま」で絞り込み、過去7日間の完了状況を確認し、編集・削除・きっかけを設定します |
| **ライブラリ** | テンプレートライブラリから習慣を選びます（[ライブラリ](#thu-vien)） |
| **プログラム** | 段階的に取り組む習慣のまとまりを開始します（[プログラム](#chuong-trinh)。ベトナム語のみ表示） |

各習慣は、**1人のお子さま**または**家族全体**へのカードとして表示されます（「割り当て先」）。一時停止した習慣は保存されますが、[お子さまの画面](02-man-hinh-be.md#nhiem-vu)には表示されません。

<a id="tao-viec"></a>
## 習慣の作成・編集

「新しい習慣を作成」ボタンからフォームを開きます。

| 項目 | 内容 |
|---|---|
| 習慣のタイトル | 例:「食事の前に手を洗う」 |
| 説明と目的 | お子さまが[タスクの詳細](02-man-hinh-be.md#chi-tiet)の「大切な理由」で読む内容 |
| アイコン | 習慣を表す小さな画像 |
| 発達カテゴリー | 健康的な食事、よい行い、セルフケア、学習、健康、徳、考え方など |
| ごほうびのスター | 習慣を完了したときにお子さまが受け取るスター数 |
| 繰り返し | 毎日、月～金、土・日、または曜日を指定 |
| 時間帯 | 朝、午後、夕方、いつでも |
| タイマーのカウントダウン | [タイマー](02-man-hinh-be.md#dem-gio)の分数。0はカウントダウンなし |
| 保護者の承認が必要 | オンにすると、お子さまが完了を記録しても、保護者が[承認](03-hom-nay-va-duyet-viec.md#duyet)するまでスターは付与されません |
| 割り当て先 | すべてのお子さま、または1人のお子さま |

ライブラリやロードマップからテンプレートを適用した後も、家族の生活に合うように時間やスターを調整したり、習慣を追加・削除したりできます。各習慣の完了は、**お子さま1人につき1日1回のみ**記録されます（2度タップしても重複して数えません）。

<a id="thu-vien"></a>
## ライブラリ

ライブラリの内容は、使用中の言語によって異なります。

- **ベトナム語**: [0～18歳向け47の習慣の枠組み](#khung-47)。
- **その他の言語**: 「子どもにおすすめの習慣ライブラリ」。健康的な食事と思いやり、よい行いと与えること、徳、考え方、調和のとれた人格、知恵と学習、能力と自立、身体の活力の8つのグループから提案を選べます。名前と説明はその言語に翻訳されています。「タスクリストに追加」を選ぶとスケジュールに追加されます。

この2つのライブラリに加えて、[お子さま](05-gia-dinh-va-cai-dat.md#ho-so)から**年齢別習慣パック**（最初の6つの習慣）を読み込むか、[年齢別ロードマップ](#lo-trinh)を適用できます。

<a id="khung-47"></a>
## 0～18歳向け47の習慣の枠組み

ベトナム語のライブラリには**習慣の枠組み**があります（[6の枠組みの説明](06-khoa-hoc-thoi-quen.md#khung)）。使い方は次のとおりです。

1. **発達段階**（5段階）と習慣の**領域**（内面、健康、人間関係、学習、お金、または「すべて」）を選択します。
2. 各カードには、推奨年齢、**進捗の目安**、大人が担う役割、お子さまが自分で記録する方法が表示されます。**「やり方とサポート方法を見る」**ボタンもあります。年齢は目安として、お子さまの実際の力に合わせて調整してください。
3. **「タスクリストに追加」**をタップすると、カードは「家族に追加済み」に変わります。枠組みから追加した習慣は**家族全体に共有**されます。特定のお子さまに割り当てるには、「割り当て先」を編集する（[習慣の作成・編集](#tao-viec)）か、適用時にお子さまを選べる[プログラム](#chuong-trinh)または[年齢別ロードマップ](#lo-trinh)を使います。カードには過去7日間の完了数も表示されます。

枠組みから追加した習慣は、元の習慣（枠組みコード）へのリンクを保持します。お子さまが完了すると、アプリは[16の肖像バッジ](02-man-hinh-be.md#huy-hieu)と[プログラム](#chuong-trinh)の進捗を記録します。健康に関する内容は参考情報であり、専門家の助言に代わるものではありません。枠組みは英語、韓国語、フランス語、ドイツ語、イタリア語、スペイン語、中国語、日本語で利用できます。翻訳のない言語では英語版が表示されます。

<a id="chuong-trinh"></a>
## プログラムときっかけ

現在有効な**適応型習慣プログラム**では、一度に多くの習慣を割り当てず、段階的に身につけることを支援します。

**「もし…なら…」のきっかけ**: 各習慣に、お子さま自身の言葉で計画を設定できます。例:「歯をみがいたら、本を1ページ読む」。

- 使用中の習慣カードの**きっかけ**ボタンでフォームが開きます。きっかけの種類（**なじみのある行動の後**または**決まった時間に**）、お子さまの言葉での計画、時間帯、実施場所（任意）、週末や忙しい日の計画（任意）、対象のお子さまを設定します。きっかけを設定したカードには「きっかけ設定済み」と表示されます。
- きっかけのテンプレートは5種類です: 起床後、朝食後、学校から帰宅後、夕食後、夜の歯みがき後。

**プログラムの開始**（プログラム表示、ベトナム語のみ）: アプリがお子さまごとに習慣のまとまりを提案し、3つのステップを案内します。

1. **最初に取り組む習慣を選ぶ**: 通常は1つか2つなど、少数から始めます。[年齢別の推奨上限](03-hom-nay-va-duyet-viec.md#hom-nay)まで選べます。上限を超えると警告が出ますが、続けることもできます。
2. 各習慣にテンプレートまたは自分の言葉で**きっかけを設定**します。
3. **確認**: 習慣をお子さまに追加し、きっかけを保存します。完了すると「使用中」表示に戻ります。

きっかけを設定すると、アプリは各習慣の**段階**（きっかけの設定、ルーティンづくり、サポートを減らす、定着）を追跡し、[お子さまの実施方法](03-hom-nay-va-duyet-viec.md#muc-ho-tro)を記録して、「今日」に[調整の提案](03-hom-nay-va-duyet-viec.md#tien-trien)を表示します。詳しいロジックは[6](06-khoa-hoc-thoi-quen.md#logic)をご覧ください。

<a id="lo-trinh"></a>
## 年齢別ロードマップ

`Design → Age Roadmaps`は、習慣研究で万人共通の日数が定められていないことから、以前使われていた固定の週間・月間ロードマップに代わるものです。

- **5つの年齢段階**: 0～3歳「安心と感覚」、3～6歳「探索と意志」、6～12歳「勤勉さとスキル」、12～15歳「自分らしさと感情」、15～18歳「方向性と責任」。各段階では、大人の役割として手本を示す、一緒に行う、見守る、支援する、助言することを提案します。
- 各段階は約**12週間**で、**3つのステップ**があります。**各ステップで追加する新しい習慣は1つだけ**で、前の習慣は続けます。週の表示は振り返りの目安であり、**期限ではありません**。お子さまに合う期間だけ、各ステップに取り組んでください。
- アプリは選択したお子さまの年齢をもとに段階を選びますが、別の段階に切り替えることもできます。各ステップに割り当て済み・実施済みの習慣数と現在のステップが表示されます。
- ステップをタップして**詳細を表示**し、「どのお子さまに適用しますか？」を選んでから、**確認して適用**をタップします。習慣はお子さまの日々のスケジュールに追加され、割り当て済みの習慣が重複することはありません。

ベトナム語版のタブには、このロードマップが提案するのは**習慣を追加する順番**のみで、[プログラム](#chuong-trinh)はお子さまそれぞれのペースに合わせることも記載されています。

<a id="kho-qua"></a>
## ごほうびストア

`Design → Rewards`で、保護者はお子さまがスターと交換できるごほうびを作成します（[お子さまのごほうび交換](02-man-hinh-be.md#qua)）。

- **ごほうびを作成**: ごほうびの名前、必要なスター数（5個以上）、説明または条件を設定します。ここで作成したごほうびには交換回数の上限はありません。編集や削除もできます。
- **意味のあるごほうびのアイデア**: テンプレートライブラリには、**体験**（一緒に過ごす時間、体験、選ぶ権利）と**目的のある品物**（趣味、運動、学習、与える心を支えるもの）の2種類があり、推奨スター数も表示されます。「ごほうびに追加」を選びます。
- お子さまからのリクエストは[今日 → 承認](03-hom-nay-va-duyet-viec.md#duyet)に表示されます。

アプリでは物より、一緒に過ごす時間や体験を優先することをおすすめしています（[認めることの原則](06-khoa-hoc-thoi-quen.md#nguyen-tac)）。

## 各機能のつながり

```
47の習慣の枠組み ──追加──▶ 使用中の習慣 ◀──適用── 年齢別ロードマップ
        │                         │  ▲                      （年齢別パック）
        │ 枠組みコード            │  └─ 習慣を自分で作成
        ▼                         ▼
 16の肖像バッジ          きっかけ + プログラム ──▶ 段階、提案（今日）
                                  │
                                  ▼
                         お子さまが完了を記録 ─▶ 承認 ─▶ スター ─▶ ごほうび（ごほうびストア）
```

アプリ全体のマップは[12](12-ban-do-lien-ket.md#ban-do)をご覧ください。
