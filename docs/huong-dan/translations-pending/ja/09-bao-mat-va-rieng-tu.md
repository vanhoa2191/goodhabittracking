このページでは、KidHabitがお子さまのデータを安全に保つために行っていることを、わかりやすく説明します。技術的な詳細は[セキュリティとプライバシー](../security-privacy.md)をご覧ください。

<a id="du-lieu"></a>
## 保存されるデータ

アプリは、お子さまのプロフィール（氏名、ニックネーム、年齢）、習慣、進捗、ポイント、ごほうび、ペアリング済み端末、サブスクリプションプラン、および保護者の連絡先（氏名、電話番号、メールアドレス）を保存します。任意機能には、1文日記、きっかけの計画、お子さまが各回をどのように完了したか、ウィッシュリストが含まれる場合もあります。お子さまのデータ、セッションコード、PIN、PayOSキー、Webhookの内容を分析システムに送信することは**ありません**。

<a id="ai-thay"></a>
## 閲覧できる人と情報

| 閲覧する人 | 閲覧できる情報 | 閲覧できない情報 |
|---|---|---|
| 保護者 | 自分の家族に属するすべてのデータ | ほかの家族のデータ |
| ケア担当者 | 読み取り専用で、お子さまの氏名、実施中の習慣（繰り返しスケジュールを含む）、完了または承認済みの実施回数、直近7日間の日ごとの件数 | 変更はできません。個々の実施記録、時間帯、メモ、年齢、ニックネーム、ごほうび、グループ、サブスクリプション、支払い、設定、ほかのメンバーは確認できません |
| お子さま（ペアリング済み端末） | 自分のデータ | ほかのお子さまのプロフィール、支払い、設定、PIN |
| 運用担当者 | 保護者のプロフィール（氏名、メールアドレス、電話番号）、サブスクリプションプラン、注文。すべての操作が記録されます | お子さまのプロフィール、タスク、日記 |

データベースでは家族ごとに独立した「区画」に分けられています。アプリの画面に不具合があっても、あるアカウントが別の家族のデータを読み書きすることはできません。すべてのデータは`family_id`に属し、プランや特典はメールアドレスではなく家族に紐づきます。

<a id="ma-ghep"></a>
## お子さまのペアリングコード

- 各コードで開けるのは**特定のお子さまのプロフィール1つのみ**です。PINや家族データは含まれません。データベースにはコードのハッシュのみが保存されます。
- お子さまの端末セッションはHTTP専用Cookieに保存されるため、ページのスクリプトから読み取れません。各リクエストで取得できるのは1人のお子さまのデータだけです。
- コードの入力を何度も間違えると、**レート制限**が適用されます。
- 保護者はいつでも**コードを更新**（古いコードは無効になります）したり、個々の端末の連携を**解除**したりできます（[5](05-gia-dinh-va-cai-dat.md#ghep-thiet-bi)）。コードの表示、変更、解除にはPINが必要です。

<a id="pin"></a>
## PIN

4桁のPINは**サーバー**で確認されます。正しいPINを入力すると、ブラウザーに保護者と家族に紐づいた署名付きのロック解除Cookieが発行されます。有効期間は**2時間**で、再度ロックすると削除されます。PINを設定した家族では、ロック解除するまで機密性の高い操作を実行できません。対象の操作は、家族の削除、端末の連携解除、ペアリングコードの表示または変更、支払いの作成、タスクやごほうびの承認、スターの手動追加または差し引き、紹介プログラムの出金情報の表示です。保護者の端末では、お子さまはPINを入力せずにタップしてタスクを完了できます。PINの設定方法は[5](05-gia-dinh-va-cai-dat.md#pin)をご覧ください。

<a id="dong-thuan"></a>
## 同意

- [家族の設定](01-bat-dau.md#thiet-lap)時に、大人はお子さまの親または法定後見人であることを確認し、お子さまのデータ保存に同意する必要があります。同意は**ポリシーのバージョン**とともに保存されます。
- 公開ランキング、匿名分析、リマインダー、販促案内はすべて**任意**で、**初期設定ではオフ**です。後からオフにすることもできます。同意を撤回した記録は削除せず、タイムスタンプとして保持します。
- ケア担当者が家族に入るには、保護者が作成した1回限りの招待（72時間で期限切れ）が必要です。招待は取り消せます（[5](05-gia-dinh-va-cai-dat.md#nguoi-cham-soc)）。

<a id="bxh-cong-khai"></a>
## 公開ランキング

お子さまが公開ランキングに表示されるのは、次の**両方**の条件を満たす場合のみです。家族が共有を有効にしていること（初期設定ではオフで、保護者のみ変更可能）、およびお子さまのプロフィールが参加対象に設定されていること（新しいプロフィールは初期設定で非公開）。ランキングに表示されるのはニックネーム（または「スーパーベビー」）、アバター、期間内に獲得したポイント、連続記録、順位のみです。お子さまのコード、家族コード、本名、年齢は表示されません。ポイントは現在の残高ではなく、期間内に確認された記録から算出されるため、スターをごほうびに使っても順位は変わりません。家族ランキングとグループランキングには、それぞれの範囲内のデータのみが使われます。設定は[5](05-gia-dinh-va-cai-dat.md#rieng-tu)、お子さま側の表示は[2](02-man-hinh-be.md#bang-xep-hang)をご覧ください。

<a id="chia-se"></a>
## 節目の共有

「前向きな節目を共有する」（[3](03-hom-nay-va-duyet-viec.md#thong-ke)）では、共有パネルを開く前に、必ず保護者に**プレビューと確認の機会**が表示されます。初期設定では、お子さまの氏名、年齢、写真、タスク、追跡コードは内容に含まれません。

<a id="gioi-thieu-rieng-tu"></a>
## 紹介プログラム

紹介コードは`kidhabit_ref` Cookieに60日間保存され、紹介の記録後に削除されます。紹介者の銀行情報を閲覧できるのは、権限を持つ管理者のみです。紹介者に表示されるのは口座番号の末尾4桁だけです。紹介者が紹介先の家族の情報を見ることは**ありません**（[8](08-gioi-thieu-ban-be.md)）。

<a id="goi-y-ai"></a>
## AIによる提案

この機能は段階的に有効化されており、初期設定では**オフ**です。`Settings → Privacy`の**AIによる提案**カードで同意すると表示されます。提案ボタンをタップすると、アプリがAIモデル（Cloudflare Workers AI）に下書きを依頼します。

- **AIで小さなステップを提案**（習慣フォーム）: **入力したばかりの習慣名のみ**（リンク、メールアドレス、電話番号を除去）と年齢層が送信されます。
- **AIで週を要約**: **今週の件数のみ**（1人で完了、声かけあり、一緒に、未完了）が送信されます。習慣名とお子さまの名前は含まれません。

**送信されない情報**: お子さまの氏名やニックネーム、日記、お子さまが書いた内容、写真、お客様のメールアドレス。送信内容と受信内容がシステムログに記録されることは**ありません**。結果は「AIが作成した下書き」と表示される提案のみです。内容を確認して**使用**または**閉じる**を選択してください。アプリが自動で適用することはありません。家族ごとに1日の提案数に上限があり、共有枠を使い切ると機能は一時停止します。ほかの機密性の高い操作と同様、PINが必要です。設定をオフにすると直ちに停止します。

<a id="do-luong"></a>
## 分析とリマインダー

- **匿名分析**には厳格な制限があります。イベントには氏名、習慣の内容、お子さま・家族・ユーザーのコード、ペアリングコード、支払い情報、正確なタイムスタンプは含まれません。現在、データの送信先は設定されていないため、保護者が同意しても端末外に情報が送られることはありません。実際に測定していない指標（DAU、継続率、NPSなど）を公表することもありません。[プロダクト分析](../product-analytics.md)をご覧ください。
- **リマインダー**は、承認が必要なタスクを保護者に知らせるためだけに使われ、広告には使われません。
- お子さまが各回をどのように完了したかのデータときっかけの計画は、**保護者への提案にのみ使用**します。お子さまの順位付けや比較には使用しません（[6](06-khoa-hoc-thoi-quen.md#logic)）。

<a id="xoa-du-lieu"></a>
## データのダウンロードと削除

- **ダウンロード**: 家族データのJSONコピー（[5](05-gia-dinh-va-cai-dat.md#du-lieu)）と、1文日記のCSV（[3](03-hom-nay-va-duyet-viec.md#thong-ke)）を取得できます。お子さまのデータが含まれるため、ファイルは安全に保管してください。
- **完全削除**: `Today → Analytics`から、**家族の所有者のみ**が実行できます。`DELETE FAMILY`を正確に入力してください（PINを設定している場合はPINが必要です）。お子さまのプロフィール、習慣、進捗、ごほうび、ペアリング済み端末、端末セッションが削除されます。元には戻せません。ログインアカウントを復元しても、削除したデータは復元されません（[データ復旧](../data-recovery.md)）。

<a id="ky-thuat"></a>
## 技術的な保護対策

| 保護対策 | お客様にとっての意味 |
|---|---|
| 家族ごとの分離とトランザクション内の行レベルロック | 異なる家族のデータが混ざりません |
| Cookieを使った書き込み操作はすべてクロスオリジンリクエストを拒否 | 見知らぬサイトがお客様に代わって操作できません |
| PayOSの「フェイルクローズ」: 署名、金額、内容、注文者、重複処理の確認 | 偽の通知でプランが有効になることはありません |
| トライアルの1回限りの制限とデータベースでのプラン確認 | 画面を変更して制限を回避することはできません |
| コンテンツセキュリティポリシー（CSP）、フレーム保護、最小限のブラウザー権限 | 悪意のあるコードによるリスクを軽減します |
| 機密性の高い処理はサーバーのみで実行し、新しい処理は初期設定で無効 | 悪用される範囲を抑えます |
| 管理者には2段階認証が必要で、すべての操作は理由とともに記録 | 追跡と管理が可能です |

<a id="phap-ly"></a>
## 法的な制限

お子さまのデータについて、初期設定は**慎重な方針**で設計されていますが、COPPAまたはGDPR-Kへの準拠を**認証するものではありません**。特定の市場で公開ランキングを有効にする前に、同意年齢、保存期間、アクセス権、削除権を含む法的確認を受けてください。[ウェブサイト](11-website-va-trang-cong-khai.md#phap-ly-web)の`Privacy`、`Terms`、`Contact`ページは、法的承認フラグが有効になるまで下書きのまま（インデックス登録されず、フッターやチェックアウトにも表示されない場合があります）です。インシデントを報告する際は、公開チャンネルで秘密情報やお子さまのデータを送信しないでください。
