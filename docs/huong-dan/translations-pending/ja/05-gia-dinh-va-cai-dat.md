**家族**エリアには、`Family → Child profiles`と`Family → Settings`の2つのセクションがあります。

<a id="ho-so"></a>
## お子さまのプロフィール

お子さまごとに個別のプロフィールがあり、次の情報を設定します。

| 情報 | 備考 |
|---|---|
| 本名 | 保護者向けに使用します。共有を選択しない限り公開されません |
| ニックネーム | ランキングに表示される名前です。空欄の場合、公開ランキングには「スーパーキッズ」と表示されます |
| 年齢（0～18歳） | スライダーで設定すると、説明付きで**段階**（0～3、3～6、6～12、12～18歳）が自動的に決まります。提案、[ステップ](04-thiet-ke-thoi-quen.md#lo-trinh)、[年齢に合わせた画面](02-man-hinh-be.md#giao-dien-tuoi)に反映されます |
| マスコットと色 | 6種類の[マスコット](02-man-hinh-be.md#linh-vat) |
| ランキング | 公開ランキングへの参加と、本名またはニックネームのみの表示を選択します（ニックネームを推奨）。新しいお子さまは初期設定で**非公開**です |
| 年齢別の画面 | プロフィール編集時に、**年齢に合わせて自動**、3～8歳または9～12歳に固定、13歳以上、**現在の画面を維持**を選択できます。保護者の選択は、お子さまの端末での選択より優先されます |

プロフィールカードから保護者ができること:

- お子さまのプロフィールの**追加、編集、削除**。登録できる人数は[プラン](07-goi-va-thanh-toan.md#cac-goi)によります。子ども1人プランでは1人まで、トライアルとファミリープランでは上限はありません。プランの有効期限が切れると、プランなしでは新しいプロフィールを追加できません。
- **年齢別パックを読み込む**（「年齢に合った習慣を6つ自動で追加…」）と、最初の6つのタスクをすぐに設定できます。
- [スターを手動で付与または差し引く](03-hom-nay-va-duyet-viec.md#chinh-sao)。
- スター、レベル、連続記録、ランキングで非表示になっているかを確認できます。
- お子さまの**接続コードとQRコード**を開けます（[下記](#ghep-thiet-bi)）。

<a id="ghep-thiet-bi"></a>
## お子さまの端末をペアリング

お子さまごとに**固定の接続コード1つ**（および対応するQRコード）があります。コードでアクセスできるのはそのお子さまのみで、PINや家族データは含まれません。保護者が更新するまでコードは変わりません。

1. **お子さまのコードを取得**: `Family → Child profiles`でコードをコピーするか、「QRコードを表示」をタップします。PINを設定している場合は[PIN](#pin)が必要です。
2. **お子さまの端末を開く**: アプリを開き、「お子さまの端末ですか？」を開いて「コードを入力またはQRをスキャン」を選びます（または上部バーの「お子さまコード」を選択）。
3. **QRコードをスキャンまたはコードを入力**: 端末が正しいお子さまのプロフィールに自動でサインインします。「接続しました！」と表示されたら、お子さまが「タスクを始める」をタップします。

ペアリング後は、保護者用ダッシュボードや販売ページを表示せず、常に[お子さまの画面](02-man-hinh-be.md)が直接開きます。

- 1人のお子さまのコード（「この子の新しいコードを作成」）または**すべてのお子さま**のコード（「お子さまの新しいコードを作成」）を**更新**できます。古いコードは無効になります。コードが漏れたおそれがある場合にのみ行ってください。PINが必要です。
- カメラが起動しない場合は、カメラの使用を許可する、安全な接続（https）を使う、またはコードを手入力してください。
- コードの入力を何度も間違えると、レート制限が適用されます（[9](09-bao-mat-va-rieng-tu.md#ma-ghep)）。

<a id="thiet-bi"></a>
## 端末の管理

`Settings → Devices & family rhythm → Children's devices`には、ペアリング済み端末、お子さまとの対応、最終アクセス日時、アクセス期限切れの有無が表示されます。端末を紛失した場合や使用しなくなった場合は、すぐに**アクセスを解除**してください（PINが必要）。各端末からアクセスできるプロフィールはお子さま**1人分のみ**です。

<a id="nguoi-cham-soc"></a>
## ケア担当者を招待

進捗を確認したいものの、**変更操作は行わない**祖父母や親族のための機能です。

1. `Settings`で**ケア担当者を招待**をタップします。**1回限り**の招待リンクは作成時にのみ表示され、**72時間で期限切れ**になります。コピーして相手に送ります。
2. 招待された方はリンクを開き、Googleでサインインして承認をタップします。招待の期限切れ、取り消し、または相手のアカウントがすでに別の家族に属している場合、「無効な招待…」と表示されます。
3. **ケア担当者エリア**を開くと、読み取り専用で各お子さまの進捗を確認できます。「今日: x/y件のタスク」（yは繰り返し設定に基づく今日の予定件数。予定がない場合は「今日は予定されたタスクがありません」）、「過去7日間: x/y」、各お子さまの習慣、補足として「累計」の完了数が表示されます。ケア担当者が確認できるのは日ごとの件数のみで、実行したタスク、時刻、メモは表示されません。
4. 保護者は「有効な招待」一覧からいつでも**招待を取り消す**ことができます。

<a id="cai-dat"></a>
## 設定グループ

`Family → Settings`はグループに分かれており、「設定グループ」バーから各セクションに移動できます。

| グループ | 内容 |
|---|---|
| **端末と家族のリズム** | お子さまの端末、アプリのインストール、ケア担当者、[家族の休憩](#tam-nghi) |
| **アカウントと同期** | お客様情報、ギフトコード、家族データ |
| **プライバシーと通知** | 公開ランキング、匿名測定、リマインダー |
| **表示設定** | ライト、ダーク、端末の設定 |
| **保護者エリアの保護** | PIN |
| **特典と紹介** | 紹介コード欄、友だち紹介カード（ページ下部にあり、サインイン時のみ表示） |

アドレスバーには開いているセクションが記憶されます（例: `?section=settings#settings-security`）。再読み込み後も同じセクションが表示され、ブラウザーの「戻る」ボタンで前のセクションに戻れます。このリンクは保護者エリア内のセクションを選ぶだけで、ロックは解除しません。お子さまモードでは`section`部分は無視されます。
ページの下部には「ユーザーガイドを開く」（アプリ内の`/docs`ページ。[アプリ内のヘルプ](01-bat-dau.md#tro-giup)を参照）と、プライバシー、利用規約、サポートへの連絡のリンクがあります（[11](11-website-va-trang-cong-khai.md)）。

<a id="tai-khoan"></a>
## アカウントと同期

- **状態**: 「家族アカウント」、確認済み、「クラウド利用可能」。特別な設定なしで、スマートフォン、タブレット、パソコン間で家族データが自動同期されます。
- **お客様情報**: 氏名、電話番号（9～15桁）、メールアドレス（読み取り専用）、ガイドや特典の受け取り設定。アカウントと支払いのサポートに使われます。
- **クーポンコード**: ギフトコードを入力すると、利用期間が追加されます（[7](07-goi-va-thanh-toan.md#coupon)）。

<a id="rieng-tu"></a>
## プライバシーと通知

- **公開ランキングへの共有**: 家族全体の切り替え設定です。初期設定は**オフ**で、変更できるのは保護者のみです。有効にすると、[プロフィール](#ho-so)で選択したお子さまのみが、ニックネーム、アバター、期間スコア、連続記録、順位で表示されます。いつでもオフにできます（[9](09-bao-mat-va-rieng-tu.md#bxh-cong-khai)）。
- **匿名測定**: 保護者の同意を設定する項目で、初期設定はオフです。現在、データの送信先は設定されていないため、イベントが端末外に送信されることはありません（[プロダクト分析](../product-analytics.md)）。
- **リマインダー**: [下記](#nhac-viec)をご覧ください。

<a id="nhac-viec"></a>
### 保護者向けリマインダー

「対応が必要な項目のリマインダーを許可」をオンにすると、タスクやごほうびの承認が必要な際に通知を受け取れます。リマインダーは承認が必要な項目のみを知らせ、広告には使われません。いつでもオフにできます。アプリの外で通知を受け取るには「この端末での通知を許可」をタップしてください。端末で通知がブロックされている場合も、アプリ内にはリマインダーが表示されます（[今日のバナー](03-hom-nay-va-duyet-viec.md#nhac-viec-ngan)を参照）。

<a id="giao-dien"></a>
## 表示設定

- 表示設定グループで**ライト、ダーク、端末の設定**を選べます。
- **フォントとサイズ**: 上部バーから「フォントとサイズの設定」ウィンドウを開き、お子さまが読みやすい文字に調整できます。
- **言語**: 上部バーの言語セレクターを使います（[1](01-bat-dau.md#ngon-ngu)）。
- **年齢に合わせたお子さまの画面**: [お子さまのプロフィールを編集](#ho-so)して固定できます。

<a id="pin"></a>
## 保護者用PIN

PINは**正確に4桁**で、家族管理エリアを保護します。お子さまには共有しないでください。

- **作成**: PINを入力し、確認のためもう一度入力します。**変更**: 現在のPINを入力し、新しいPINを2回入力します。
- PINを設定すると、お子さまの画面から保護者モードに切り替える際にPINが必要です。正しいPINを入力すると、このブラウザーは**2時間**ロック解除されます。再ロックすると解除状態は消去されます。
- 次の機密性の高い操作にはロック解除が必要です: お子さまの接続コードの表示または変更、端末の連携解除、タスクやごほうびの承認、スターの手動付与または差し引き、支払いの作成、家族の削除、銀行情報の保存、紹介手数料の出金。ロック解除されていない場合、アプリはロック画面に戻ります。
- 紹介手数料を出金するには、家族に**PINを設定済みであること**が必要です（[8](08-gioi-thieu-ban-be.md#rut-tien)）。
- 入力を何度も間違えると、数分待つ必要があります（「試行回数が多すぎます」）。
- お子さまが保護者の端末で完了をタップする際にPINは**不要**です。

<a id="tam-nghi"></a>
## 家族で休憩する

`Settings → Family break`で**休憩を取る**をタップし、家族全体で休む必要があるとき（病気、旅行、休暇など）に確認します。休憩中は次のようになります。

- お子さまの画面では、進捗リマインダー、連続記録、ランキングが非表示になり、やさしいメッセージが表示されます（[2](02-man-hinh-be.md#tam-nghi-be)）。
- お子さまは引き続きタスクを完了できます。スター、ごほうび、タスクは削除されません。
- 休憩日は[連続記録](02-man-hinh-be.md#sao-cap-chuoi)を途切れさせず、[習慣の段階の計算](06-khoa-hoc-thoi-quen.md#logic)で未実施として数えません。
- [リマインダー](#nhac-viec)は一時停止されます。

準備ができたら**再開**をタップしてください。

<a id="pwa"></a>
## アプリをインストール

「KidHabit Heroをインストール」カードから、ウェブ経由で新しいバージョンを受け取りながら、アプリのように素早く開けるようになります。Android/Chromeでは「今すぐインストール」をタップします。iPhoneではSafariで開き、共有 → ホーム画面に追加を選択します。必要に応じて「アプリデータを更新」ボタンも使えます。

<a id="du-lieu"></a>
## 家族データ

「家族データ」カードから、お子さまのプロフィール、習慣、完了履歴、ごほうび、グループ、日記、きっかけ、お子さまの取り組み方の記録を含むJSONコピーを**ダウンロード**できます。このファイルに**PINや支払い情報は含まれません**が、お子さまのデータが含まれるため非公開で保管してください。「JSONファイルから復元」はこの端末に保存されたデータのみが対象で（端末のローカルデータをすべて置き換えます）、Googleアカウントのデータは家族のサーバーに保存されています。お子さまの日記は[統計](03-hom-nay-va-duyet-viec.md#thong-ke)から個別にエクスポートできます。完全削除については[9](09-bao-mat-va-rieng-tu.md#xoa-du-lieu)をご覧ください。

<a id="uu-dai"></a>
## 特典と紹介

サインイン時のみ表示される、`Settings`の最後のグループです。

- **紹介コード**: 「友だちから紹介コードを受け取りましたか？」欄（家族が対象の場合のみ表示）。
- **友だちを紹介**: リンクの取得、紹介手数料の確認、出金を行うカード（[8](08-gioi-thieu-ban-be.md)）。
