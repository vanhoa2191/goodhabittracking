## 7日間の無料トライアル

- **無料: 0 VND**。クレジットカードは不要で、終了時に**自動請求されません**。
- お子さまの人数に上限なく、ファミリープランのすべての機能を利用できます。
- **各家族につき1回のみ**です。すでにトライアルを利用した場合、開始ボタンには「この家族はすでにトライアルを利用済みです。続けるにはプランを選択してください」と表示されます。
- 開始方法: (a) プランがない場合、[家族の設定](01-bat-dau.md#thiet-lap)の最後に自動で開始。(b) `/start`（「7日間のトライアルを開始」）から開始。Googleでサインインして家族を設定し、開始をタップします。(c) 料金画面のトライアル欄から開始。開始できるのは家族の保護者のみです。
- 家族が支払いを行うと、トライアル欄は**再表示されません**。
- トライアル終了が近づくと、システムからリマインダーメールが送信されます（[メール](#email)）。

<a id="cac-goi"></a>
## プラン

| プラン | 料金 | お子さまの人数 | おすすめの対象 |
|---|---|---|---|
| **7日間の無料トライアル** | 0 VND | 無制限 | 決める前にすべての機能を試したいご家族 |
| **子ども1人プラン** | 月額29,000 VND | 1人 | まず1人のお子さまから始めるご家族 |
| **ファミリープラン・月払い** | 月額49,000 VND | 無制限 | お子さまが複数いる、またはすべての機能を利用したいご家族 |
| **ファミリープラン・年払い** | 年額399,000 VND（通常588,000 VND、189,000 VNDお得、32%割引） | 無制限 | 小さなステップで習慣が身につくまで続けたいご家族 |
| **ライフタイム** | 販売なし | 無制限 | 管理者のみが手動で付与<!--op--> ([10](10-quan-tri-va-van-hanh.md#khach-hang))<!--/op--> |

支払いはすべて**一度限り**で、自動更新はありません。料金画面には、ファミリープランの追加特典（週間進捗レポート、家族対抗、優先度の高い技術サポート）と、年払いプランの追加特典（優先サポート、子育てガイドの電子書籍）も記載されています。電子書籍は**まだ利用できません**。

**地域によって名称が異なります**: マーケティングサイトでは、*子ども1人プラン*を「ベーシックプラン」、2種類のファミリープランを「プレミアムプラン」（月払い、年払い）と呼びます。同じ商品で、料金も同じです。

**プランごとのお子さまの人数**はデータベースで確認されます。子ども1人プランでは1人まで、トライアル、ファミリー、ライフタイムプランでは無制限です。有効なプランがない場合、新しいお子さまのプロフィールは追加できません。

## 購入場所

| 入口 | 説明 |
|---|---|
| 上部バーの**Proにアップグレード**ボタン | プランを選択できる「KidHabit Hero Pro 料金」画面が開きます |
| プランが必要なときに表示される料金画面 | 例: プランの期限切れ後 |
| `/pricing`ページ、または[ウェブサイト](11-website-va-trang-cong-khai.md#trang-chinh)のプラン選択ボタン | アプリ内の`/checkout?plan=…`に移動します |
| `/checkout`ページ | 選択したプランが読み込まれます。サインインし、必要なら家族を設定してから支払います |

無効なプランリンク（古い情報または情報不足）を開くと、「無効な支払いプラン」と料金を表示するボタンが現れます。利用権はメールアドレスではなく**家族**に紐づきます。

<a id="thanh-toan"></a>
## 支払いの手順

支払いは**PayOS（VietQR）**を通じて処理されます。

1. プランを選択し、必要ならGoogleでサインインして、「支払いに進む」を選びます。プロフィールが未完成の場合、氏名と電話番号を入力します。情報は次回以降の支払いのために保存されます。特典の受け取りは任意で、初期設定ではオフです。求められた場合は利用規約を確認し、家族が対象の場合のみ紹介コードを入力します。コード送信中は注文を作成できません。注文作成時にサーバーが金額を計算するため、QR作成前のみコードを入力できます。適用しても既存注文は置き換わりません。
2. 支払い画面に**VietQRコード**と振込情報（受取人名、銀行、口座番号、**正確な金額**、**必須の振込メモ**）が表示されます。各項目をコピーするボタン、**QRコードをダウンロード**するボタン（銀行アプリを開き、ギャラリーから画像を選んで読み取れます）、PayOSの安全な支払いページへのリンクがあります。コピーに失敗した場合は、テキストを長押しして選択し、手動でコピーしてください。サーバーは15分の支払期限を設定していないため、カウントダウンはありません。
3. 銀行アプリまたはMoMoでスキャンします。**金額と振込メモは正確に保ってください。**
4. 必要に応じて**「振込済み」**をタップします。アプリが自動で状態を確認します。エラーは選択中の言語で表示され、自動確認は続きます。完了すると「🎉 アップグレードに成功しました！」と表示され、プランがすぐに有効になります。

支払いが保留中の場合、**すぐに再度支払わないでください**。料金はサーバーで設定され、ブラウザーでは変更できません。支払いができるのは家族の保護者のみです。PINを設定している場合、支払いの作成には[PIN](05-gia-dinh-va-cai-dat.md#pin)が必要です。PayOSのページからアプリに戻ると支払い結果が表示されます。

<a id="kich-hoat"></a>
## 有効化と照合

次の独立した3つの経路のいずれかで、システムが支払いを**確認**するとプランが有効になります。最初に届いた確認を採用し、支払いが二重に数えられることはありません。

1. PayOSの**Webhook**が`/api/payment/webhook`を呼び出します（署名、金額、振込メモ、注文者の確認を含む）。
2. **PayOSへの照会**: 保護者が支払い画面を開いている間、アプリがPayOSに直接注文を問い合わせます。Webhookには依存しません。
3. **バックグラウンド照合**: 10分ごとにバックグラウンドタスクが支払い待ちの注文を確認し、PayOSに問い合わせます。

振込後にプランが表示されない場合は、数分待ってから`/checkout`を再度開き、注文コードを添えてサポートにご連絡ください。<!--op-->運用チームは[管理 → 支払い](10-quan-tri-va-van-hanh.md#thanh-toan-admin)で注文を確認できます。<!--/op-->

<a id="cong-don"></a>
## 期間の延長

現在のプランが有効なうちに購入した場合、トライアルの残り期間を含めて**現在の期間の末尾に追加**されます。月払いプランでは1か月、年払いプランでは1年が追加されます。現在のプランより下位のプランを購入しても、**上位プランが維持**されます。ライフタイムプランが別のプランに置き換わることはありません。

<a id="coupon"></a>
## ギフトコード（クーポン）

ギフトコードは運用チームが作成します。`Settings → Account → Coupon code → Apply code`で入力してください。

- ギフトコードは利用期間を**日数で追加**します。割引のみのコードは使用できません。有料プランがまだない場合は、対応する日数のファミリープラン（月払い）に切り替わります。すでにプランがある場合は、現在の期間の末尾に日数が追加され、プラン自体は変わりません。ライフタイムプランには適用できません。
- 各コードは**家族につき1回**使用できます。同じ家族が別のコードを使うことはできます。期限切れ、使用済み、無効のコードには「コードが見つからないか、使用済み、または期限切れです」と表示されます。
- 15分間に**10回を超えて**入力に失敗すると、数分間アクセスが一時的にロックされます。

<a id="giam-gia"></a>
## 紹介された家族の割引

紹介コード（`?ref=`リンクまたは手入力）を使った家族は、過去に支払い済みの注文がない場合に限り、初回の年払いプランが**10%割引**になります（399,000 VNDが359,100 VNDになります）。支払い画面に「紹介コードで10%割引」と表示されます。詳細は[8. 紹介](08-gioi-thieu-ban-be.md#giam-10)をご覧ください。

<a id="hoan-tien"></a>
## 返金とキャンセル

- **30日間の返金**: ご満足いただけない場合は、支払いから30日以内に注文コードと支払い日時をサポートメール宛てにお送りください。返金は手動で処理されます。返金が確定すると、保留中の場合はその注文に対する紹介手数料が取り消されます（[8](08-gioi-thieu-ban-be.md#hoan-tien-hoa-hong)）。
- **支払い待ちリンク**はサポートチームがキャンセルできます。PayOSの確認後にのみ注文が「キャンセル済み」に変わります。
- **プランのキャンセル**はサポートチームが処理し、メールで確認します。自動請求はありません。

<a id="email"></a>
## お客様に送信されるメール

メールは2種類あります。

- **サインインメール**（Supabaseから送信）: 登録確認、サインインリンク、アカウント復旧、招待、メールアドレス変更、再認証。メール画面は事前にデザインされています（[テンプレート](../../supabase/email-templates/README.md)）。
- **ライフサイクルメール**（オン・オフを切り替え可能）: ようこそ・設定案内（`welcome_setup`）、トライアル終了前のリマインダー（`trial_ending`）、支払い領収書（`payment_receipt`）、サポート依頼の更新（`support_status`）、返金（`refund_status`）、プランキャンセルの確認（`subscription_cancelled`）。

ライフサイクルメールに**お子さまのデータは含まれません**。販促メールは特典の受け取りに同意した場合のみ送信され、同意をオフにすると直ちに停止します。宛先不明、迷惑メール報告、配信停止のアドレスには、その後メールを送りません。

<a id="het-han"></a>
## プランの期限切れ

トライアルまたはプランが更新されずに期限切れになると、家族はプランなしの状態になります。新しいお子さまのプロフィールを追加できず、プランを選ぶ案内が表示されます。**データは削除されません**。プランを購入するかギフトコードを使うと続けられます。
