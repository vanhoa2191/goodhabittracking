## 保護者エリアの構成

保護者エリアは3つのセクションと、それぞれのサブセクションで構成されています。キーボードの矢印キー、Home、Endで移動できます。

| セクション | 項目 | ガイド |
|---|---|---|
| **今日** | 承認、統計 | このガイド |
| **設計** | 習慣、年齢別ステップ、ごほうび | [4](04-thiet-ke-thoi-quen.md) |
| **家族** | お子さま、設定 | [5](05-gia-dinh-va-cai-dat.md) |

承認待ちのタスク数は、承認項目のバッジに表示されます。[家族](05-gia-dinh-va-cai-dat.md#ghep-thiet-bi)からお子さまの端末をペアリングできます。上部バーでは保護者モードとお子さまの画面を切り替えたり、[16の強みと与える7つの行いのガイド](06-khoa-hoc-thoi-quen.md#chan-dung)を開いたりできます。

<a id="hom-nay"></a>
## お子さまごとの今日の状況

**承認**セクションには、「（お子さまの名前）の今日」カードが最初に表示されます。お子さまが複数いる場合は、上に並ぶボタンから選択してください。

- 今日完了したタスク数と、予定されているタスクの合計（「5件中3件完了」）、および**連続記録**（「1日休んでも進捗は失われません」）。
- **対応が必要**: 保護者の対応を待つタスク、または「現在、対応が必要な項目はありません」。調整が提案されている場合は、「お子さまの習慣に関する調整提案がN件あります」と**提案を見る**ボタンが表示されます（[提案](#tien-trien)）。
- **習慣づくり中（進行中／上限）**: 初期段階にある新しい習慣の数と、年齢別の推奨上限（0～3歳: 1、3～6歳: 2、6～15歳: 3、15歳以上: 4）を比較します。上限を超えた場合は注意が表示されるだけで、操作は制限されません。
- **過去7日間**: 各日を「完了」「未完了」「予定なし」で示し、お子さまがどのように行ったか（1人で、声かけが必要、一緒に）も表示します。
- まだきっかけが設定されていない習慣がある場合、カードに**「最初の習慣のきっかけを設定」**と表示され、[習慣](04-thiet-ke-thoi-quen.md#chuong-trinh)に直接移動できます。

このカードは常に表示されます。以下の「今日はどのようにできましたか？」「習慣の進捗」「週の振り返り」は、[適応型習慣プログラム](06-khoa-hoc-thoi-quen.md#logic)（現在有効）に含まれます。

<a id="duyet"></a>
## 承認が必要なタスクとごほうび

承認セクションには2つの一覧があります。

1. **保護者の承認待ちタスク**: お子さまが完了と記録し、[保護者が「承認を必要とする」に設定した](04-thiet-ke-thoi-quen.md#quan-ly-viec)タスクです。各行にはタスク名、お子さまの名前、ごほうびのスター数、完了日が表示されます。**承認**するとスターが加算され（[バッジ](02-man-hinh-be.md#huy-hieu)を獲得する場合があります）、**却下**するとスターは加算されません。
2. **お子さまからのごほうびリクエスト**: お子さまがリクエストした内容、すでに差し引かれたスター、リクエスト日時が表示されます。手順は、お子さまがリクエスト → 保護者が**承認** → 保護者が**ごほうびを渡す** → 完了です。**却下**するとスターがお子さまに返却されます（[お子さまのごほうび](02-man-hinh-be.md#qua)）。

タスクの承認または却下、ごほうびの承認または受け渡しには、ご家族で設定している場合、[PIN](05-gia-dinh-va-cai-dat.md#pin)が必要です。お子さまが保護者の端末で直接タスクを完了する場合、PINは不要です。[リマインダー](#nhac-viec-ngan)が有効な場合、「確認待ちの項目がN件あります」というバナーも表示されます。

<a id="can-xu-ly"></a>
## 「対応が必要」欄と複数タスクの承認

この機能は段階的に有効化されています。アプリにまだ表示されていない場合は、お使いのバージョンにはまだ反映されていません。

承認セクションの上部にある**対応が必要**欄には、承認待ちのタスク、ごほうびのリクエスト、習慣の調整提案と、それぞれの件数がまとめて表示されます。項目をタップすると、操作する場所に直接移動します。対応待ちがない場合は「現在、対応が必要な項目はありません」と表示されます。

承認待ちタスクの各行にはチェックボックスがあります。**初期状態で選択されているタスクはありません**。タスクを1つずつ選ぶか、**すべて選択**（一度に最大50件）をタップします。画面下部のバーに、選択したお子さまとタスク数が表示され、**N件のタスクを承認**または**N件のタスクを却下**を選べます。一括操作では[PIN](05-gia-dinh-va-cai-dat.md#pin)の入力は1回だけです。すでに承認または却下済みのタスク（もう一方の保護者が操作した場合など）はスキップされ、その旨が表示されます。2度タップしてもスターが重複して付与されることはありません。

お子さまが[習慣セット](04-thiet-ke-thoi-quen.md#chuong-trinh)の最初の習慣に慣れてきて（声かけが減っている、または定着している）、年齢別上限に達していない場合、次の習慣を追加する提案が表示されます。**次のステップを追加**を選ぶとセットの3ステップを再度開き、**後で**を選ぶと14日間非表示になります。アプリが自動で追加することはありません。

アプリをホーム画面に追加し、[リマインダー](#nhac-viec-ngan)をオンにしている場合、アイコンバッジに承認待ちの**タスクとごほうびの件数**が表示されます（対応していない端末もあります。表示されるのは件数のみで、お子さまの名前やタスク名は表示されません）。アイコンを長押しすると、**承認**と**ユーザーガイド**のショートカットも表示されます。ウェブアプリには独自のホーム画面ウィジェットはありません。

<a id="muc-ho-tro"></a>
## お子さまの実施方法を記録する

「今日はどのようにできましたか？」では、今日または昨日の各習慣をお子さまがどのように行ったか、3つのボタン（**1人でできた**、**声かけが必要だった**、**一緒にできた**）から選びます。回答は任意です。回答は、アプリがリマインダーを徐々に減らすタイミングを判断するために使います（[4段階](06-khoa-hoc-thoi-quen.md#bon-pha)）。評価やお子さま同士の比較には使いません。15歳以上のお子さまは[自分で選択](02-man-hinh-be.md#hoan-thanh)できます。保護者はいつでも回答を編集できます。

アプリが尋ねるのは最近完了したタスク（今日と昨日）のうち、数件ずつです。回答を記録すると「記録しました」と表示されます。記録されていない完了項目が複数ある場合、フィードバックを受け取れるよう、進捗カードに記録を追加する案内が表示されます。

<a id="nhin-lai-tuan"></a>
## 週の振り返り

「今週を振り返る（5分）」カードは週に1回表示され、毎日お子さまに声をかける代わりに、家族で一緒に振り返る機会を作ります。内容は次のとおりです。

- **ほめることを1つ**: お子さまが安定して行えている習慣。
- **調整することを1つ**: まだ安定していない習慣と、より小さくする、または時間を変える提案。
- 現在の習慣が比較的安定し、上限を超えていない場合は新しい習慣の**追加**を提案します。そうでない場合は、もう1週間**リズムを維持**する案内が表示されます。
- データが足りない場合、アプリからフィードバックを受け取れるよう、数日間、お子さまの実施方法を記録する案内が表示されます。

<a id="tien-trien"></a>
## 習慣の進捗と提案

「習慣の進捗」には、きっかけが設定された各習慣と現在の段階（**きっかけを選ぶ、習慣を作る、サポートを減らす、習慣が定着**）が表示されます。これはお子さまをサポートするための提案であり、評価ではありません。各お子さまに一度に表示される提案は最大3件で、それぞれに「一度に習慣を増やしすぎているため、1つを一時停止する」など、わかりやすい理由が添えられます。

- 習慣を同時に増やしすぎている → 1つの習慣を一時停止する。
- 何度か続けてできなかった → より小さくする、時間を変える、週末にもできるようにする。
- 最近の実施に声かけが必要だった → 視覚的なきっかけを使うか、お子さま自身にリマインダーを設定してもらう。
- お子さまが自分でできている → 言葉で励まし、スターを徐々に減らす。

「後で」を選ぶと、その提案は14日間非表示になります（このブラウザーに保存）。習慣を選ぶと[習慣](04-thiet-ke-thoi-quen.md#quan-ly-viec)が開き、きっかけを編集できます。提案ルールの全容は[6. 習慣の科学](06-khoa-hoc-thoi-quen.md#goi-y)をご覧ください。

<a id="xu-huong-ho-tro"></a>
## 週ごとのサポート状況と習慣の状態

この機能は段階的に有効化されています。まだ表示されていない場合は、お使いのバージョンにはまだ反映されていません。

各習慣には、中立的な**状態ラベル**が記号と文字で表示されます。**未開始**（きっかけなし）、**形になりつつある**、**サポートが必要**（停滞、リマインダーに依存しているなどの提案あり）、**安定**（サポートが減っている、または定着し、最近の機会の多くで実施できた）。ラベルは状態を説明するだけで、お子さまを評価しません。

**過去6週間のサポート状況**を開くと、週ごとの棒グラフ（1人で、声かけあり、一緒に、未記録、未実施）が表示されます。アプリが「サポートが減っています」と表示するのは、**3週間以上連続した**データがあり、直近の週にお子さまが1人で行った割合が最初の週より**20ポイント以上**高く、両方の週で実施方法が十分に記録されている場合のみです。それ以外は「まだ判断できるデータが足りません」と表示されます。これは確度の低い設計上の基準であり、お子さま同士の比較には使いません。

<a id="tot-nghiep"></a>
## 習慣の卒業

習慣が**3週間以上**定着し、お子さまが直近10回の機会のうち**8回以上を1人で行った**場合、[対応が必要](#can-xu-ly)欄に3つの選択肢が表示されます。

- **卒業**: 習慣はお子さまの日々の一覧から外れ、保護者とお子さまの**できること**に表示されます。獲得済みのスター、履歴、バッジはそのまま残ります。
- **スターを減らす**: 以降、そのタスクで得られるスターは、最初の値の半分、さらに5分の1に減ります（最低1個）。すでに獲得したスターは変わらず、いつでも最初の値に戻せます。
- **そのまま続ける**: 提案を14日間非表示にします。

アプリが提案を出すだけで、自動で実行することはありません。卒業済みの習慣について、毎月1回「今も1人でできていますか？」とワンタップで確認します。**今も1人でできる**または**再開する**を選択してください。卒業直後に**取り消す**をタップするか、できることから**再開する**こともできます。

<a id="mot-thay-doi"></a>
## 今週の1つの変更

この機能は段階的に有効化されています。まだ表示されていない場合は、お使いのバージョンにはまだ反映されていません。

「週の振り返り」の下にある**今週の1つの変更**カードでは、お子さまにすでに表示されている提案から、**7日間**試す変更を**1つだけ**提案します。

- **小さくする**: 習慣の名前を変更し、2分間でできる形に説明し直します（枠組みの47の習慣すべてで利用できます）。
- **時間を変える**: お子さまが実際に行う時間帯に習慣を移します（完了時刻から推定。最近の記録が6件以上あり、その大半が別の時間帯の場合に利用できます）。
- **一緒に行う**: 数日間、保護者がお子さまと一緒に行います。一緒に行った日は未実施として数えません。
- **新しいきっかけ**: タスク管理を開いて、きっかけを編集します。
- **声かけを減らす**: 声をかける前に、お子さまが始めるのを待ちます。

**7日間試す**を選ぶと、必要に応じて変更を適用し、試行を記録します。試行中または回答待ちの間、そのお子さまには別の変更は提案されません。7日後に「役に立ちましたか？」と尋ねます（役に立った／まだ／やめる）。「まだ」または「やめる」を選ぶと、小さくした習慣は元の形に戻ります。同じ習慣に対する同じ提案は30日間表示されません。「習慣の進捗」の提案（停滞、声かけに依存、定着）にも、対応する**7日間試す**ボタンがあります。

<a id="muc-tieu-tuan"></a>
## お子さまの今週の目標

**お子さまが選べるタスク**カードで、**2～4件のタスク**を「お子さまが選択可能」にします（各タスクの横のチェックボックス）。6歳以上のお子さまは、週の初めに自分の画面でその中から**1～2件**を目標に選び、「x/7日」と進捗を確認できます。アカウントは不要です。6歳未満の場合はカードで一緒に選びます。お子さまが選べるのは保護者が許可したタスクのみで、保存できるのは自分の選択だけです。選択しない場合も、画面には[練習中のこと](02-man-hinh-be.md#tu-lap)が表示されます。

<a id="chinh-sao"></a>
## スターの手動追加または差し引き

`Family → Children`では、各お子さまに**スターの手動追加／差し引き**ボタンがあります。変更するスター数（正の数で追加、負の数で差し引き）と短い理由（「きょうだいに親切に分けたことをほめる」「リマインダー…」など）を入力します。[PIN](05-gia-dinh-va-cai-dat.md#pin)が必要で、操作は記録されます。割り当て済みタスク以外の行動を認めるために使い、お子さまを比較するためには使わないでください。

<a id="thong-ke"></a>
## 統計、印刷、共有

**統計**セクション（`Today → Statistics`）には次の情報があります。

- **7日間の推移**: 家族全体が毎日完了したタスク数を棒で表示します。完了がない日は空の棒になります。
- **週間習慣表を印刷**、**週間レポートを印刷**: 冷蔵庫に貼れる曜日別のタスク表と、「今週X/Y件を完了 · Nポイント」の週間レポートです。どちらもブラウザーの印刷画面から印刷できます。
- **お子さまの1文日記**: 日付ごとに記録を読み返し、CSVを**エクスポート**できます（お子さまの言葉が含まれるため、ファイルは非公開で保管してください）。[日記](02-man-hinh-be.md#nhat-ky)機能が有効な場合のみ表示されます。
- **前向きな節目を共有**: 端末の共有画面で、家族向けメッセージをプレビューしてから共有を確定します。初期設定では、お子さまの氏名、年齢、写真、タスクは**含まれず**、追跡コードも入りません。
- ページ下部には危険な操作を行う領域があり、**家族データを完全に削除**できます（家族の所有者のみ。`DELETE FAMILY`を正確に入力。[9](09-bao-mat-va-rieng-tu.md#xoa-du-lieu)を参照）。

<a id="nhac-viec-ngan"></a>
## リマインダー

保護者が[操作可能なリマインダーを許可](05-gia-dinh-va-cai-dat.md#nhac-viec)し、承認待ちの項目があると、ページにバナーが表示されます。端末で通知が許可されている場合は、ブラウザーから通知が届きます。家族が[休憩中](05-gia-dinh-va-cai-dat.md#tam-nghi)はリマインダーを送りません。リマインダーは承認が必要な項目にのみ使われ、広告には使われません。
