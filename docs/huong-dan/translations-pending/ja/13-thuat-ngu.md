# 13. 用語集

[← 12. 関連マップと利用シナリオ](12-ban-do-lien-ket.md) · [目次](README.md)

このドキュメント全体で使用する用語をアルファベット順に示し、詳しい説明へのリンクを付けています。

| 用語 | KidHabitでの意味 | 参照先 |
|---|---|---|
| **与える7つの行い** | 毎日できる7つの簡単な行い: 笑顔、目を合わせる、思いやりのある言葉、感謝、寛容、人を助ける行動、ほかの人に譲ること | [6](06-khoa-hoc-thoi-quen.md#chan-dung) |
| **お子さま** | 家族内のお子さまのプロフィール。ペアリングした端末からお子さまの画面を開きます | [2](02-man-hinh-be.md) |
| **ニックネーム** | ランキングでお子さまの本名の代わりに表示される名前 | [5](05-gia-dinh-va-cai-dat.md#ho-so) |
| **ランキング** | 期間内に獲得したスターによる順位。家族、グループ、公開の範囲があります | [2](02-man-hinh-be.md#bang-xep-hang) |
| **レベル** | スターを100個獲得するごとに上がります | [2](02-man-hinh-be.md#sao-cap-chuoi) |
| **肖像（16の肖像）** | 性格タイプではなく成長の方向性を示すもの。それぞれがバッジです | [6](06-khoa-hoc-thoi-quen.md#chan-dung) |
| **家族の所有者** | 家族を作成した人。家族データを削除できます | [1](01-bat-dau.md#vai-tro) |
| **習慣プログラム** | きっかけを設定し、段階を追いながら習慣を少しずつ身につける仕組み | [4](04-thiet-ke-thoi-quen.md#chuong-trinh) |
| **連続記録（炎）** | 確認済みのタスクを連続して完了した日数。休憩日に1日空いても連続記録は途切れません | [2](02-man-hinh-be.md#sao-cap-chuoi) |
| **クーポン／ギフトコード** | プラン期間の日数を追加するコード | [7](07-goi-va-thanh-toan.md#coupon) |
| **無料トライアル** | 家族につき1回、7日間無料で利用でき、自動請求はありません | [7](07-goi-va-thanh-toan.md#dung-thu) |
| **承認** | 保護者が、お子さまのタスクまたはごほうびを確認すること | [3](03-hom-nay-va-duyet-viec.md#duyet) |
| **利用権** | 現在のプランで認められる内容（お子さまの人数など）。家族に紐づきます | [7](07-goi-va-thanh-toan.md#cac-goi) |
| **家族** | データと支払いの単位。それぞれの家族が独立した「スペース」を持ちます | [9](09-bao-mat-va-rieng-tu.md#ai-thay) |
| **年齢段階（GD1～GD5）** | 枠組みの5つの年齢段階: 0～3歳、3～6歳、6～12歳、12～15歳、15～18歳 | [6](06-khoa-hoc-thoi-quen.md#khung) |
| **習慣の段階／フェーズ** | 習慣の4段階: きっかけを定着させる、ルーティンを作る、サポートを減らす、習慣にする | [6](06-khoa-hoc-thoi-quen.md#bon-pha) |
| **端末のペアリング** | コードまたはQRコードを使い、1台の端末を特定のお子さま1人に紐づけること | [5](05-gia-dinh-va-cai-dat.md#ghep-thiet-bi) |
| **年齢別パック** | お子さまの年齢層に合わせた最初の6つのタスクを、ワンタップで読み込むセット | [5](05-gia-dinh-va-cai-dat.md#ho-so) |
| **リーグのランク** | 獲得したスターの合計に基づく、ブロンズ、シルバー、ゴールド、ダイヤモンド | [2](02-man-hinh-be.md#sao-cap-chuoi) |
| **紹介手数料** | 紹介された家族が実際に支払った金額の30% | [8](08-gioi-thieu-ban-be.md#hoa-hong) |
| **今日** | 保護者用の最初の領域。承認と分析が含まれます | [3](03-hom-nay-va-duyet-viec.md) |
| **バッジ** | 節目に達すると獲得できるごほうび。基本バッジが5つ、肖像バッジが16あります | [2](02-man-hinh-be.md#huy-hieu) |
| **47の習慣の枠組み** | 0～18歳を対象に、5段階・5領域にわたる習慣のセット | [6](06-khoa-hoc-thoi-quen.md#khung) |
| **ごほうびストア** | 保護者がお子さまのために作成するごほうびの一覧 | [4](04-thiet-ke-thoi-quen.md#kho-qua) |
| **年齢別ロードマップ** | 5段階、各段階3ステップで、ステップごとに習慣を1つずつ追加する道筋 | [4](04-thiet-ke-thoi-quen.md#lo-trinh) |
| **マスコット** | お子さまに寄り添う6つのキャラクター: Leo、Bunny、Panda、Fox、Turtle、Bee | [2](02-man-hinh-be.md#linh-vat) |
| **ペアリングコード／接続コード** | お子さまごとに固定されたコード。そのお子さまのプロフィールだけを開きます | [9](09-bao-mat-va-rieng-tu.md#ma-ghep) |
| **紹介コード** | `?ref=`リンクに付属する8文字のコード | [8](08-gioi-thieu-ban-be.md) |
| **ケア担当者** | 閲覧専用モードで進捗を確認するために招待された家族の一員 | [5](05-gia-dinh-va-cai-dat.md#nguoi-cham-soc) |
| **PayOS／VietQR** | 銀行QRコードを使った銀行振込の決済ゲートウェイ | [7](07-goi-va-thanh-toan.md#thanh-toan) |
| **保護者用PIN** | 保護者モードと機密性の高い操作を保護する4桁のコード。2時間のアクセス解除に使います | [5](05-gia-dinh-va-cai-dat.md#pin) |
| **PWA** | ウェブサイトをホーム画面にアプリとしてインストールする機能 | [5](05-gia-dinh-va-cai-dat.md#pwa) |
| **スター** | ごほうびとの交換や街づくりに使うポイント | [2](02-man-hinh-be.md#sao-cap-chuoi) |
| **休憩** | データを失わずに、家族全体の進捗リマインダーと連続記録を一時停止すること | [5](05-gia-dinh-va-cai-dat.md#tam-nghi) |
| **モデリング** | 保護者が自分の行動を通じて手本を示すこと | [6](06-khoa-hoc-thoi-quen.md#chan-dung) |
| **「もし…なら…」のきっかけ** | 習慣を、なじみのある行動や決まった時間に結びつける計画 | [4](04-thiet-ke-thoi-quen.md#chuong-trinh) |
| **あとで（スヌーズ）** | タスクをその日の終わりに移動すること。未完了として数えられません | [2](02-man-hinh-be.md#hoan-thanh) |
| **Webhook／照合** | PayOSが支払いを通知し、システムもPayOSに再確認して確定する処理 | [7](07-goi-va-thanh-toan.md#kich-hoat) |
| **2段階認証（管理者）** | 管理者アカウントで必要となるTOTPコード | [10](10-quan-tri-va-van-hanh.md#admin) |
