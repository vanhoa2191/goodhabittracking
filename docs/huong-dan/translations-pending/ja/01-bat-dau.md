## アプリへの3つの入り方

`app.kidhabithero.com`を初めて開くと、「KidHabitにはどのように入りますか？」という画面に3つの選択肢が表示されます。画面に表示されるボタンが2つと、お子さま向けの折りたたみ欄が1つです。保護者用とお子さま用の領域は分かれており、お子さまに支払いや家族の設定が表示されることはありません。

| 入り方 | 対象 | 動作 |
|---|---|---|
| **保護者として続ける**（Googleでサインイン） | 保護者、後見人 | 家族ダッシュボードが開きます（[3](03-hom-nay-va-duyet-viec.md)）。初回は[家族の設定](#thiet-lap)に進みます。 |
| **お子さまの端末ですか？**（開いてから「コードを入力またはQRをスキャン」を選択） | お子さま | 端末を特定のお子さま1人とペアリングし、[お子さまの画面](02-man-hinh-be.md)を直接開きます。お子さまのアカウントは不要です。 |
| **デモを試す**（保護者ボタンの下に表示） | すべての方 | サンプルデータを使います。アカウントは不要です（[デモ](#demo)）。 |

すでにサインインしている保護者は、ダッシュボードに直接移動します。ランディングページをもう一度表示するには、「ホーム」または「ランディングページを表示」を選択してください。お子さまの端末をペアリングすると、以後はお子さま用の画面が直接開き、保護者用ダッシュボードや料金ページは表示されません。

<a id="dang-nhap"></a>
## サインイン

- 保護者の主なサインイン方法は**Google**です。
- **メールで届くワンタイムコード**は2番目の方法ですが、現在は有効化されるまで**オフ**です<!--op-->（`emailCodeLogin`フラグ、[有効化の方法](../deployment.md)）<!--/op-->。有効にすると、入口画面に「その他のサインイン方法」という折りたたみ欄が表示され、開くと「メールでサインインコードを受け取る」欄が現れます。フラグがオフの場合、この欄はありません。保護者がメールアドレスを入力すると短い数字のコードが届き、それを入力してサインインします。数秒後にコードを再送できますが、リクエストが多すぎると数分待つ必要があります。
- サインインに失敗すると、アプリに短いメッセージと再試行ボタンが表示されます。データは保存されません。

紹介リンク（`?ref=`）からサインインした保護者は、自動的に紹介として記録されます（[8](08-gioi-thieu-ban-be.md#ghi-nhan)）。ケア担当者として招待された方は、Googleでサインインしてから招待を承認します（[5](05-gia-dinh-va-cai-dat.md#nguoi-cham-soc)）。

<a id="thiet-lap"></a>
## 最初のお子さまプロフィールを作成する

初回に表示される「ご家族の年齢別プランを作成」画面では、お子さまのプロフィールのみを作成します。

- **お子さまの氏名**（必須）、ニックネーム（任意）、年齢（初期値は5歳）を入力します。
- **カスタマイズを追加**を開くと、年齢段階の説明を読んだり、マスコット（初期値はLeo）を変更したり、最初の6つの習慣を確認したり、初期設定でオンになっている習慣の追加をオフにしたりできます。これらは後から編集できます。

お子さまの親または法定後見人であることを**確認し**、KidHabitがお子さまのプロフィール、習慣、進捗を保存することに同意してください。同意はポリシーのバージョンとともに記録されます（[9](09-bao-mat-va-rieng-tu.md#dong-thuan)）。公開ランキングは初期設定でオフです。

ご家族にプランがない場合、設定を完了すると**7日間の無料トライアルが自動的に開始**されます（ボタンには「7日間のトライアルを開始」と表示されます）。トライアルは各家族につき1回のみ利用できます（[7](07-goi-va-thanh-toan.md#dung-thu)）。

ウェブサイトから`/start`（「7日間のトライアルを開始」）を直接開くこともできます。Googleでサインインし、ご家族を設定してから開始をクリックしてください。

<a id="thong-tin"></a>
## お客様情報

保護者が入力する必要があるのは、利用規約と紹介の手順に進む前の**チェックアウト時の氏名と電話番号**だけです。電話番号は9～15桁で入力してください。情報は次回以降の支払いのためにサーバーへ保存されます。プロフィールが完成している場合、この手順は省略されます。この要件によってサインインやお子さまのプロフィール作成が妨げられることはありません。案内や特典の受け取りは任意で、初期設定ではオフです。保護者は後から`Family → Settings → Account`で情報を編集できます（[5](05-gia-dinh-va-cai-dat.md#tai-khoan)）。配信を停止すると、販促メールは直ちに停止します（[7](07-goi-va-thanh-toan.md#email)）。読み込みや保存に失敗した場合は、**再試行**をタップしてください。

<a id="vai-tro"></a>
## 家族内の役割

| 役割 | できること | できないこと |
|---|---|---|
| **家族の所有者**（作成者） | 保護者ができるすべての操作、支払い、家族データの削除 | なし |
| **親または後見人** | お子さま、タスク、ごほうび、承認、端末の管理 | 所有者のみの操作（家族の削除） |
| **ケア担当者** | 「ケア担当者ビュー」で進捗を確認 | プロフィール、タスク、スター、プランの編集 |
| **お子さま**（ペアリング済み端末） | 自分のタスクの完了、ごほうびのリクエスト、日記の記入 | 支払い、設定、ほかのお子さまのプロフィールの閲覧 |

トライアルの開始や支払いができるのは、その家族の保護者のみです。機密性の高い操作には[PIN](05-gia-dinh-va-cai-dat.md#pin)も必要です。

<a id="demo"></a>
## デモ

「デモを試す」を選ぶと、8歳、4歳、1歳のサンプルのお子さま3人と、サンプルのタスク、ごほうび、グループが表示されます。デモデータは現在のブラウザータブに保存されるため、ページを再読み込みしても残ります。実際の家族を設定するかサインインするとデモデータは削除され、実データと**混ざることはありません**。デモからサーバーに情報が送られることはなく、支払いも不要です。

<a id="ngon-ngu"></a>
## 言語

アプリは、ベトナム語、英語、フランス語、ドイツ語、イタリア語、スペイン語、中国語、日本語、韓国語の9言語に対応しています。初期言語は、保存済みの選択、国（Cloudflareから取得）、ブラウザーの言語、英語の順に選択されます。上部バーの言語セレクターから変更できます。選択した言語は保存され、ページ、タイトル、画面表示に反映されます。

画面が狭い場合、上部バーの操作項目は**メニュー**（⋮ボタン）に移動します。メニューには**アカウント**、**クイック設定**（言語、ライトまたはダーク表示、文字サイズ、音声）、**ユーザーガイド**へのリンクがあります。料金、お子さまのペアリングコードの入力、16の強みのガイド、家族の設定、ホーム、保存状態など、使用頻度の低い項目は**その他**の中にあり、開くまで折りたたまれています。

年齢別のステップや「今日」画面など、一部の詳細コンテンツはまだ9言語すべてに翻訳されていません。翻訳がない場合は英語で表示されます。

<a id="tro-giup"></a>
## アプリ内のヘルプ

このガイドは、アプリ内の次の2つの方法で利用できます。

- **各項目の横にある「?」**。保護者用画面では、承認、きっかけ、PIN、ペアリングコード、支払いなど、各機能のタイトルの横に小さな**「?」**が表示されます。カーソルを合わせる、タップする、またはTabキーでフォーカスすると、1～2文の説明を読めます。**詳細を見る**をクリックすると、作業中の画面を離れずに関連するガイドの箇所が開きます。そのウィンドウ内のリンクから別の項目を読み進めたり、**戻る**をクリックして元に戻ったりできます。Escキーを押すか外側をタップすると説明が閉じます。
- **専用のガイドページ**。上部バーの**ユーザーガイド**ボタン（または`Family → Settings → Open user guide`）から`/docs`を開くと、章の一覧、**検索**欄（アクセント記号の有無を問わず入力できます）、よくある操作の**「～したい」**ショートカット、各章の目次が表示されます。詳細ウィンドウの**ガイド全文を開く**ボタンからも、このページの該当箇所に移動できます。

ガイド全文はベトナム語と翻訳版（現在は英語を含む）で利用できます。翻訳がない言語では、「?」の説明は英語、詳細はベトナム語で表示され、`/docs`には簡単な概要が表示されます。
