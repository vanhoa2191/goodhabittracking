# KidHabit Hero ユーザーガイド

このガイドでは、ユーザーが利用できるKidHabit Heroの**すべての機能**を説明し、機能同士の**つながり**を示します。各ファイルは「このガイドの内容」で始まり、「関連項目」で終わります。調べ直さなくても、ある機能から関連機能へ読み進められます。

KidHabit Heroは、毎日の小さな行動を通じて、保護者とお子さまがよい習慣を身につけるのを支援します。保護者がタスクを割り当て、お子さまが完了を記録し、保護者が承認すると、お子さまは保護者が選んだごほうびと交換するスターを集められます。アプリはお子さま同士の比較や性格の評価にスターを使いません（[原則を参照](06-khoa-hoc-thoi-quen.md#nguyen-tac)）。

<!--op-->## 2つの利用環境と3つのユーザーグループ

KidHabit Heroには、それぞれ異なるアドレスを持つ2つの場所があります。

| 場所 | アドレス | 用途 | ドキュメント |
|---|---|---|---|
| **アプリ** | `app.kidhabithero.com` | サインイン、家族の管理、お子さまのタスク、支払い、管理業務 | 1～10 |
| **ランディングサイト** | `kidhabithero.com` | 紹介、料金、ブログ、習慣の枠組み、利用規約 | [11](11-website-va-trang-cong-khai.md) |

アプリには3つのユーザーグループがあり、それぞれに専用のエリアがあります。

- **保護者**（家族の所有者、親、後見人）: Googleでサインインし、「今日」「設計」「家族」エリアを利用します。
- **お子さま**: 保護者から受け取ったコードまたはQRコードで入り（アカウント不要）、自分のエリアのみを利用します。
- **ケア担当者**（祖父母や親族）: 保護者から招待され、進捗を閲覧できます。編集はできません。<!--/op-->

## このガイドの表記

- **アプリ内のパス**は`Area → Item`の形式です。例: `Family → Settings`。
- 「プラン」とは、トライアル期間中、または期限切れ前のプランがある状態を指します（[7](07-goi-va-thanh-toan.md)）。
- 「PINを設定した場合」とは、このブラウザーで有効な正しい保護者用PINを入力した後にのみ操作できることを指します（[5](05-gia-dinh-va-cai-dat.md#pin)）。
- 料金、しきい値、時間制限は記載時点の値です。各ファイル末尾の技術ドキュメントにある情報が正式な根拠です。

<!--op-->## ガイドを最新に保つ

- 機能を追加または変更した場合は、上記の**機能一覧**と説明するファイルを更新し、そのファイルの末尾の「関連項目」に関連機能へのリンクを追加します。
- 各セクションにはリンク用のアンカー`<a id="…"></a>`があります。使用中のアンカー名は変更しないでください。内部リンクまたはアンカーが壊れている場合、`tests/unit/user-guide-links.test.ts`テストがエラーを報告します。
- 料金、しきい値、リリースフラグはソースコードに基づきます。食い違う場合はソースコードが正しいため、ガイドを合わせて更新してください。
- 最終更新日: 10/03/2026。
- 第1～9章、第12章、第13章はアプリ内（`/docs`と保護者エリアの「?」）にも表示されます。Markdownを編集した後、`npm run guide:build`を実行して`public/guide`を再生成してください。実行し忘れた場合は`tests/unit/guide-build.test.ts`テストがエラーを報告します。運用担当者専用の内容をHTMLコメントの組（`<!-- op -->`と`<!-- /op -->`。ここでは効果が出ないよう空白を加えて表記）で囲むと、アプリには表示されません。
- **翻訳**: 各章の翻訳を同じファイル名で`docs/huong-dan/i18n/<言語コード>/`に置き、`<a id="…"></a>`行、リンク先、表の行数と列数、リスト項目数をすべて維持します。`src/lib/guide/guide-locale.ts`の`GUIDE_TRANSLATIONS`に言語コードを追加してから、`npm run guide:build`を実行します。`tests/unit/guide-translations.test.ts`テストは、各翻訳の構造をベトナム語版と比較します。ベトナム語の章を編集した場合は、対応する翻訳も更新してください。
- 新機能に「?」を追加するには、`src/lib/guide/help-topic-id.ts`にそのコードを追加し、`src/lib/guide/help-topics.ts`に既存のガイド項目を示す説明（ベトナム語と英語）を書いてから、画面上の見出しの横に`<HelpTip topic="…" />`を配置します。
