# 13. Begriffe

Begriffe, die in der Dokumentation verwendet werden, alphabetisch geordnet und mit Links zu ausführlichen Erläuterungen.

| Begriff | Bedeutung in KidHabit | Siehe |
|---|---|---|
| **Arten des Gebens (7 Arten des Gebens)** | Sieben einfache Möglichkeiten, jeden Tag etwas zu geben: lächeln, Blickkontakt, freundliche Worte, Dankbarkeit, Nachsicht, hilfreiches Handeln und anderen den Vortritt lassen | [6](06-khoa-hoc-thoi-quen.md#chan-dung) |
| **Kind** | Ein Kinderprofil in der Familie; über ein gekoppeltes Gerät wird die Kinderansicht geöffnet | [2](02-man-hinh-be.md) |
| **Spitzname** | Der Name, der in der Rangliste statt des echten Namens des Kindes angezeigt wird | [5](05-gia-dinh-va-cai-dat.md#ho-so) |
| **Rangliste** | Rangfolge nach den im Zeitraum verdienten Sternen: Familie, Gruppe oder öffentlich | [2](02-man-hinh-be.md#bang-xep-hang) |
| **Stufe** | Steigt mit jeweils 100 verdienten Sternen | [2](02-man-hinh-be.md#sao-cap-chuoi) |
| **Persönlichkeitsprofil (16 Profile)** | Eine Entwicklungsrichtung, kein Persönlichkeitstyp; jedes Profil ist ein Abzeichen | [6](06-khoa-hoc-thoi-quen.md#chan-dung) |
| **Familieninhaber** | Person, die die Familie erstellt hat und Familiendaten löschen kann | [1](01-bat-dau.md#vai-tro) |
| **Gewohnheitsprogramm** | Eine Schritt für Schritt aufgebaute Gruppe von Gewohnheiten mit Hinweisen und Phasenverfolgung | [4](04-thiet-ke-thoi-quen.md#chuong-trinh) |
| **Serie (Flamme)** | Anzahl aufeinanderfolgender Tage mit bestätigten Aufgaben; ein leerer Pausentag beendet die Serie nicht | [2](02-man-hinh-be.md#sao-cap-chuoi) |
| **Gutschein / Geschenkcode** | Ein Code, der dem Tarifzeitraum zusätzliche Tage hinzufügt | [7](07-goi-va-thanh-toan.md#coupon) |
| **Kostenlose Testphase** | 7 kostenlose Tage, einmal pro Familie, ohne automatische Abbuchung | [7](07-goi-va-thanh-toan.md#dung-thu) |
| **Bestätigung** | Ein Elternteil bestätigt eine Aufgabe oder Belohnung des Kindes | [3](03-hom-nay-va-duyet-viec.md#duyet) |
| **Nutzungsrecht** | Was der aktuelle Tarif ermöglicht, zum Beispiel die Anzahl der Kinder; ist mit der Familie verknüpft | [7](07-goi-va-thanh-toan.md#cac-goi) |
| **Familie** | Einheit für Daten und Zahlungen; jede Familie hat einen eigenen „Bereich“ | [9](09-bao-mat-va-rieng-tu.md#ai-thay) |
| **Altersstufe (GD1–GD5)** | Die fünf Altersstufen des Rahmenwerks: 0–3, 3–6, 6–12, 12–15, 15–18 | [6](06-khoa-hoc-thoi-quen.md#khung) |
| **Gewohnheitsstufe / Phase** | Die vier Phasen einer Gewohnheit: den Auslöser verankern, die Routine aufbauen, Unterstützung reduzieren und sie zur Gewohnheit machen | [6](06-khoa-hoc-thoi-quen.md#bon-pha) |
| **Gerätekopplung** | Verknüpft ein Gerät über einen Code oder QR-Code mit einem bestimmten Kind | [5](05-gia-dinh-va-cai-dat.md#ghep-thiet-bi) |
| **Altersgerechtes Paket** | Eine Auswahl von sechs Startaufgaben, die mit einem Tippen für die Altersgruppe des Kindes geladen werden | [5](05-gia-dinh-va-cai-dat.md#ho-so) |
| **Ligastufe** | Bronze, Silber, Gold oder Diamant, basierend auf den insgesamt verdienten Sternen | [2](02-man-hinh-be.md#sao-cap-chuoi) |
| **Provision** | 30 % des tatsächlichen Betrags, den eine geworbene Familie bezahlt hat | [8](08-gioi-thieu-ban-be.md#hoa-hong) |
| **Heute** | Erster Elternbereich: Bestätigungen und Analysen | [3](03-hom-nay-va-duyet-viec.md) |
| **Abzeichen** | Eine Belohnung, die bei einem erreichten Meilenstein freigeschaltet wird: 5 einfache und 16 Profilabzeichen | [2](02-man-hinh-be.md#huy-hieu) |
| **Rahmenwerk mit 47 Gewohnheiten** | Gewohnheiten für das Alter von 0 bis 18 Jahren, aufgeteilt auf 5 Stufen und 5 Bereiche | [6](06-khoa-hoc-thoi-quen.md#khung) |
| **Belohnungsbibliothek** | Eine Liste von Belohnungen, die Eltern für ihr Kind erstellen | [4](04-thiet-ke-thoi-quen.md#kho-qua) |
| **Altersgerechter Entwicklungsplan** | Fünf Stufen mit jeweils drei Schritten; bei jedem Schritt kommt eine Gewohnheit hinzu | [4](04-thiet-ke-thoi-quen.md#lo-trinh) |
| **Maskottchen** | Sechs Figuren, die das Kind begleiten: Leo, Bunny, Panda, Fox, Turtle und Bee | [2](02-man-hinh-be.md#linh-vat) |
| **Kopplungscode / Verbindungscode** | Ein fester Code für jedes Kind; er öffnet nur dessen Profil | [9](09-bao-mat-va-rieng-tu.md#ma-ghep) |
| **Empfehlungscode** | Ein 8-stelliger Code, der an den `?ref=`-Link angehängt ist | [8](08-gioi-thieu-ban-be.md) |
| **Betreuungsperson** | Ein Familienmitglied, das eingeladen wurde, den Fortschritt im Nur-Lese-Modus anzusehen | [5](05-gia-dinh-va-cai-dat.md#nguoi-cham-soc) |
| **PayOS / VietQR** | Zahlungsdienst für Banküberweisungen per Bank-QR-Code | [7](07-goi-va-thanh-toan.md#thanh-toan) |
| **Eltern-PIN** | Ein 4-stelliger Code, der den Elternmodus und sensible Aktionen schützt und den Zugriff für 2 Stunden freischaltet | [5](05-gia-dinh-va-cai-dat.md#pin) |
| **PWA** | Installiert die Website als App auf dem Startbildschirm | [5](05-gia-dinh-va-cai-dat.md#pwa) |

| **„Wenn …, dann …“-Hinweis** | Ein Plan, der eine Gewohnheit mit einer vertrauten Tätigkeit oder einer festen Uhrzeit verknüpft | [4](04-thiet-ke-thoi-quen.md#chuong-trinh) |
