# 13. Glosario

[← 12. Mapa de conexiones y escenarios](12-ban-do-lien-ket.md) · [Índice](README.md)

Términos utilizados en toda la documentación, en orden alfabético, con enlaces a explicaciones detalladas.

| Término | Significado en KidHabit | Consulte |
|---|---|---|
| **Actos de dar (7 formas de dar)** | Siete maneras sencillas de contribuir cada día: una sonrisa, contacto visual, palabras amables, gratitud, tolerancia, acciones útiles y ceder el paso a los demás | [6](06-khoa-hoc-thoi-quen.md#chan-dung) |
| **Niño** | Perfil de un niño de la familia; se usa un dispositivo vinculado para abrir su pantalla | [2](02-man-hinh-be.md) |
| **Apodo** | Nombre que aparece en la clasificación en lugar del nombre real del niño | [5](05-gia-dinh-va-cai-dat.md#ho-so) |
| **Clasificación** | Posiciones basadas en las estrellas obtenidas durante el periodo: familiar, de grupo o pública | [2](02-man-hinh-be.md#bang-xep-hang) |
| **Nivel** | Aumenta cada vez que se obtienen 100 estrellas | [2](02-man-hinh-be.md#sao-cap-chuoi) |
| **Retrato (16 retratos)** | Dirección de crecimiento, no tipo de personalidad; cada retrato corresponde a una insignia | [6](06-khoa-hoc-thoi-quen.md#chan-dung) |
| **Propietario de la familia** | Persona que creó la familia; puede eliminar sus datos | [1](01-bat-dau.md#vai-tro) |
| **Programa de hábitos** | Grupo de hábitos que se desarrollan paso a paso, con señales y seguimiento de fases | [4](04-thiet-ke-thoi-quen.md#chuong-trinh) |
| **Racha (llama)** | Cantidad de días consecutivos con tareas confirmadas; dejar un día vacío para descansar no termina la racha | [2](02-man-hinh-be.md#sao-cap-chuoi) |
| **Cupón / código de regalo** | Código que añade días al periodo del plan | [7](07-goi-va-thanh-toan.md#coupon) |
| **Prueba gratuita** | 7 días gratis, una vez por familia, sin cargos automáticos | [7](07-goi-va-thanh-toan.md#dung-thu) |
| **Aprobación** | Confirmación de los padres de una tarea o recompensa del niño | [3](03-hom-nay-va-duyet-viec.md#duyet) |
| **Derecho del plan** | Lo que permite el plan actual, como la cantidad de niños; está vinculado a la familia | [7](07-goi-va-thanh-toan.md#cac-goi) |
| **Familia** | Unidad de datos y pago; cada familia es un «espacio» independiente | [9](09-bao-mat-va-rieng-tu.md#ai-thay) |
| **Etapa (GD1–GD5)** | Las cinco etapas de edad del marco: 0–3, 3–6, 6–12, 12–15 y 15–18 | [6](06-khoa-hoc-thoi-quen.md#khung) |
| **Fase / etapa del hábito** | Las cuatro fases de un hábito: fijar la señal, desarrollar la rutina, reducir el apoyo y convertirlo en hábito | [6](06-khoa-hoc-thoi-quen.md#bon-pha) |
| **Vinculación de dispositivo** | Vincula un dispositivo a un niño concreto mediante un código o código QR | [5](05-gia-dinh-va-cai-dat.md#ghep-thiet-bi) |
| **Paquete según la edad** | Conjunto de seis tareas iniciales que se carga con un toque para el grupo de edad del niño | [5](05-gia-dinh-va-cai-dat.md#ho-so) |
| **Categoría de liga** | Bronce, Plata, Oro o Diamante según el total de estrellas obtenidas | [2](02-man-hinh-be.md#sao-cap-chuoi) |
| **Comisión** | 30% del importe real pagado por una familia recomendada | [8](08-gioi-thieu-ban-be.md#hoa-hong) |
| **Hoy** | Primera área para padres: Aprobaciones y Estadísticas | [3](03-hom-nay-va-duyet-viec.md) |
| **Insignia** | Recompensa que se desbloquea al alcanzar un hito: 5 insignias básicas y 16 insignias de retrato | [2](02-man-hinh-be.md#huy-hieu) |
| **Marco de 47 hábitos** | Conjunto de hábitos para edades de 0 a 18 años, en 5 etapas y 5 ámbitos | [6](06-khoa-hoc-thoi-quen.md#khung) |
| **Tienda de recompensas** | Lista de recompensas que los padres crean para su hijo | [4](04-thiet-ke-thoi-quen.md#kho-qua) |
| **Recorrido por edad** | Cinco etapas, tres pasos por etapa y un hábito adicional en cada paso | [4](04-thiet-ke-thoi-quen.md#lo-trinh) |
| **Mascota** | Seis personajes que acompañan al niño: Leo, Bunny, Panda, Fox, Turtle y Bee | [2](02-man-hinh-be.md#linh-vat) |
| **Código de vinculación / conexión** | Código fijo de cada niño; solo abre su perfil | [9](09-bao-mat-va-rieng-tu.md#ma-ghep) |
| **Código de recomendación** | Código de 8 caracteres asociado al enlace `?ref=` | [8](08-gioi-thieu-ban-be.md) |
| **Cuidador** | Familiar invitado para consultar el progreso en modo de solo lectura | [5](05-gia-dinh-va-cai-dat.md#nguoi-cham-soc) |
| **PayOS / VietQR** | Pasarela de pago para transferencias bancarias mediante un código QR bancario | [7](07-goi-va-thanh-toan.md#thanh-toan) |
| **PIN parental** | Código de 4 dígitos que protege el modo para padres y las acciones sensibles; desbloquea el acceso durante 2 horas | [5](05-gia-dinh-va-cai-dat.md#pin) |
| **PWA** | Instala el sitio web como aplicación en la pantalla de inicio | [5](05-gia-dinh-va-cai-dat.md#pwa) |
| **Estrellas** | Puntos de recompensa que se usan para canjear recompensas y construir la ciudad | [2](02-man-hinh-be.md#sao-cap-chuoi) |
| **Descanso** | Pausa los recordatorios de progreso y las rachas de toda la familia sin perder datos | [5](05-gia-dinh-va-cai-dat.md#tam-nghi) |
| **Aprendizaje por imitación** | Los padres dan ejemplo mediante sus propias acciones | [6](06-khoa-hoc-thoi-quen.md#chan-dung) |
| **Señal «Si… entonces…»** | Plan que vincula un hábito a una actividad conocida o una hora fija | [4](04-thiet-ke-thoi-quen.md#chuong-trinh) |
| **Más tarde (aplazar)** | El niño pasa una tarea al final del día; no cuenta como incumplida | [2](02-man-hinh-be.md#hoan-thanh) |
| **Webhook / conciliación** | PayOS informa del pago; el sistema también vuelve a consultar PayOS para confirmarlo | [7](07-goi-va-thanh-toan.md#kich-hoat) |
| **Verificación en dos pasos (administración)** | Código TOTP requerido para las cuentas de administrador | [10](10-quan-tri-va-van-hanh.md#admin) |
