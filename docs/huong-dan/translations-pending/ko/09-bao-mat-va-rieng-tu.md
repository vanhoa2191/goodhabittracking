이 페이지는 KidHabit이 자녀 데이터를 보호하기 위해 하는 일을 쉬운 말로 설명합니다. 기술 세부 정보는 [보안 및 개인정보](../security-privacy.md)를 참조하세요.

<a id="du-lieu"></a>
## 저장되는 데이터

앱은 자녀 프로필(이름, 별명, 나이), 습관, 진행 상황, 포인트, 보상, 연결된 기기, 구독 요금제 및 부모 연락처(전체 이름, 전화번호, 이메일)를 저장합니다. 선택 기능에는 한 문장 일기, 단서 계획, 자녀의 각 시도 방법, 위시리스트도 포함될 수 있습니다. 자녀 데이터, 세션 코드, PIN, PayOS 키 또는 웹훅 내용은 어떤 분석 시스템에도 **절대 전송하지 않습니다**.

<a id="ai-thay"></a>
## 정보를 볼 수 있는 사람

| 사용자 | 볼 수 있는 정보 | 볼 수 없는 정보 |
|---|---|---|
| 부모 | 본인 가족에 속한 모든 데이터 | 다른 가족 데이터 |
| 돌봄 제공자 | 자녀 이름, 활성 습관(반복 일정 포함), 각 자녀의 완료 또는 승인된 시도 수, 최근 7일의 날짜별 개수. 읽기 전용입니다. | 변경 불가. 개별 시도, 시간대, 메모, 나이, 별명, 보상, 그룹, 구독, 결제, 설정 또는 다른 구성원은 볼 수 없습니다. |
| 자녀(연결된 기기) | 본인 데이터 | 다른 자녀 프로필, 결제, 설정 또는 PIN |
| 운영자 | 부모 프로필(이름, 이메일, 전화번호), 구독 요금제, 주문. 모든 작업이 기록됩니다. | 자녀 프로필, 할 일 또는 자녀 일기 |

데이터베이스 수준에서 각 가족은 서로 분리된 “구획”에 저장됩니다. 앱에 화면 오류가 있더라도 한 계정이 다른 가족의 데이터를 읽거나 쓸 수 없습니다. 모든 데이터는 `family_id`에 속합니다. 요금제와 혜택도 이메일 주소가 아니라 가족에 연결됩니다.

<a id="ma-ghep"></a>
## 자녀 연결 코드

- 코드마다 자녀 프로필 **하나만** 열 수 있으며 PIN이나 가족 데이터가 포함되지 않습니다. 데이터베이스에는 코드의 해시만 저장됩니다.
- 자녀 기기 세션은 페이지 스크립트가 읽을 수 없는 HTTP 전용 쿠키에 저장됩니다. 각 요청은 자녀 한 명의 데이터만 반환합니다.
- 코드를 반복해서 잘못 입력하면 **요청 제한**이 적용됩니다.
- 부모는 언제든 **코드를 새로 발급**(기존 코드 무효화)하거나 개별 기기 접근을 **해제**할 수 있습니다([5](05-gia-dinh-va-cai-dat.md#ghep-thiet-bi)). 코드를 보거나 변경하거나 해제할 때 PIN이 필요합니다.

<a id="pin"></a>
## PIN

숫자 4자리 PIN은 **서버에서** 확인합니다. PIN을 올바르게 입력하면 브라우저에 부모 및 가족 계정에 연결된 서명된 잠금 해제 쿠키가 제공됩니다. **2시간** 동안 유효하며 다시 잠그면 삭제됩니다. PIN을 설정한 가족은 잠금 해제 전까지 민감한 작업을 할 수 없습니다: 가족 삭제, 기기 접근 해제, 연결 코드 확인 또는 변경, 결제 생성, 할 일 및 보상 승인, 별 직접 지급 또는 차감, 추천 수익 정보 확인. 자녀는 부모 기기에서 PIN 없이 할 일을 완료 표시할 수 있습니다. PIN 설정 방법은 [5](05-gia-dinh-va-cai-dat.md#pin)를 참조하세요.

<a id="dong-thuan"></a>
## 동의

- [가족 설정](01-bat-dau.md#thiet-lap) 중 성인은 본인이 부모 또는 법적 보호자임을 확인하고 자녀 데이터 저장에 동의해야 합니다. 동의는 **정책 버전**과 함께 저장됩니다.
- 공개 순위표, 익명 분석, 알림 및 홍보 혜택은 모두 **선택 사항**이고 기본적으로 **꺼져 있으며**, 다시 끌 수 있습니다. 동의 철회는 동의 기록을 삭제하는 대신 시각으로 보관합니다.
- 돌봄 제공자는 부모가 만든 일회용 초대(72시간 후 만료)로만 가족에 참여할 수 있으며 초대를 취소할 수 있습니다([5](05-gia-dinh-va-cai-dat.md#nguoi-cham-soc)).

<a id="bxh-cong-khai"></a>
## 공개 순위표

다음 두 조건을 **모두** 충족하는 경우에만 자녀가 공개 순위표에 표시됩니다. 가족이 공유를 켰고(기본 꺼짐, 부모만 변경 가능), 자녀 프로필에서 참여하도록 설정해야 합니다(새 프로필은 기본 비공개). 순위표에는 별명(또는 “슈퍼 키드”), 아바타, 해당 기간에 얻은 포인트, 연속 기록, 순위만 표시됩니다. 자녀 코드, 가족 코드, 실명 또는 나이는 **포함되지 않습니다**. 포인트는 현재 잔액이 아니라 해당 기간에 확인된 기록으로 산정되므로 보상에 별을 써도 순위가 바뀌지 않습니다. 가족 및 그룹 순위표는 각각의 범위에 속한 데이터만 사용합니다. 설정: [5](05-gia-dinh-va-cai-dat.md#rieng-tu), 자녀 화면: [2](02-man-hinh-be.md#bang-xep-hang).

<a id="chia-se"></a>
## 이정표 공유

“긍정적인 이정표 공유”([3](03-hom-nay-va-duyet-viec.md#thong-ke))는 기기의 공유 패널을 열기 전에 부모에게 항상 **미리 보기와 확인 기회**를 제공합니다. 기본 내용에는 자녀 이름, 나이, 사진 또는 할 일이 없으며 추적 코드도 없습니다.

<a id="gioi-thieu-rieng-tu"></a>
## 추천 프로그램

추천 코드는 `kidhabit_ref` 쿠키에 60일간 저장된 후 기록되면 삭제됩니다. 승인된 관리자만 추천인의 은행 정보를 볼 수 있으며 추천인은 계좌 번호 끝 네 자리만 볼 수 있습니다. 추천인은 추천받은 가족 정보를 **절대 볼 수 없습니다**([8](08-gioi-thieu-ban-be.md)).

<a id="goi-y-ai"></a>
## AI 제안

이 기능은 순차적으로 활성화되고 있으며 기본값은 **꺼짐**입니다. 설정 → 개인정보의 **AI 제안** 카드에서 동의한 경우에만 표시됩니다. 제안 버튼을 누르면 앱이 AI 모델(Cloudflare Workers AI)에 초안 작성을 요청합니다.

- **AI로 작은 단계 제안**(습관 양식): 방금 입력한 **습관 이름만**(링크, 이메일, 전화번호는 제거)과 연령대를 전송합니다.
- **AI로 한 주 요약**: 습관 이름이나 자녀 이름 없이 **주간 횟수만**(혼자 완료, 알림과 함께, 함께, 미완료) 전송합니다.

**전송하지 않는 정보**: 자녀 이름이나 별명, 일기, 자녀가 작성한 내용, 사진, 부모 이메일. 전송 내용과 응답은 **시스템 로그에 기록되지 않습니다**. 결과는 “AI가 작성한 초안”으로 표시되는 제안일 뿐입니다. 부모가 읽고 **사용** 또는 **닫기**를 선택하며 앱이 자동으로 적용하지 않습니다. 가족마다 하루에 사용할 수 있는 제안 수가 제한되며 공동 허용량을 모두 사용하면 기능이 일시 중지됩니다. 다른 민감한 작업과 마찬가지로 PIN이 필요합니다. 스위치를 끄면 즉시 중단됩니다.

<a id="do-luong"></a>
## 분석 및 알림

- **익명 분석**에는 엄격한 경계가 있습니다. 이벤트에 이름, 습관 내용, 자녀/가족/사용자 코드, 연결 코드, 결제 데이터 또는 정확한 시각은 포함되지 않습니다. 현재 **데이터 수집 대상이 설정되어 있지 않으므로** 부모가 동의해도 기기 밖으로 나가지 않습니다. 실제 측정 없이 DAU, 유지율, NPS 등의 지표를 공개하지 않습니다. [제품 분석](../product-analytics.md)을 참조하세요.
- **알림**은 승인이 필요한 할 일을 알리는 데만 사용하며 광고에는 사용하지 않습니다.
- 자녀의 각 시도 방법 및 단서 계획 데이터는 **부모에게 제안하기 위한 용도로만** 사용하며 자녀 순위를 매기거나 비교하지 않습니다([6](06-khoa-hoc-thoi-quen.md#logic)).

<a id="xoa-du-lieu"></a>
## 데이터 다운로드 및 삭제

- **다운로드**: 가족 데이터 JSON 사본([5](05-gia-dinh-va-cai-dat.md#du-lieu))과 한 문장 일기 CSV([3](03-hom-nay-va-duyet-viec.md#thong-ke)). 자녀 데이터가 포함되므로 비공개로 보관하세요.
- **영구 삭제**: **가족 소유자**만 `Today → Analytics`에서 `DELETE FAMILY`를 정확히 입력해 진행할 수 있습니다(PIN이 설정되어 있으면 필요). 자녀 프로필, 습관, 진행 상황, 보상, 연결된 기기 및 연결 세션이 삭제되며 취소할 수 없습니다. 로그인 계정을 복구해도 삭제된 데이터는 복구되지 않습니다([데이터 복구](../data-recovery.md)).

<a id="ky-thuat"></a>
## 기술적 보호 조치

| 보호 조치 | 사용자에게 의미하는 점 |
|---|---|
| 가족 분리 및 트랜잭션 내 행 수준 잠금 | 서로 다른 가족의 데이터가 섞이지 않습니다. |
| 쿠키 기반 쓰기 요청은 모두 교차 출처 요청을 거부 | 알 수 없는 사이트가 사용자를 대신해 작업할 수 없습니다. |
| PayOS “실패 시 닫힘”: 서명, 금액, 내용, 주문 소유자 및 중복 처리 확인 | 가짜 알림으로 요금제를 활성화할 수 없습니다. |
| 일회용 체험 및 데이터베이스 수준 요금제 확인 | 인터페이스를 바꿔 제한을 우회할 수 없습니다. |
| 콘텐츠 보안 정책(CSP), 프레임 보호 및 최소한의 브라우저 권한 | 악성 코드 위험을 줄입니다. |
| 민감한 기능은 서버에서만 처리하고 새 기능은 기본적으로 닫힘 | 악용 가능한 범위를 줄입니다. |
| 관리자에게 2단계 인증을 요구하고 모든 작업과 사유를 기록 | 추적 및 통제가 가능합니다. |

<a id="phap-ly"></a>
## 법적 한계

기본 설정은 아동 데이터에 대해 **보수적으로** 설계되었지만 COPPA 또는 GDPR-K 준수 **인증을 의미하지 않습니다**. 특정 시장에서 공개 순위표를 켜기 전에 동의 연령, 보관 기간, 접근 권리 및 삭제 권리를 포함한 법률 검토를 받으세요. 법적 승인 플래그가 켜질 때까지 [웹사이트](11-website-va-trang-cong-khai.md#phap-ly-web)의 `Privacy`, `Terms`, `Contact` 페이지는 초안(검색 색인 제외, 바닥글 및 결제 화면에 표시되지 않음)으로 남아 있을 수 있습니다. 사고를 신고할 때 공개 채널로 비밀 정보나 자녀 데이터를 보내지 마세요.
