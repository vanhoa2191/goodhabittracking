**설계** 영역(`Design`)에는 습관, 연령별 로드맵, 보상 세 섹션이 있습니다. 이용하려면 요금제 또는 체험이 활성화되어 있어야 합니다([7](07-goi-va-thanh-toan.md)).

<a id="quan-ly-viec"></a>
## 습관 관리

`Design → Habits`에는 세 가지 보기가 있습니다.

| 보기 | 용도 |
|---|---|
| **사용 중** | 할당된 습관 확인, 자녀 또는 “모든 자녀”로 필터링, 최근 7일 완료 보기, 수정, 삭제, 단서 설정 |
| **라이브러리** | 템플릿 라이브러리에서 더 선택([라이브러리](#thu-vien)) |
| **프로그램** | 단계별로 형성할 습관 묶음 시작([프로그램](#chuong-trinh)). 베트남어에서만 표시 |

각 습관 카드는 **자녀 한 명** 또는 **가족 전체**(“할당 대상”)에 적용됩니다. 일시 중지한 습관은 저장된 상태로 남지만 [자녀 화면](02-man-hinh-be.md#nhiem-vu)에는 표시되지 않습니다.

<a id="tao-viec"></a>
## 습관 만들기 또는 수정

“새 습관 만들기” 버튼을 누르면 양식이 열립니다.

| 필드 | 의미 |
|---|---|
| 습관 제목 | 예: “식사 전에 손 씻기” |
| 설명 및 목적 | 자녀가 [할 일 세부 정보](02-man-hinh-be.md#chi-tiet)의 “중요한 이유”에서 읽습니다. |
| 아이콘 | 습관을 나타내는 작은 이미지 |
| 발달 영역 | 건강한 식사, 선행, 자기 돌봄, 학습, 건강, 덕목, 마음가짐 등 |
| 별 보상 | 습관을 완료할 때 자녀가 받는 별 |
| 반복 | 매일, 월~금, 토·일 또는 요일 지정 |
| 시간대 | 아침, 오후, 저녁 또는 아무 때나 |
| 타이머 카운트다운 | [타이머](02-man-hinh-be.md#dem-gio)에 사용할 분 수. 0은 카운트다운 없음 |
| 부모 승인 필요 | 켜면 자녀가 완료 표시한 후 부모가 [승인](03-hom-nay-va-duyet-viec.md#duyet)할 때까지 별을 **받지 않습니다**. |
| 할당 대상 | 모든 자녀 또는 한 자녀 |

라이브러리나 로드맵에서 템플릿을 적용한 뒤에도 부모가 가족 일정에 맞게 시간과 별을 조정하고 습관을 추가하거나 삭제할 수 있습니다. 습관 완료는 자녀 한 명당 하루 **한 번만** 기록됩니다(여러 번 눌러도 중복 계산되지 않음).

<a id="thu-vien"></a>
## 라이브러리

라이브러리는 사용 중인 언어에 따라 달라집니다.

- **베트남어**: [0~18세용 47가지 습관 체계](#khung-47).
- **기타 언어**: “어린이를 위한 추천 습관 라이브러리”가 제공되며 건강한 식사, 선행과 나눔, 덕목, 마음가짐, 조화로운 인성, 지혜와 학습, 역량과 자립, 신체 활력의 여덟 그룹으로 제안이 구성되고 이름과 설명이 해당 언어로 번역되어 있습니다. “할 일 목록에 추가”를 눌러 일정에 추가합니다.

두 라이브러리 외에도 [자녀](05-gia-dinh-va-cai-dat.md#ho-so)에서 **연령별 습관 팩**(시작 습관 여섯 개)을 불러오거나 [연령별 로드맵](#lo-trinh)을 적용할 수 있습니다.

<a id="khung-47"></a>
## 0~18세용 47가지 습관 체계

베트남어 라이브러리에는 **습관 체계**가 들어 있습니다([6의 체계 설명](06-khoa-hoc-thoi-quen.md#khung)). 이용 방법:

1. **발달 단계**(5단계)와 습관 **영역**(내면, 건강, 관계, 학습, 돈 또는 “전체”)을 선택합니다.
2. 각 카드에는 권장 연령대, **진행 신호**, 성인의 역할, 자녀의 자기 추적 방법 및 **“방법과 지원 방식 보기”** 버튼이 있습니다. 나이는 참고 기준일 뿐이므로 자녀의 실제 능력에 맞추세요.
3. **“할 일 목록에 추가”**를 누릅니다. 카드가 “가족에 추가됨”으로 바뀝니다. 체계에서 추가한 습관은 **가족 전체에 공유**됩니다. 특정 자녀에게 할당하려면 “할당 대상”을 수정([습관 만들기 또는 수정](#tao-viec))하거나, 적용할 때 자녀를 선택할 수 있는 [프로그램](#chuong-trinh) 또는 [연령별 로드맵](#lo-trinh)을 사용하세요. 카드에는 최근 7일 완료 수도 표시됩니다.

체계에서 추가한 습관은 원래 습관(체계 코드)과 연결됩니다. 자녀가 완료하면 [초상 배지 16개](02-man-hinh-be.md#huy-hieu)와 [프로그램](#chuong-trinh)의 진행 상황이 기록됩니다. 건강 관련 내용은 참고용이며 전문가 조언을 대신하지 않습니다. 체계는 영어, 한국어, 프랑스어, 독일어, 이탈리아어, 스페인어, 중국어 및 일본어로 번역되어 있습니다. 번역이 없는 언어에서는 영어 버전을 사용합니다.

<a id="chuong-trinh"></a>
## 프로그램 및 단서

현재 활성화된 **적응형 습관 프로그램**은 한꺼번에 많은 습관을 할당하는 대신 단계별로 습관을 형성하도록 돕습니다.

**“만약… 그러면…” 단서**: 각 습관에 “양치한 다음 책을 한 쪽 읽어요”처럼 자녀가 직접 말하는 계획을 연결할 수 있습니다.

- 사용 중 습관 카드의 **단서** 버튼을 누르면 양식이 열립니다. 단서 유형(**익숙한 활동 후** 또는 **정해진 시각**), 자녀 말투의 계획, 시간대, 장소(선택), 주말이나 바쁜 날을 위한 계획(선택), 대상 자녀를 입력합니다. 단서가 설정된 카드에는 “단서 설정됨”이 표시됩니다.
- 기상 후, 아침 식사 후, 학교에서 돌아온 후, 저녁 식사 후, 밤에 양치한 후의 단서 템플릿 다섯 가지가 제공됩니다.

**프로그램 시작**(프로그램 보기, 베트남어만 지원): 자녀별로 앱이 습관 묶음을 제안하고 세 단계를 안내합니다.

1. **시작할 습관 선택**: 보통 한두 개의 적은 수로 시작하고 [연령별 권장 한도](03-hom-nay-va-duyet-viec.md#hom-nay)를 따릅니다. 한도를 초과해도 경고가 표시될 뿐 계속할 수 있습니다.
2. 템플릿이나 직접 쓴 말로 습관마다 **단서 설정**.
3. **확인**: 자녀에게 습관을 추가하고 단서를 저장합니다. 완료하면 “사용 중” 보기로 돌아갑니다.

단서를 설정하면 앱이 습관별 **단계**(단서 설정, 반복 행동 형성, 지원 줄이기, 일상으로 자리 잡음)를 추적하고 [자녀의 실천 방법](03-hom-nay-va-duyet-viec.md#muc-ho-tro)을 기록하며 오늘 화면에 [조정 제안](03-hom-nay-va-duyet-viec.md#tien-trien)을 제공합니다. 자세한 로직은 [6](06-khoa-hoc-thoi-quen.md#logic)에 있습니다.

<a id="lo-trinh"></a>
## 연령별 로드맵

`Design → Age Roadmaps`는 습관 연구에서 모든 사람에게 적용되는 보편적 일수를 제시하지 않기 때문에 이전의 고정 주간 또는 월간 로드맵을 대체합니다.

- **연령별 다섯 단계**: 0~3세 “안전과 감각”, 3~6세 “탐색과 의지력”, 6~12세 “근면함과 기술”, 12~15세 “정체성과 감정”, 15~18세 “방향성과 책임”. 단계별 성인의 역할은 본보기, 함께 하기, 지켜보기, 지원 또는 조언입니다.
- 각 단계는 약 **12주**이며 **세 걸음**으로 구성됩니다. **각 걸음마다 새 습관 하나만** 추가하고 이전 습관은 유지합니다. 주간 표시는 검토 시점이지 **마감일이 아닙니다**. 자녀에게 맞는 기간만큼 그 단계에 머물 수 있습니다.
- 선택한 자녀의 나이를 바탕으로 단계를 선택하며 다른 단계로 바꿀 수도 있습니다. 각 걸음에 할당 및 연습한 습관 수와 현재 걸음이 표시됩니다.
- 걸음을 눌러 **세부 정보 보기**, “어느 자녀에게 적용할까요?” 선택 후 **확인 및 적용**을 누릅니다. 자녀의 매일 일정에 습관이 추가되며 이미 할당된 습관은 중복되지 않습니다.

베트남어 탭에는 로드맵은 **습관을 추가하는 순서**만 제안하며 [프로그램](#chuong-trinh)은 자녀의 속도에 맞춘다는 안내도 있습니다.

<a id="kho-qua"></a>
## 보상 상점

`Design → Rewards`에서 부모가 자녀가 별로 신청할 보상을 만듭니다([자녀의 보상 신청 방법](02-man-hinh-be.md#qua)).

- **보상 만들기**: 보상 이름, 필요한 별(5개부터), 설명 또는 조건을 설정합니다. 여기서 만든 보상은 신청 횟수 제한이 없습니다. 수정하거나 삭제할 수 있습니다.
- **의미 있는 보상 아이디어**: 템플릿 라이브러리에는 **경험**(함께하는 시간, 체험, 선택권)과 **목적 있는 물건**(취미, 움직임, 학습, 나눔의 정신 지원) 두 유형이 있고 추천 별 수가 나옵니다. “보상에 추가”를 선택하세요.
- 자녀 요청은 [오늘 → 승인](03-hom-nay-va-duyet-viec.md#duyet)에 표시됩니다.

앱은 물건보다 함께 보내는 시간과 경험을 우선하도록 권장합니다([인정 원칙](06-khoa-hoc-thoi-quen.md#nguyen-tac)).

<a id="ghep-lai"></a>
## 요소 연결 방식

```
47가지 습관 체계 ──추가──▶ 사용 중 습관 ◀──적용── 연령별 로드맵
        │                         │  ▲                    (연령별 팩)
        │ 체계 코드               │  └─ 직접 습관 만들기
        ▼                         ▼
  초상 배지 16개           단서 + 프로그램 ──▶ 단계, 제안(오늘)
                                  │
                                  ▼
                         자녀 완료 표시 ─▶ 승인 ─▶ 별 ─▶ 보상(보상 상점)
```

전체 앱 지도는 [12](12-ban-do-lien-ket.md#ban-do)에 있습니다.
