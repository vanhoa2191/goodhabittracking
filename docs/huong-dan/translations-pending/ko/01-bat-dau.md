## 앱에 들어가는 세 가지 방법

`app.kidhabithero.com`을 처음 열면 “KidHabit에 어떻게 들어가시겠어요?” 화면에 세 가지 옵션이 표시됩니다. 화면에 보이는 버튼 두 개와 자녀용 접이식 영역 하나입니다. 부모 영역과 자녀 영역은 분리되어 있어 자녀는 결제나 가족 설정을 볼 수 없습니다.

| 입장 옵션 | 대상 | 동작 |
|---|---|---|
| **부모로 계속하기** (Google로 로그인) | 부모 및 보호자 | 가족 대시보드([3](03-hom-nay-va-duyet-viec.md))를 엽니다. 처음에는 [가족 설정](#thiet-lap)을 진행합니다. |
| **자녀 기기인가요?** (열고 “코드 입력 또는 QR 스캔” 선택) | 자녀 | 기기가 자녀 한 명과 연결되고 [자녀 화면](02-man-hinh-be.md)이 바로 열립니다. 자녀 계정은 필요하지 않습니다. |
| **데모 둘러보기** (부모 버튼 아래에 표시) | 누구나 | 샘플 데이터를 사용하며 계정이 필요하지 않습니다([데모](#demo)). |

이미 로그인한 부모는 대시보드로 바로 이동합니다. 시작 페이지를 다시 보려면 “홈” 또는 “시작 페이지 보기”를 선택하세요. 자녀 기기를 연결하면 항상 자녀 인터페이스가 바로 열리며 부모 대시보드나 요금 페이지는 표시되지 않습니다.

<a id="dang-nhap"></a>
## 로그인

- **Google**은 부모를 위한 기본 로그인 방법입니다.
- **이메일로 전송되는 일회용 코드**는 두 번째 옵션이며, 현재 활성화될 때까지 **꺼져 있습니다**<!--op--> (`emailCodeLogin` 플래그, [활성화 방법](../deployment.md))<!--/op-->. 활성화하면 입장 화면에 “다른 로그인 방법” 접이식 영역이 표시됩니다. 열면 “또는 이메일로 로그인 코드 받기” 입력란이 나타납니다. 플래그가 꺼져 있으면 영역 자체가 없습니다. 부모가 이메일을 입력하면 짧은 숫자 코드가 전송되며, 이를 입력해 로그인합니다. 몇 초 후 다른 코드를 요청할 수 있습니다. 너무 많이 요청하면 몇 분 기다려야 합니다.
- 로그인이 실패하면 앱에서 짧은 안내와 재시도 버튼을 표시합니다. 아무것도 저장되지 않습니다.

추천 링크(`?ref=`)로 로그인한 부모는 자동으로 추천인으로 기록됩니다([8](08-gioi-thieu-ban-be.md#ghi-nhan)). 보호자로 초대된 분은 Google로 로그인한 다음 초대를 수락합니다([5](05-gia-dinh-va-cai-dat.md#nguoi-cham-soc)).

<a id="thiet-lap"></a>
## 첫 자녀 프로필 만들기

처음 입장하면 “자녀 연령별 계획으로 가족 만들기” 창에서 자녀 프로필만 생성합니다.

- **자녀의 전체 이름**(필수), 별명(선택), 나이(기본값 5세)를 입력합니다.
- **추가 맞춤 설정**을 열어 연령 단계를 확인하고, 마스코트(기본값 Leo)를 바꾸거나, 시작 습관 여섯 가지를 미리 보거나, 시작 습관 추가를 끌 수 있습니다(기본값 켜짐). 나중에 수정할 수 있습니다.

**자녀의 부모 또는 법적 보호자임을 확인**하고 KidHabit이 자녀의 프로필, 습관 및 진행 상황을 저장하는 데 동의해야 합니다. 동의는 정책 버전과 함께 기록됩니다([9](09-bao-mat-va-rieng-tu.md#dong-thuan)). 공개 순위표는 기본적으로 꺼져 있습니다.

가족에게 이용 중인 요금제가 없으면 설정을 완료할 때 **7일 무료 체험이 자동으로 시작됩니다**(버튼 문구: “7일 체험 시작”). 가족당 체험은 한 번만 이용할 수 있습니다([7](07-goi-va-thanh-toan.md#dung-thu)).

웹사이트에서 `/start`(“7일 체험 시작”)를 바로 열 수도 있습니다. Google로 로그인하고 가족을 설정한 다음 시작을 누르세요.

<a id="thong-tin"></a>
## 고객 정보

부모는 약관 및 추천 단계 전에 결제 시 **전체 이름과 전화번호**만 입력하면 됩니다. 전화번호는 숫자 9~15자리여야 합니다. 정보는 이후 결제를 위해 서버에 저장되며, 프로필을 완료한 경우 이 단계를 건너뜁니다. 로그인과 자녀 프로필 생성에는 이 요건이 적용되지 않습니다. 안내와 혜택 수신은 선택 사항이며 기본적으로 꺼져 있습니다. 나중에 `Family → Settings → Account`에서 정보를 수정할 수 있습니다([5](05-gia-dinh-va-cai-dat.md#tai-khoan)). 수신을 거부하면 홍보 이메일이 즉시 중단됩니다([7](07-goi-va-thanh-toan.md#email)). 불러오기나 저장에 실패하면 **다시 시도**를 누르세요.

<a id="vai-tro"></a>
## 가족 역할

| 역할 | 할 수 있는 일 | 할 수 없는 일 |
|---|---|---|
| **가족 소유자** (생성자) | 부모가 할 수 있는 모든 일, 결제, 가족 데이터 삭제 | 없음 |
| **부모 또는 보호자** | 자녀, 할 일, 보상, 승인 및 기기 관리 | 소유자 전용 작업(가족 삭제) |
| **돌봄 제공자** | “돌봄 제공자 보기”에서 진행 상황 확인 | 프로필, 할 일, 별 또는 요금제 수정 |
| **자녀** (연결된 기기) | 본인의 할 일 완료, 보상 요청, 일기 작성 | 결제, 설정 또는 다른 자녀 프로필 확인 |

가족의 부모만 체험을 시작하거나 결제할 수 있습니다. 민감한 작업에는 [PIN](05-gia-dinh-va-cai-dat.md#pin)도 필요합니다.

<a id="demo"></a>
## 데모

“데모 둘러보기”를 누르면 샘플 자녀 세 명(8세, 4세, 1세)과 샘플 할 일, 보상 및 그룹이 있는 앱이 열립니다. 데모 데이터는 현재 브라우저 탭에 저장되므로 페이지를 새로고침해도 유지됩니다. 실제 가족을 설정하거나 로그인하면 데모 데이터는 삭제되며 실제 데이터와 **섞이지 않습니다**. 데모는 서버로 데이터를 보내지 않으며 결제도 필요하지 않습니다.

<a id="ngon-ngu"></a>
## 언어

앱은 베트남어, 영어, 프랑스어, 독일어, 이탈리아어, 스페인어, 중국어, 일본어, 한국어를 지원합니다. 초기 언어는 저장된 선택, Cloudflare에서 확인한 국가, 브라우저 언어, 영어 순으로 선택됩니다. 상단 바의 언어 선택기에서 변경하세요. 선택한 언어가 저장되어 페이지, 제목 및 인터페이스에 계속 적용됩니다.

좁은 화면에서는 상단 바의 컨트롤이 **메뉴**(⋮ 버튼) 안으로 이동합니다. 메뉴에는 **계정**, **빠른 설정**(언어, 밝거나 어두운 화면, 글자 크기, 소리), **사용자 안내서** 링크가 있습니다. 자주 쓰지 않는 항목(요금, 자녀 연결 코드 입력, 16가지 강점 안내서, 가족 설정, 홈, 저장 상태)은 **더 보기**에 있으며 열기 전까지 닫혀 있습니다.

연령별 여정과 오늘 화면을 포함한 일부 상세 내용은 아직 9개 언어 모두로 번역되지 않았으며, 번역이 없는 경우 영어로 표시됩니다.

<a id="tro-giup"></a>
## 앱에서 도움말 찾기

이 안내서는 앱에 두 가지 형태로 포함되어 있습니다.

- **각 항목 옆의 ?** 부모 영역에서는 승인, 단서, PIN, 연결 코드, 결제 등의 기능 제목 옆에 작은 **?**가 표시됩니다. 마우스를 올리거나, 탭하거나, Tab 키로 이동하면 한두 문장으로 된 설명을 볼 수 있습니다. **자세히 보기**를 누르면 현재 화면을 떠나지 않고 안내서의 해당 부분이 열립니다. 창에서 다른 섹션 링크를 누르면 계속 읽을 수 있고, **뒤로**를 누르면 돌아갑니다. Esc를 누르거나 바깥을 탭하면 설명이 닫힙니다.
- **전용 안내서 페이지.** 상단 바의 **사용자 안내서** 버튼(또는 `Family → Settings → Open user guide`)을 누르면 `/docs`가 열립니다. 여기에는 장 목록, **검색** 상자(발음 기호 유무와 상관없이 입력 가능), 일반 작업을 위한 **“원하는 작업…”** 바로 가기 그룹, 각 장의 목차가 있습니다. 상세 창의 **전체 안내서 열기** 버튼도 이 페이지의 해당 위치로 이동합니다.

전체 안내서는 베트남어와 번역본으로 제공되며, 현재 영어가 포함되어 있습니다. 번역이 없는 언어에서는 ? 설명이 영어로 표시되고 상세 섹션은 베트남어로 표시되며 `/docs`에 간단한 요약이 제공됩니다.
