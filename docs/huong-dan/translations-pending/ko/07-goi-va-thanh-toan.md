<a id="dung-thu"></a>
## 7일 무료 체험

- **무료: 0 VND**, 신용카드가 필요하지 않으며 체험 종료 시 **자동 청구되지 않습니다**.
- 자녀 수 제한 없이 가족 요금제의 모든 기능을 이용할 수 있습니다.
- **가족당 한 번만** 이용할 수 있습니다. 이미 체험한 경우 시작 버튼에 “이 가족은 이미 체험을 사용했습니다. 계속하려면 요금제를 선택하세요.”라고 표시됩니다.
- 시작 방법: (a) 요금제가 없으면 [가족 설정](01-bat-dau.md#thiet-lap)의 마지막 단계에서 자동으로, (b) `/start`(“7일 체험 시작”)에서 Google 로그인, 가족 설정 후 시작 누르기, (c) 요금 창의 체험 패널에서 시작합니다. 가족의 부모만 체험을 시작할 수 있습니다.
- 가족이 결제한 후에는 체험 패널이 **다시 표시되지 않습니다**.
- 체험 종료가 가까워지면 시스템에서 알림 이메일을 보냅니다([이메일](#email)).

<a id="cac-goi"></a>
## 요금제

| 요금제 | 가격 | 자녀 수 | 적합한 경우 |
|---|---|---|---|
| **7일 무료 체험** | 0 VND | 무제한 | 결정하기 전에 모든 기능 사용 |
| **자녀 1명 요금제** | 월 29,000 VND | 자녀 1명 | 자녀 한 명과 시작하는 가족 |
| **가족 요금제 · 월간** | 월 49,000 VND | 무제한 | 자녀가 여러 명이거나 모든 기능 사용 |
| **가족 요금제 · 연간** | 연 399,000 VND (정가 588,000 VND, 189,000 VND 절약, 32%) | 무제한 | 작은 실천이 습관이 될 때까지 충분히 이용 |
| **평생 이용** | 판매하지 않음 | 무제한 | 관리자만 수동으로 부여<!--op--> ([10](10-quan-tri-va-van-hanh.md#khach-hang))<!--/op--> |

모든 결제는 **일회성 결제**이며 자동 갱신되지 않습니다. 요금 화면에는 가족 요금제 추가 혜택(주간 추적 보고서, 가족 대회, 빠른 기술 지원)과 연간 요금제 혜택(우선 지원 및 양육 안내 전자책)도 나옵니다. 전자책은 **아직 제공되지 않습니다**.

**지역별 이름 차이:** 마케팅 웹사이트에서는 *자녀 1명 요금제*를 “기본 요금제”, 두 가족 요금제를 “프리미엄 요금제”(월간 및 연간)라고 부릅니다. 같은 가격의 동일한 상품입니다.

**요금제별 자녀 수**는 데이터베이스에서 확인합니다. 자녀 1명 요금제는 최대 1명, 체험·가족·평생 이용 요금제는 제한이 없습니다. 활성 요금제가 없으면 새 자녀 프로필을 추가할 수 없습니다.

<a id="noi-mua"></a>
## 구매 위치

| 진입 경로 | 설명 |
|---|---|
| 상단 바의 **Pro로 업그레이드** 버튼 | 요금제를 선택할 수 있는 “KidHabit Hero Pro 요금” 창을 엽니다. |
| 요금제가 필요한 경우 표시되는 요금 창 | 예: 요금제 만료 후 |
| `/pricing` 페이지 및 [웹사이트](11-website-va-trang-cong-khai.md#trang-chinh)의 요금제 선택 버튼 | 앱의 `/checkout?plan=…`으로 이동합니다. |
| `/checkout` 페이지 | 선택한 요금제를 불러옵니다. 로그인하고 필요한 경우 가족을 설정한 다음 결제합니다. |

유효하지 않은 요금제 링크(정보가 오래되었거나 누락됨)는 “유효하지 않은 결제 요금제”와 요금 보기 버튼을 표시합니다. 이용 권한은 이메일 주소가 아니라 **가족**에 속합니다.

<a id="thanh-toan"></a>
## 결제 단계

결제는 **PayOS(VietQR)**를 통해 처리됩니다.

1. 요금제를 선택하고 필요한 경우 Google로 로그인한 다음 “결제 계속”을 누릅니다. 프로필이 미완료면 전체 이름과 전화번호를 입력합니다. 이후 결제를 위해 정보가 기억됩니다. 혜택 안내 수신은 선택 사항이며 기본적으로 꺼져 있습니다. 요청이 있으면 약관을 확인하고 가족이 대상인 경우에만 추천 코드를 입력합니다. 코드를 제출하는 동안 주문 생성이 비활성화됩니다. 서버가 주문 생성 시 결제 금액을 계산하므로 QR을 만들기 전까지만 코드를 입력할 수 있으며, 이 단계는 코드 적용 후 기존 주문을 대체하지 않습니다.
2. 결제 화면에 **VietQR 코드**와 수취인 이름, 은행, 계좌 번호, **정확한 금액**, **필수 송금 메모**가 표시됩니다. 각 항목 복사 버튼, **QR 코드 다운로드** 버튼(갤러리의 이미지를 선택해 은행 앱에서 스캔 가능), PayOS 보안 결제 페이지 링크가 있습니다. 복사에 실패하면 텍스트를 길게 눌러 선택한 뒤 직접 복사하세요. 서버가 15분 결제 기한을 적용하지 않으므로 카운트다운은 없습니다.
3. 은행 앱이나 MoMo로 스캔합니다. **정확한 금액과 송금 메모를 유지하세요.**
4. 필요한 경우 **“송금했습니다”**를 누릅니다. 앱이 상태를 자동으로 확인합니다. 상태 오류는 선택한 언어로 표시되며 자동 확인은 계속됩니다. 완료되면 “🎉 업그레이드 성공!”이 표시되고 요금제가 즉시 활성화됩니다.

결제가 대기 중이면 **곧바로 다시 결제하지 마세요**. 가격은 서버에서 정하며 브라우저에서 변경할 수 없습니다. 가족의 부모만 결제할 수 있으며, PIN을 설정한 경우 결제 생성 시 [PIN](05-gia-dinh-va-cai-dat.md#pin)이 필요합니다. PayOS 페이지에서 앱으로 돌아오면 결제 결과가 표시됩니다.

<a id="kich-hoat"></a>
## 활성화 및 대조 확인

세 가지 독립된 경로 중 하나로 시스템이 결제를 **확인하면** 요금제가 활성화됩니다. 먼저 도착한 확인이 적용되며 결제는 두 번 집계되지 않습니다.

1. PayOS의 **웹훅**이 `/api/payment/webhook`을 호출합니다(서명, 금액, 송금 메모, 주문 소유자 확인 포함).
2. **PayOS 조회**: 부모가 결제 화면에 있을 때 앱이 PayOS에 직접 주문 상태를 묻습니다. 웹훅에 의존하지 않습니다.
3. **백그라운드 대조 확인**: 10분마다 작업이 대기 주문을 검토하고 PayOS에 확인합니다.

송금했는데 요금제가 보이지 않으면 몇 분 기다리고 `/checkout`을 다시 연 다음 주문 코드와 함께 고객 지원에 문의하세요. <!--op-->운영팀은 [관리자 → 결제](10-quan-tri-va-van-hanh.md#thanh-toan-admin)에서 주문을 볼 수 있습니다.<!--/op-->

<a id="cong-don"></a>
## 기간 연장

현재 요금제가 활성화된 동안 구매하면 체험 잔여 기간을 포함해 현재 기간 끝에 **구매 기간이 더해집니다**. 월간 요금제는 1개월, 연간은 1년을 더합니다. 기존보다 낮은 요금제를 구매해도 **상위 요금제가 유지됩니다**. 평생 이용은 다른 요금제로 대체되지 않습니다.

<a id="coupon"></a>
## 선물 코드(쿠폰)

선물 코드는 운영팀이 만듭니다. `Settings → Account → Coupon code → Apply code`에서 입력합니다.

- 선물 코드는 이용 기간에 **날짜를 추가**합니다. 할인 전용 코드는 여기서 사용할 수 없습니다. 가족에게 유료 요금제가 없다면 해당 일수만큼 가족 요금제 · 월간으로 전환됩니다. 이미 요금제가 있으면 현재 기간 끝에 날짜가 더해지고 요금제는 그대로 유지됩니다. 평생 이용에는 적용할 수 없습니다.
- 가족마다 코드 하나를 **한 번만** 사용할 수 있습니다. 만료, 소진 또는 비활성 코드에는 “코드를 찾을 수 없거나 이미 사용했거나 만료되었습니다.”라고 표시됩니다.
- 15분 안에 실패가 **10회를 초과**하면 몇 분 동안 접근이 일시 차단됩니다.

<a id="giam-gia"></a>
## 추천 가족 할인

추천 코드(`?ref=` 링크 또는 직접 입력)를 입력한 가족은 이전에 유료 주문을 한 적이 없는 경우 첫 연간 요금제에 **10% 할인**을 받습니다(399,000 VND가 359,100 VND로 변경). 결제 화면에 “추천 코드로 10% 할인”이 표시됩니다. 자세한 내용: [8. 추천](08-gioi-thieu-ban-be.md#giam-10).

<a id="hoan-tien"></a>
## 환불 및 취소

- **30일 환불**: 만족하지 않으시면 결제일부터 30일 안에 주문 코드와 결제 시각을 고객 지원 이메일로 보내세요. 수동으로 환불을 처리합니다. 환불이 확인되면 해당 주문의 추천 수수료가 아직 보류 중인 경우 회수됩니다([8](08-gioi-thieu-ban-be.md#hoan-tien-hoa-hong)).
- **대기 중인 결제 링크**는 고객 지원팀이 취소할 수 있습니다. PayOS가 확인한 다음에만 주문 상태가 “취소됨”으로 바뀝니다.
- **요금제 취소**는 고객 지원팀이 처리하고 이메일로 확인합니다. 자동 청구는 없습니다.

<a id="email"></a>
## 이메일 안내

이메일은 두 그룹입니다.

- **로그인 이메일**(Supabase 발송): 가입 확인, 로그인 링크, 계정 복구, 초대, 이메일 변경, 재인증. 이메일 인터페이스는 미리 설계되어 있습니다([템플릿](../../supabase/email-templates/README.md)).
- **라이프사이클 이메일**(켜거나 끌 수 있음): 환영 및 설정 안내(`welcome_setup`), 체험 종료 알림(`trial_ending`), 결제 영수증(`payment_receipt`), 지원 요청 업데이트(`support_status`), 환불(`refund_status`), 요금제 취소 확인(`subscription_cancelled`).

라이프사이클 이메일에는 자녀 데이터가 **포함되지 않습니다**. 혜택 수신에 동의한 경우에만 홍보 이메일을 보내며 동의를 끄면 즉시 중단됩니다. 반송, 불만 접수 또는 수신 거부한 주소에는 추가 메일을 보내지 않습니다.

<a id="het-han"></a>
## 요금제 만료

체험 또는 요금제가 갱신되지 않고 만료되면 가족은 더 이상 요금제를 보유한 것으로 간주되지 않습니다. 새 자녀 프로필을 추가할 수 없으며 앱에서 요금제 선택을 안내합니다. **데이터는 삭제되지 않습니다**. 계속 이용하려면 요금제를 구매하거나 선물 코드를 사용하세요.
