<a id="ho-so"></a>
## 자녀 프로필

각 자녀에게는 다음 정보가 담긴 별도 프로필이 있습니다.

| 정보 | 참고 |
|---|---|
| 실명 | 부모가 사용하며, 공유를 선택하지 않는 한 공개되지 않습니다. |
| 별명 | 순위표에 표시되는 이름. 비워 두면 공개 순위표에 “슈퍼 어린이”가 표시됩니다. |
| 나이(0~18세) | 슬라이더로 설정하며 **단계**(0–3, 3–6, 6–12, 12–18세)를 자동으로 정하고 설명합니다. 추천, [여정](04-thiet-ke-thoi-quen.md#lo-trinh), [연령별 인터페이스](02-man-hinh-be.md#giao-dien-tuoi)에 적용됩니다. |
| 마스코트 및 색상 | 여섯 [마스코트](02-man-hinh-be.md#linh-vat) 중 선택 |
| 순위표 | 공개 순위표에 참여할지, 실명 또는 별명만 표시할지 선택합니다(별명 권장). 새 자녀는 기본적으로 **비공개**입니다. |
| 연령별 인터페이스 | 프로필 수정 시 **연령 자동 적용**, 3~8세 또는 9~12세 범위 고정, 13세 이상, **현재 인터페이스 유지** 중 선택합니다. 부모의 선택이 자녀 기기의 선택보다 우선합니다. |

프로필 카드에서 부모는 다음을 할 수 있습니다.

- 자녀 프로필을 **추가, 수정 또는 삭제**합니다. 자녀 수는 [요금제](07-goi-va-thanh-toan.md#cac-goi)에 따라 다릅니다. 단일 자녀 요금제는 최대 1명이며 체험 및 가족 요금제는 제한이 없습니다. 요금제가 만료되면 요금제 없이는 새 프로필을 추가할 수 없습니다.
- **연령별 팩 불러오기**(“연령에 맞는 습관 6개 자동 추가…”)로 시작 할 일 여섯 개를 바로 받습니다.
- [별을 직접 지급하거나 차감](03-hom-nay-va-duyet-viec.md#chinh-sao)합니다.
- 별, 레벨, 연속 기록 및 자녀가 순위표에서 숨겨졌는지 확인합니다.
- 자녀의 **연결 코드와 QR 코드**를 엽니다([아래](#ghep-thiet-bi)).

<a id="ghep-thiet-bi"></a>
## 자녀 기기 연결

자녀마다 **고정 연결 코드 하나**와 그에 해당하는 QR 코드가 있습니다. 코드는 해당 자녀에게만 접근을 허용하고 PIN이나 가족 데이터를 포함하지 않으며, 부모가 새로 고침하기 전까지 바뀌지 않습니다.

1. **자녀 코드 받기**: `Family → Child profiles`에서 코드를 복사하거나 “QR 코드 표시”를 누릅니다. PIN이 설정되어 있다면 [PIN](#pin)이 필요합니다.
2. **자녀 기기 열기**: 앱에서 “자녀 기기인가요?”를 열고 “코드 입력 또는 QR 스캔”을 선택합니다(또는 상단 바에서 “자녀 코드” 선택).
3. **QR을 스캔하거나 코드 입력**: 기기가 올바른 자녀 프로필에 자동으로 로그인합니다. “연결되었습니다!”가 표시되면 자녀가 “자녀 할 일 시작”을 누릅니다.

연결 후에는 부모 대시보드나 판매 페이지 없이 [자녀 화면](02-man-hinh-be.md)이 바로 열립니다.

- 한 자녀의 코드(“이 자녀의 새 코드 만들기”) 또는 **모든 자녀의 코드**(“새 자녀 코드 만들기”)를 새로 발급하면 이전 코드는 사용할 수 없습니다. 코드가 노출되었다고 의심될 때만 진행하세요. PIN이 필요합니다.
- 카메라가 열리지 않으면 카메라 권한을 허용하고 보안 연결(https)을 사용하거나 코드를 직접 입력하세요.
- 잘못된 코드를 너무 많이 입력하면 요청이 제한됩니다([9](09-bao-mat-va-rieng-tu.md#ma-ghep)).

<a id="thiet-bi"></a>
## 기기 관리

`Settings → Devices & family rhythm → Children's devices`에 연결된 기기와 연결된 자녀, 마지막 확인 시각, 접근 만료 여부가 표시됩니다. 기기를 잃어버렸거나 더 이상 사용하지 않으면 **접근 권한을 즉시 해제**하세요(PIN 필요). 기기 하나는 자녀 프로필 **하나만** 이용할 수 있습니다.

<a id="nguoi-cham-soc"></a>
## 돌봄 제공자 초대

진행 상황을 확인하고 싶지만 **아무것도 변경할 수 없는** 조부모나 친척을 초대할 수 있습니다.

1. `Settings`에서 **돌봄 제공자 초대 만들기**를 누릅니다. **일회용** 초대 링크는 생성 시에만 표시되며 **72시간 후 만료**됩니다. 복사해 초대할 분에게 보내세요.
2. 초대받은 분은 링크를 열고 Google로 로그인한 다음 수락을 누릅니다. 초대가 만료되거나 취소되었거나 계정이 이미 다른 가족에 속하면 “유효하지 않은 초대…”가 표시됩니다.
3. **돌봄 제공자 공간**을 열어 각 자녀의 진행 상황을 읽기 전용으로 봅니다. “오늘: x / y개 할 일”(y는 반복 규칙에 따라 오늘 예정된 할 일 수이며 없으면 “오늘 예정된 할 일이 없습니다”), “최근 7일: x / y”, 자녀별 습관, 보조 수치인 “전체 기간” 완료 합계가 표시됩니다. 돌봄 제공자는 날짜별 개수만 볼 수 있으며 어떤 할 일을 했는지, 시간이나 메모는 볼 수 없습니다.
4. 부모는 “활성 초대” 목록에서 언제든 **초대 취소**를 할 수 있습니다.

<a id="cai-dat"></a>
## 설정 그룹

`Family → Settings`는 여러 그룹으로 나뉩니다. “설정 그룹” 바를 누르면 각 섹션으로 이동합니다.

| 그룹 | 내용 |
|---|---|
| **기기 및 가족 리듬** | 자녀 기기, 앱 설치, 돌봄 제공자, [가족 휴식](#tam-nghi) |
| **계정 및 동기화** | 고객 정보, 선물 코드, 가족 데이터 |
| **개인정보 및 알림** | 공개 순위표, 익명 측정, 알림 |
| **화면 표시** | 밝게, 어둡게, 기기 설정 |
| **부모 영역 보호** | PIN |
| **혜택 및 추천** | 추천 코드 입력란, 친구 추천 카드(페이지 하단, 로그인 시에만 표시) |

주소 표시줄에 열린 섹션이 기억됩니다(예: `?section=settings#settings-security`). 새로고침해도 같은 섹션에 머물고 브라우저 뒤로 가기 버튼으로 이전 섹션에 돌아갑니다. 링크는 부모 영역의 섹션만 선택하며 잠금을 해제하지 않습니다. 자녀 모드에서는 `section` 부분이 무시됩니다.
페이지 아래쪽에서 “사용자 안내서 열기”(앱의 `/docs` 페이지, [앱에서 도움말 찾기](01-bat-dau.md#tro-giup) 참조)와 개인정보, 약관, 고객 지원 링크를 찾을 수 있습니다([11](11-website-va-trang-cong-khai.md)).

<a id="tai-khoan"></a>
## 계정 및 동기화

- **상태**: “가족 계정”, 인증됨, “클라우드 준비됨”. 별도 기술 설정 없이 가족 데이터가 휴대폰, 태블릿, 컴퓨터 사이에서 자동 동기화됩니다.
- **고객 정보**: 전체 이름, 전화번호(숫자 9~15자리), 이메일(읽기 전용), 안내 및 혜택 수신 선택. 계정과 결제 지원에 사용됩니다.
- **쿠폰 코드**: 선물 코드를 입력해 이용 기간에 날짜를 추가합니다([7](07-goi-va-thanh-toan.md#coupon)).

<a id="rieng-tu"></a>
## 개인정보 및 알림

- **공개 순위표 공유**: 가족 전체에 적용되는 스위치이며 기본값은 **꺼짐**입니다. 부모만 변경할 수 있습니다. 켜면 [프로필](#ho-so)에서 선택한 자녀만 별명, 아바타, 기간 점수, 연속 기록 및 순위로 표시됩니다. 언제든 끌 수 있습니다([9](09-bao-mat-va-rieng-tu.md#bxh-cong-khai)).
- **익명 측정**: 부모 동의 스위치이며 기본값은 꺼짐입니다. 현재 데이터 수집 대상이 설정되어 있지 않아 이벤트는 기기를 벗어나지 않습니다([제품 분석](../product-analytics.md)).
- **알림**: [아래](#nhac-viec)를 참조하세요.

<a id="nhac-viec"></a>
### 부모 알림

“확인이 필요한 항목의 알림 허용”을 켜면 할 일이나 보상의 승인이 필요할 때 알림을 받습니다. 알림은 승인 대기 항목에만 사용되며 광고가 아닙니다. 언제든 끌 수 있습니다. 앱 밖에서도 알림을 받으려면 “이 기기의 알림 허용”을 누르세요. 기기에서 차단하더라도 앱 안에는 알림이 표시됩니다([오늘 배너](03-hom-nay-va-duyet-viec.md#nhac-viec-ngan) 참조).

<a id="giao-dien"></a>
## 화면 표시

- 화면 표시 그룹에서 **밝게, 어둡게, 기기 설정**을 선택합니다.
- **글꼴 및 크기**: 상단 바의 “글꼴 및 크기 설정” 창을 열어 자녀가 읽기 편하도록 조정합니다.
- **언어**: 상단 바의 언어 선택기([1](01-bat-dau.md#ngon-ngu)).
- **연령별 자녀 인터페이스**: [자녀 프로필을 수정](#ho-so)할 때 고정합니다.

<a id="pin"></a>
## 부모 PIN

PIN은 **정확히 숫자 4자리**이며 가족 관리 영역을 보호합니다. 자녀와 공유하지 마세요.

- **만들기**: PIN을 입력한 다음 확인을 위해 다시 입력합니다. **변경**: 현재 PIN을 입력한 후 새 PIN을 두 번 입력합니다.
- PIN을 설정하면 자녀 화면에서 부모 모드로 전환할 때 PIN이 필요합니다. 올바르게 입력하면 이 브라우저가 **2시간** 동안 잠금 해제 상태로 유지됩니다. 다시 잠그면 잠금 해제 상태가 해제됩니다.
- 다음 민감한 작업에는 잠금 해제가 필요합니다: 자녀 연결 코드 보기 또는 변경, 기기 접근 해제, 할 일 및 보상 승인, 별 직접 지급 또는 차감, 결제 생성, 가족 삭제, 은행 정보 저장, 추천 수익 출금. 영역이 잠금 해제되지 않았으면 앱이 잠금 화면으로 돌아갑니다.
- 추천 수익을 출금하려면 가족에 **PIN이 설정되어 있어야 합니다**([8](08-gioi-thieu-ban-be.md#rut-tien)).
- 잘못된 입력이 너무 많으면 몇 분 기다려야 합니다(“너무 많이 시도했습니다”).
- 부모 기기에서 자녀가 할 일을 완료 표시하는 데는 PIN이 **필요하지 않습니다**.

<a id="tam-nghi"></a>
## 가족 휴식

`Settings → Family break`에서 **휴식하기**를 누른 후 가족 모두가 쉬어야 할 때(질병, 여행 또는 휴가) 확인합니다. 휴식 중에는 다음과 같습니다.

- 자녀 화면에서 진행 알림, 연속 기록 및 순위표가 숨겨지고 다정한 안내가 표시됩니다([2](02-man-hinh-be.md#tam-nghi-be)).
- 자녀는 계속 할 일을 할 수 있으며 별, 보상 및 할 일은 삭제되지 않습니다.
- 휴식일은 [연속 기록](02-man-hinh-be.md#sao-cap-chuoi)을 끊지 않으며 [습관 단계 계산](06-khoa-hoc-thoi-quen.md#logic)에서 놓친 날로 세지 않습니다.
- [알림](#nhac-viec)이 일시 중지됩니다.

준비되면 **다시 시작**을 누르세요.

<a id="pwa"></a>
## 앱 설치

“KidHabit Hero 설치” 카드로 웹에서 새 버전을 계속 받으면서 앱처럼 빠르게 열 수 있습니다. Android/Chrome에서는 “지금 설치”를 누르고, iPhone에서는 Safari를 열어 공유 → 홈 화면에 추가를 선택하세요. 필요하면 “앱 데이터 새로고침” 버튼도 사용할 수 있습니다.

<a id="du-lieu"></a>
## 가족 데이터

“가족 데이터” 카드에서 자녀 프로필, 습관, 완료 기록, 보상, 그룹, 일기, 신호 및 자녀의 실천 방법 기록을 포함한 JSON 사본을 **다운로드**할 수 있습니다. 파일에는 **PIN이나 결제 정보가 들어 있지 않지만** 자녀 데이터가 포함되므로 비공개로 보관하세요. “JSON 파일에서 복원”은 이 기기에 저장된 데이터에만 적용되며 모든 로컬 데이터를 대체합니다. Google 계정 데이터는 가족 서버에 저장됩니다. 자녀 일기는 [통계](03-hom-nay-va-duyet-viec.md#thong-ke)에서 별도로 내보내세요. 영구 삭제: [9](09-bao-mat-va-rieng-tu.md#xoa-du-lieu).

<a id="uu-dai"></a>
## 혜택 및 추천

로그인했을 때만 표시되는 `Settings`의 마지막 그룹입니다.

- **추천 코드**: “친구에게 받은 추천 코드가 있나요?” 입력란(가족이 대상일 때만 표시).
- **친구 추천**: 링크 받기, 수수료 추적 및 출금을 위한 카드([8](08-gioi-thieu-ban-be.md)).
