# 13. Terms

[← 12. Link Map and Scenarios](12-ban-do-lien-ket.md) · [Table of Contents](README.md)

Terms used throughout the documentation, in alphabetical order, with links to detailed explanations.

| Term | Meaning in KidHabit | See |
|---|---|---|
| **Acts of Giving (7 acts of giving)** | Seven simple ways to give each day: a smile, eye contact, kind words, gratitude, tolerance, helpful action, and giving way to others | [6](06-khoa-hoc-thoi-quen.md#chan-dung) |
| **Child** | A child profile in the family; use a paired device to open the child’s screen | [2](02-man-hinh-be.md) |
| **Nickname** | The name shown on the leaderboard instead of the child’s real name | [5](05-gia-dinh-va-cai-dat.md#ho-so) |
| **Leaderboard** | Rankings based on stars earned during the period: family, squad, or public | [2](02-man-hinh-be.md#bang-xep-hang) |
| **Level** | Increases with every 100 stars earned | [2](02-man-hinh-be.md#sao-cap-chuoi) |
| **Portrait (16 portraits)** | A direction for growth, not a personality type; each portrait is a badge | [6](06-khoa-hoc-thoi-quen.md#chan-dung) |
| **Family Owner** | The person who created the family; can delete family data | [1](01-bat-dau.md#vai-tro) |
| **Habit Program** | A group of habits built step by step, with cues and stage tracking | [4](04-thiet-ke-thoi-quen.md#chuong-trinh) |
| **Streak (flame)** | The number of consecutive days with confirmed tasks; leaving one day blank for a break does not end the streak | [2](02-man-hinh-be.md#sao-cap-chuoi) |
| **Coupon / gift code** | A code that adds days to the plan period | [7](07-goi-va-thanh-toan.md#coupon) |
| **Free Trial** | 7 free days, once per family, with no automatic charge | [7](07-goi-va-thanh-toan.md#dung-thu) |
| **Approval** | A parent confirms a child’s task or reward | [3](03-hom-nay-va-duyet-viec.md#duyet) |
| **Entitlement** | What the current plan allows, such as the number of children; linked to the family | [7](07-goi-va-thanh-toan.md#cac-goi) |
| **Family** | The data and payment unit; each family is a separate “space” | [9](09-bao-mat-va-rieng-tu.md#ai-thay) |
| **Stage (GD1–GD5)** | The five age stages in the framework: 0–3, 3–6, 6–12, 12–15, 15–18 | [6](06-khoa-hoc-thoi-quen.md#khung) |
| **Habit Stage / Phase** | The four phases of a habit: anchor the cue, build the routine, reduce support, and make it a habit | [6](06-khoa-hoc-thoi-quen.md#bon-pha) |
| **Device Pairing** | Links one device to one specific child using a code or QR code | [5](05-gia-dinh-va-cai-dat.md#ghep-thiet-bi) |
| **Age-Based Pack** | A set of six starter tasks loaded with one tap for the child’s age group | [5](05-gia-dinh-va-cai-dat.md#ho-so) |
| **League Tier** | Bronze, Silver, Gold, or Diamond based on total stars earned | [2](02-man-hinh-be.md#sao-cap-chuoi) |
| **Commission** | 30% of the actual amount paid by a referred family | [8](08-gioi-thieu-ban-be.md#hoa-hong) |
| **Today** | The first parent area: Approvals and Analytics | [3](03-hom-nay-va-duyet-viec.md) |
| **Badge** | A reward unlocked when a milestone is reached: 5 basic badges and 16 portrait badges | [2](02-man-hinh-be.md#huy-hieu) |
| **47-Habit Framework** | A set of habits for ages 0–18, across 5 stages and 5 areas | [6](06-khoa-hoc-thoi-quen.md#khung) |
| **Rewards Store** | A list of rewards parents create for their child | [4](04-thiet-ke-thoi-quen.md#kho-qua) |
| **Age Roadmap** | Five stages, three steps per stage, with one more habit added at each step | [4](04-thiet-ke-thoi-quen.md#lo-trinh) |
| **Mascot** | Six characters who accompany the child: Leo, Bunny, Panda, Fox, Turtle, and Bee | [2](02-man-hinh-be.md#linh-vat) |
| **Pairing Code / Connection Code** | A fixed code for each child; it opens only that child’s profile | [9](09-bao-mat-va-rieng-tu.md#ma-ghep) |
| **Referral Code** | An 8-character code attached to the `?ref=` link | [8](08-gioi-thieu-ban-be.md) |
| **Caregiver** | A family member invited to view progress in read-only mode | [5](05-gia-dinh-va-cai-dat.md#nguoi-cham-soc) |
| **PayOS / VietQR** | A payment gateway for bank transfers using a bank QR code | [7](07-goi-va-thanh-toan.md#thanh-toan) |
| **Parent PIN** | A 4-digit code protecting Parent Mode and sensitive actions; unlocks access for 2 hours | [5](05-gia-dinh-va-cai-dat.md#pin) |
| **PWA** | Installs the website as an app on the home screen | [5](05-gia-dinh-va-cai-dat.md#pwa) |
| **Stars** | Reward points used to redeem rewards and build the city | [2](02-man-hinh-be.md#sao-cap-chuoi) |
| **Break** | Pauses progress reminders and streaks for the whole family without losing data | [5](05-gia-dinh-va-cai-dat.md#tam-nghi) |
| **Modeling** | Parents set an example through their own actions | [6](06-khoa-hoc-thoi-quen.md#chan-dung) |
| **“If… then…” cue** | A plan that connects a habit to a familiar activity or a fixed time | [4](04-thiet-ke-thoi-quen.md#chuong-trinh) |
| **Maybe Later (snooze)** | The child moves a task to the end of the day; it is not counted as missed | [2](02-man-hinh-be.md#hoan-thanh) |
| **Webhook / reconciliation** | PayOS reports the payment; the system also checks with PayOS again to confirm it | [7](07-goi-va-thanh-toan.md#kich-hoat) |
| **Two-Step Verification (admin)** | A TOTP code required for administrator accounts | [10](10-quan-tri-va-van-hanh.md#admin) |
