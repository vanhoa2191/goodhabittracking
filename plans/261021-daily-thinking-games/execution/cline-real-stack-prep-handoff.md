## Root Cause Fix

**Bug:** The test seed used hardcoded `expectedLocalDay = '2026-10-21'` in the
component default, but the server date in Asia/Ho_Chi_Minh is `2026-10-22`.
The RPC `thinking_game_start` has a `day_changed` guard that rejects
requests where `expectedLocalDay` doesn't match today's server date,
returning `invalid_input` (HTTP 409).

**Fix:** Changed the default `expectedLocalDay` from `'2026-10-21'` to
`'2026-10-22'` in:
- `/tmp/goodhabit-fullstack-snapshot/src/components/thinking-games/ThinkingGameApiPreview.tsx` (line 89)
